每篇长什么样

每篇固定 9 个板块，顺序不变：

  1. 30 秒速查
  2. 准备事项
  3. 现场流程
  4. 常见问题
  5. 避坑提醒
  6. 特殊情况与应急
  7. 费用与时间预算
  8. 延伸资源
  9. 依据与核实

写作模板见 meta/条目模板.html，规范见 meta/写作规范.html。

事实怎么保证

  • 每条关键事实标依据等级：Ⅰ 法规与强制标准、Ⅱ 官方办事指引、Ⅲ 多方一致的通行做法、Ⅳ 亲历者经验。
  • 「必须」「不得」「否则会被拒绝」这类强制表述，只能由 Ⅰ 或 Ⅱ 级来源支撑。
  • 每篇配一份 sources/ID.核实.md，记录文中说法、来源、原文摘录、访问日期。
  • 查不到的内容写「待核实」，不写推测。
  • 来源白名单、引用格式和链接失效处理，见 meta/依据分级与引用规则.html。

怎么参与

  1. 提 纠错：写清条目 ID、正文原句、正确说法、来源链接和访问日期。
  2. 提 新条目：写清为什么是第一次、目标读者、3 个核心问题、2 个官方来源。
  3. 提 内容过时：写清哪条规则变了、官方新链接、生效日期。
  4. 改稿前先读 meta/调研与核实流程.html，按七步流水线走。

本地运行

检索页是纯静态的，没有后端。因为浏览器不允许网页直接读本地 JSON，需要起一个静态服务：

cd HowToFirstTime   # 或你的本地目录名
node tools/serve.mjs

然后打开 http://localhost:8000/。也可以用 Python：

python -m http.server 8000

重新生成索引：

node tools/build-index.mjs

重新生成全部阅读页（book/、checklists/、sources/ 等目录下的 .html 由脚本从 Markdown 生成，改完正文后跑一次即可，产物与 index.json 一并提交）：

npm install
node tools/build-site.mjs

跑全部检查：

node tools/check-frontmatter.mjs
node tools/check-structure.mjs
node tools/check-refs.mjs
node tools/check-stale.mjs
node tools/check-todo.mjs
node tools/check-links.mjs
