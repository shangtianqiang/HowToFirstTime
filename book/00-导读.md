# 怎么用这份手册

每个人都会遇到第一次。第一次坐飞机、第一次入职、第一次当爸爸，难的往往不是事情本身，而是不知道先做什么、要带什么、哪里会出错。

这份手册把每件事拆成固定的九块：速查、准备、现场流程、常见问题、避坑、特殊情况、费用时间、延伸资源、依据核实。你可以从头读，也可以在现场直接翻。

## 三种读法

**还有时间，提前准备。** 先看「30 秒速查」，再看「准备事项」，照着清单勾。

**人已经在现场。** 直接看「现场流程」，找当前这一步；卡住了翻「特殊情况与应急」。

**已经做完，想弄明白。** 看「常见问题」和「避坑提醒」，再按「延伸资源」去官方页面核对。

## 状态标记

| 标记 | 含义 |
| --- | --- |
| 初稿 | 结构已就位，正文尚未逐条核实。 |
| 已核实 | 关键事实已逐条核对，核实记录可查。 |
| 待更新 | 规则可能已变，正在复核。 |
| 有争议 | 来源之间存在冲突，正文已注明。 |

检索页默认只显示「已核实」的条目。骨架阶段可以在设置里打开「显示初稿」。

## 事实怎么保证

- 每条关键事实标依据等级：Ⅰ 法规与强制标准、Ⅱ 官方办事指引、Ⅲ 多方一致的通行做法、Ⅳ 亲历者经验。
- 强制表述只能由 Ⅰ 或 Ⅱ 级来源支撑。
- 每篇配一份 `sources/ID.核实.md`，记录说法、来源、原文摘录和访问日期。
- 查不到就写「待核实」，不写推测。
- 规则会变，每篇都标最近核实日期和时效等级。
