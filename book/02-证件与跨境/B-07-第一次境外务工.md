# 第一次境外务工

> **一句话**：只走有对外劳务合作经营资格的企业，签书面合同、办工作签证，持旅游签出境打工是违法的。
> **适用**：第一次通过正规渠道赴境外从事建筑、制造、餐饮、护理等劳务工作的人。
> **不适用**：企业外派的管理技术人员、留学生兼职、海员，适用不同规定。

## 0. 30 秒速查

- **查企业**：商务部对外劳务合作企业名单，有经营资格才合法。
- **签证**：必须是工作签证，旅游、商务、探亲签不能打工。
- **合同**：服务合同 + 劳动合同，写清工资、工时、保险、食宿、退费。
- **收费**：服务费有上限，不得收押金、不得扣押证件。
- **体检**：按目的国要求做健康检查，带疫苗记录。
- **落地**：办居留许可、税号、保险，到使领馆登记。
- **求助**：中国驻当地使领馆、12308、当地劳工部门。

## 1. 准备事项

### 1.1 选正规渠道

- 在商务部“对外劳务合作企业名录”查询企业资格。
- 看企业是否有对应国家的项目备案，不轻信个人中介。
- 问清岗位、工资、工时、合同期限、食宿、保险。
- 警惕“高薪、零门槛、包机票”的招工广告。

### 1.2 合同与费用

- [ ] 对外劳务合作服务合同
- [ ] 与境外雇主签订的劳动合同（中文或附中文译本）
- [ ] 护照
- [ ] 工作签证
- [ ] 体检报告和疫苗记录
- [ ] 技能证书
- [ ] 保险单
- 合同要写清工资币种、发放方式、加班费、休息日、解除条件、违约责任。
- 服务费不得超过合同工资的一定比例，企业不得收取押金或扣押证件。[1]

### 1.3 行前

- 记下企业项目负责人、境外雇主、使领馆电话。
- 把合同、护照、签证扫描备份给家人。
- 了解目的国法律、宗教习俗、气候和安全形势。
- 换少量当地货币，准备常用药。

## 2. 现场流程

### 2.1 出境

- 在哪：国际机场或口岸。
- 做什么：值机、边检，出示护照、工作签证、合同。
- 看什么：签证类型是否为工作类，有效期是否覆盖合同期。
- 完成标志：登机。

### 2.2 入境与登记

- 在哪：目的国口岸。
- 做什么：回答入境问询，出示雇主邀请函和合同。
- 看什么：入境章上的居留期限。
- 完成标志：入境，与雇主或企业代表会合。

### 2.3 落地手续

- 居留许可：按当地规定时限办理。
- 税号、社保号：由雇主协助办理。
- 银行开户：带护照、合同、住址证明。
- 使领馆登记：部分国家要求中国公民自愿登记，便于紧急联系。
- 保险：确认工伤和医疗覆盖。

### 2.4 工作期间

- 按合同岗位工作，不擅自换雇主、换岗位。
- 保留工资单、工时记录、加班记录。
- 遇到欠薪、扣押护照、限制人身自由，立即联系使领馆和当地劳工部门。

## 3. 常见问题

### Q1 怎么查外派劳务公司是否正规？
答：在商务部对外劳务合作企业名录查询经营资格，再看是否有对应国家的项目。[1]

### Q2 持旅游签证能出国打工吗？
答：不能。持旅游、商务、探亲签证务工属非法就业，会被罚款、遣返，甚至禁止入境。

### Q3 中介收费有上限吗？
答：有。对外劳务合作企业收取服务费不得超过规定比例，不得收取押金或要求财产担保。[1]

### Q4 护照被公司收走怎么办？
答：拒绝交出护照。护照是个人证件，任何单位和个人不得非法扣押。已扣的向使领馆和当地警方求助。

### Q5 工资被拖欠怎么办？
答：保留合同、工资单、考勤记录，先向雇主书面催告，再向当地劳工部门投诉，同时联系使领馆。

### Q6 合同看不懂怎么办？
答：要求提供中文译本，逐条确认工资、工时、加班、保险、解除条件，再签字。

### Q7 境外受伤算工伤吗？
答：按当地法律和保险合同处理。出境前确认雇主是否购买工伤或意外保险，保留诊断和费用单据。

### Q8 可以带家属吗？
答：多数劳务签证不允许家属随行，具体看目的国规定和合同。

### Q9 合同到期想留下怎么办？
答：必须通过合法渠道变更签证和雇主，不能擅自滞留。咨询当地移民部门和使领馆。

### Q10 遇到战乱、疫情怎么办？
答：关注使领馆安全提醒，按企业应急方案撤离，拨 12308 求助。

## 4. 避坑提醒

- **黑中介**：没有经营资格，收钱后失联或转给其他公司。
- **旅游签打工**：违法，被查即遣返。
- **扣押护照**：限制人身自由的常见手段，坚决拒绝。
- **押金、保证金**：正规企业不得收取。
- **口头承诺高薪**：不写进合同就不算数。
- **不买保险**：境外工伤医疗费用高，雇主不买要自己确认。
- **合同外加班**：保留记录，按当地法律主张加班费。
- **轻信“老乡”介绍**：熟人也会被黑中介利用。

## 5. 特殊情况与应急

- **欠薪**：书面催告，向当地劳工部门投诉，联系使领馆。
- **护照被扣**：向当地警方报案，联系使领馆补办旅行证。
- **人身受限**：找机会报警或联系家人，拨 12308。
- **工伤事故**：先就医，保留诊断和费用单据，报保险和雇主。
- **被遣返**：联系使领馆，保留遣返文件，回国后咨询法律途径。
- **战乱、自然灾害**：按使领馆和企業应急预案撤离。

## 6. 费用与时间预算

| 项目 | 大概金额 | 说明 |
| --- | --- | --- |
| 服务费 | 按合同工资比例 | 有上限，必选 |
| 护照、签证 | 几百到几千元 | 必选 |
| 体检 | 几百元 | 必选 |
| 机票 | 几千元 | 多由雇主或企业承担 |
| 时间 | 提前 2–6 个月 | 报名到出境 |
