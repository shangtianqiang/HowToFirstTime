第一次处理毕业生档案

一句话：档案由学校按你登记的毕业去向机要转递，个人不得自带；存档和转递都免费，先查清在哪再去办。 适用：应届高校毕业生，以及毕业不久、还没弄清档案去向的人。 不适用：已工作多年且档案在单位或人才中心正常流转的人；人事争议和档案内容更正，找存档机构的档案管理部门。

0. 30 秒速查

  • 档案不能自己拿：转递必须机要通道或邮政特快专递密封转递，个人自带不被接收。
  • 毕业先登记去向：在全国高校毕业生毕业去向登记系统（dj.ncss.cn）登记，这是学校转档案的依据。
  • 两个免费去向：未就业可留校两年，或转回生源地公共就业人才服务机构。
  • 去哪查在哪：全国人社政务服务平台 zwfw.mohrss.gov.cn 的「跨省流动人员人事档案管理服务」。
  • 存档不花钱：2015 年 1 月 1 日起取消档案保管费等费用。
  • 卡住了找谁：学校就业指导中心 → 户籍地人才中心 → 12333。

1. 准备事项

1.1 先弄清档案是什么

  • 人事档案是记录你求学、工作经历的官方材料袋：高中起的学籍卡、成绩单、奖惩记录、政治面貌材料、毕业登记表等。
  • 它在你考公务员政审、进国企和事业单位入职、评定职称、某些城市落户审核时会被调阅。
  • 档案不等于户口，两者可以放在不同城市，但通常毕业去向登记时会一起处理。

1.2 毕业离校前在学校要做的事

  • 在 dj.ncss.cn 登记毕业去向：就业（含单位名称）、升学、出国、灵活就业、暂不就业等。
  • 核对去向信息：单位全称、生源地地址写错，档案会转错地方。
  • 问清学校档案室：档案何时转出、转到哪个机构、有没有转递单号。
  • 需要留校的（离校未就业），向学校提出申请，户口档案可保留两年。
  • 党员或预备党员，另外办理组织关系转接，和档案转递是两件事。

1.3 毕业后自查时带什么

  • 身份证（现场查档和办手续用）。
  • 毕业证书或学信网学历在线验证报告。
  • 记下毕业院校名称、毕业时间、生源地省市，查询时要填。

2. 现场流程

2.1 毕业时确定去向

  • 在哪：全国高校毕业生毕业去向登记系统（dj.ncss.cn）。
  • 做什么：按真实情况登记去向。单位能接收档案的（部分国企、事业单位、机关）填单位；不能接收的填生源地或工作地公共就业人才服务机构。
  • 看什么：登记完成后系统生成的去向信息，这是学校办理户籍和档案转递的依据。
  • 完成标志：学校确认登记信息，离校手续里档案一栏显示已安排转递。

2.2 档案怎么从学校到存档地

  • 在哪：学校档案部门 → 机要通信或邮政特快专递。
  • 做什么：学校按你的去向填写《高等学校毕业生档案转递单》并密封转递，你不需要也不应该经手。
  • 看什么：向学校要转递单号或转出日期，方便后续追踪。
  • 完成标志：接收机构签收入库。多数学校在毕业后 1–2 个月内完成转递。

2.3 查档案现在存在哪

  • 在哪：全国人社政务服务平台 zwfw.mohrss.gov.cn，注册后进「就业创业」板块的「跨省流动人员人事档案管理服务」。
  • 做什么：实名登录，用「档案存档情况查看」查询；查不到的，用平台机构查询或 m12333.cn 找到户籍地人才中心电话，打电话报身份证号查。
  • 看什么：存档机构名称、存档编号。
  • 卡住了怎么办：线上查不到先别慌，部分机构数据未上传全国平台，电话和线下窗口仍是最准的。

2.4 用档案时怎么调

  • 触发场景：考上公务员或事业编、入职新单位、人才引进落户，政审或入职需要调档。
  • 做什么：由具备档案管理权限的接收单位（机关、事业单位、国企人事部门或当地人才中心）开具「调档函」；你把调档函交给存档机构，机构之间机要转递。
  • 看什么：调档函有效期（通常注明），别压着过期。
  • 完成标志：接收单位确认档案到达并开封审核。

2.5 完成标志

  • 你能说出档案存在哪个机构，电话核实过；转递、存档全程没花一分钱。

3. 常见问题

Q1 档案到底有什么用，不处理会怎样？

答：考公考编政审、国企事业单位入职、职称评定、部分城市落户和工龄认定都要用。长期不知去向或自持，需要时现找现补，耗时以月计。

Q2 学校说档案已经转出，我该去哪找？

答：按你登记的毕业去向找。填了生源地就找户籍地市或县级公共就业人才服务机构；填了单位的先问单位人事。线上用 zwfw.mohrss.gov.cn 查，查不到就打电话。

Q3 档案能自己拿着保管吗？

答：不能。规定明确严禁个人保管本人或他人档案、严禁个人自带档案转递。人才中心不接收个人手递的密封档案。

Q4 存档要交钱吗？

答：不用。2015 年 1 月 1 日起，公共就业和人才服务机构取消收取人事关系及档案保管费、查阅费、证明费、档案转递费。

Q5 我在外地工作，档案必须回生源地吗？

答：不必。跨地区流动人员的档案，可由户籍所在地或现工作单位所在地的公共就业和人才服务机构管理，二选一，就近方便用就行。

Q6 离校时没找到工作，档案怎么办？

答：两条路：向学校申请保留两年（期间只能办理就业相关手续）；或按本人意愿转回户籍地公共就业人才服务机构。两年期满仍未转走的，学校一般转回生源地。

Q7 考上了公务员，调档函开出来了，流程是什么？

答：把调档函原件交到存档机构（有的支持线上提交），机构审核后通过机要通道转递到录用单位。个人不接触档案本身，通常 2–4 周到。

Q8 2023 年之后毕业，没有报到证了，档案怎么转？

答：取消就业报到证后，毕业去向登记信息就是户籍和档案转递接收的依据，学校按去向登记转递，不需要你办报到证。

Q9 出国留学，档案放哪？

答：常见做法是转回生源地公共就业人才服务机构，留学回国后按留学人员档案衔接办理；部分学校也允许短期保留，以学校规定为准。

Q10 怎么知道档案里材料齐不齐？

答：存档机构可提供档案内材料清单查询（部分城市线上可查）。政审或入职前主动查一次，缺高中材料、缺成绩单的及时补。

Q11 档案和社保冲突吗？档案在外地影响现在交社保吗？

答：不冲突。社保由工作单位在就业地缴纳，和档案存放地无关；但将来办退休审核档案时，材料要齐。

Q12 换城市工作，档案要跟着动吗？

答：不着急。档案不必随每次跳槽迁移，等有政审、落户、职称等实际需要时再调，避免反复转递增加丢失风险。

4. 避坑提醒

  • 档案到手自己存：学校把密封袋交给你让你「自己送去」，这是违规操作，多数机构拒收。坚持让学校走机要或邮政特快转递。
  • 去向登记随手填：填了「灵活就业」却想让档案回生源地，或单位地址写错，档案会转错。登记前和学校确认每一栏。
  • 两年留校当永久：留校只有两年，且期间档案处于冻结状态，办不了政审以外的多数业务。确定不就业就转生源地。
  • 网上查不到就以为丢了：全国平台只覆盖已上传数据的机构，查不到不等于丢了。先打电话给生源地人才中心。
  • 调档函压着不用：调档函有有效期，过期作废要重开，耽误入职和政审时间。
  • 交给「档案代办」中介：档案业务全程免费，公共机构直接办。中介代存不合规，可能造成档案失效。
  • 拆开看里面有什么：个人不得拆封。拆封的档案机构可能拒收，需要回原单位重新审核密封。
  • 毕业后从不过问：档案在哪都不知道，考编前才去找，最慢要追学校、机要局、人才中心三方，耗时以月计。毕业当年就查清。

5. 特殊情况与应急

  • 档案在自己手里多年：第一步联系户籍地公共就业人才服务机构，说明情况申请存入；机构审核后按其指引处理，未经密封或材料缺失可能要先补审。
  • 怀疑档案丢失：第一步找毕业院校档案室查转出记录和机要号，沿转递链逐环节追（学校→机要部门→接收机构），确实丢失的由责任方补建材料。
  • 政审等档案、流程来不及：第一步同时联系录用单位和存档机构，申请加急机要转递或协商先行出具存档证明，说明时限。
  • 学校已合并或撤销：第一步找合并后院校的档案管理部门或当地教育局查询学籍档案去向。
  • 人在国外需要办档案事务：第一步写委托书并公证，委托国内亲属到存档机构代办，或问机构是否支持线上办理。

6. 费用与时间预算

项目 大概金额 说明
存档费 0 元 2015 年起取消，必选项为 0
档案转递费 0 元 公共机构机要转递免费，必选项为 0
查询存档 0 元 全国平台或电话查询免费
补办材料 0–百元内 学籍材料补办本身免费，产生的主要是交通和复印成本，可选
存档证明 0 元 公共机构开具免费
时间 1-3天 查清去向和电话确认；转递周期另计 2–4 周
