# 第一次自学编程

> **一句话**：先定方向，只学够用的基础，边学边做项目，代码传到 Git 仓库，遇到问题先读官方文档。
> **适用**：零基础想转行、做副业或提升工作效率的成年人。
> **不适用**：计算机专业课程体系、算法竞赛、特定企业内训，路径不同。

## 0. 30 秒速查

- **定方向**：网页、数据分析、自动化办公、移动端，选一个。
- **语言**：网页前端 JavaScript；数据 Python；企业应用 Java 或 C#。
- **路线**：基础语法 → 小项目 → Git → 部署上线。
- **时间**：每天 1–2 小时，坚持 3 个月能看到成果。
- **方法**：看一遍、敲一遍、改一遍，不做“只看不练”。
- **求助**：官方文档、报错信息、开发者社区。
- **避坑**：不追新技术，不囤课，不抄作业。

## 1. 准备事项

### 1.1 选方向

| 方向 | 入门语言 | 第一个项目 |
| --- | --- | --- |
| 网页前端 | HTML/CSS/JavaScript | 个人主页、待办清单 |
| 数据分析 | Python | 表格清洗、图表 |
| 办公自动化 | Python | 批量改文件名、合并表格 |
| 移动端 | Dart/Flutter 或 Swift | 简单记账 App |

- 按目标选，不按“哪个最火”选。
- 先学一门，学透再扩展。
- 看招聘要求，确认方向有需求。

### 1.2 工具

- [ ] 电脑，内存 8GB 以上
- [ ] 编辑器：VS Code
- [ ] 浏览器：Chrome 或 Edge
- [ ] Git，注册 GitHub 或 Gitee 账号
- [ ] 笔记工具

### 1.3 学习计划

- 第 1–2 周：环境搭建、基础语法。
- 第 3–6 周：函数、数据结构、文件操作。
- 第 7–10 周：做一个小项目。
- 第 11–12 周：部署上线，写文档。
- 每周留一天复习，不追进度。

## 2. 现场流程

### 2.1 搭环境

- 在哪：电脑上。
- 做什么：装编辑器、运行时、Git，跑通 Hello World。
- 看什么：版本号、报错信息。
- 完成标志：程序能运行。

### 2.2 学基础

- 在哪：官方文档或系统课程。
- 做什么：变量、条件、循环、函数、数组、对象。
- 看什么：示例代码，跟着敲。
- 完成标志：能独立写出小练习。

### 2.3 做项目

- 在哪：本地项目文件夹。
- 做什么：从需求到代码，拆成小任务。
- 看什么：报错、日志、浏览器开发者工具。
- 完成标志：项目能跑通核心功能。

### 2.4 用 Git 管理

- 在哪：命令行或编辑器。
- 做什么：初始化仓库、提交、推送。
- 看什么：提交记录、分支。
- 完成标志：代码在远程仓库，有 README。

### 2.5 部署

- 在哪：静态托管或云服务器。
- 做什么：把项目发布到线上，配置域名。
- 看什么：访问日志、错误日志。
- 完成标志：别人能通过链接访问。

## 3. 常见问题

### Q1 零基础先学什么语言？
答：看目标。网页前端学 JavaScript，数据分析学 Python，企业后端学 Java。先选一个方向。

### Q2 需要数学很好吗？
答：普通开发不用高深数学，数据分析要统计基础，算法岗要求更高。

### Q3 看视频还是看书？
答：入门看视频快，进阶读官方文档。关键是跟着敲，不只看。

### Q4 多久能找工作？
答：因人而异。每天 2–3 小时，6–12 个月可达到初级岗位水平，项目作品比证书重要。

### Q5 要不要报培训班？
答：自制力差可以报，但先试学 2 周。高价“包就业”要谨慎。

### Q6 英语不好能学吗？
答：能。报错信息和文档多为英文，用翻译工具，慢慢积累常用词。

### Q7 报错看不懂怎么办？
答：先复制报错搜索，看官方文档，再问社区。提问要附代码、报错和环境。

### Q8 学完就忘怎么办？
答：做项目。孤立的语法记不住，项目会逼你反复用。

### Q9 要不要学算法？
答：求职笔试要，日常工作用得少。先能做项目，再补算法。

### Q10 怎么证明自己会编程？
答：GitHub 项目、可访问的作品、技术博客。面试会问项目细节。

## 4. 避坑提醒

- **教程地狱**：收藏一堆课，一个项目没做完。
- **只看不敲**：看懂了不等于写得出。
- **追新技术**：基础不牢，框架换一个就不会。
- **抄作业**：面试一问就露馅。
- **不学 Git**：代码丢失，协作困难。
- **不问人**：卡三天的问题，可能一句话就能解决。
- **买“包就业”课**：承诺不写进合同，退款难。
- **不做项目**：没有作品，简历空白。

## 5. 特殊情况与应急

- **环境装不上**：查官方安装文档，用虚拟机或在线环境。
- **卡在同一问题**：换搜索关键词，去官方论坛或社区提问。
- **电脑配置低**：用在线编辑器或轻量工具。
- **学习动力不足**：定小目标，每周产出可见成果。
- **被诈骗课程**：保留付款记录，向平台投诉或拨 12315。
- **眼睛、颈椎不适**：控制时长，定时休息。
