# 第一次买车

> **一句话**：先算落地价不只裸车价，合同写清车型配置和交车日期，提车验生产日期和手续，保险三者险买够。
> **适用**：第一次购买新车（燃油车或新能源车）的个人消费者。
> **不适用**：二手车、平行进口车、营运车辆，验车和手续不同。

## 0. 30 秒速查

- **落地价**：裸车价 + 购置税 + 保险 + 上牌 + 装饰。
- **购置税**：燃油车约车价（不含税）的 10%；新能源按现行减免政策。
- **合同**：车型、配置、颜色、车架号、交车日期、赠品、违约。
- **验车**：生产日期、里程、外观、轮胎、玻璃、手续。
- **手续**：合格证、发票、三包凭证、保养手册。
- **保险**：交强险必买，三者险建议 200 万元以上。
- **上牌**：身份证、发票、合格证、交强险、购置税。

## 1. 准备事项

### 1.1 算总预算

- 裸车价：指导价减去优惠。
- 购置税：燃油车按不含税价 10% 估算；新能源按现行减免政策。[1]
- 保险：交强险 + 商业险，首年通常 4000–8000 元。
- 上牌：几百元。
- 装饰、充电桩、停车位：按需。
- 贷款：算清利息和手续费，不只看月供。

### 1.2 选车

- 用途：通勤、家庭、长途。
- 能源：燃油、混动、纯电，考虑充电条件。
- 配置：安全配置优先（气囊、ESP、主动刹车）。
- 保值率、保养成本、保险费用。
- 试驾，坐满家人试空间。

### 1.3 签约材料

- [ ] 身份证
- [ ] 驾驶证
- [ ] 银行卡
- [ ] 贷款资料（如需）
- [ ] 居住证（部分城市上牌）

## 2. 现场流程

### 2.1 谈价与签约

- 在哪：4S 店或直营店。
- 做什么：谈裸车价、赠品、保险、上牌服务费。
- 看什么：合同是否写清车型、配置、颜色、车架号。
- 完成标志：签合同，交定金。

### 2.2 付款

- 全款或贷款，保留付款凭证。
- 贷款要看清利率、手续费、提前还款条款。
- 完成标志：付款完成，拿到发票。

### 2.3 提车验车

- 在哪：交车区。
- 做什么：核对车架号、发动机号、生产日期、里程。
- 看什么：漆面、轮胎、玻璃、内饰、随车工具。
- 完成标志：验车无误，签交车单。

### 2.4 买保险

- 交强险必买。
- 商业险：三者险、车损险、座位险、医保外用药责任险。
- 完成标志：保单生效。

### 2.5 缴税与上牌

- 缴纳车辆购置税。
- 到车管所验车、选号、上牌。
- 完成标志：拿到行驶证和号牌。

### 2.6 后续

- 贴膜、脚垫、行车记录仪按需。
- 首保按手册。
- 完成标志：正常使用。

## 3. 常见问题

### Q1 落地价怎么算？
答：裸车价 + 购置税 + 保险 + 上牌费 + 装饰。贷款还要算利息和手续费。

### Q2 购置税多少？
答：燃油车按不含税价的 10%，大约裸车价除以 11.3。新能源按现行减免政策。[1]

### Q3 定金能退吗？
答：合同写“定金”通常不退，“订金”可退。签字前看清。

### Q4 提车要看什么？
答：生产日期（避免库存车）、里程（通常 50 公里内）、漆面、轮胎、玻璃、手续。

### Q5 库存车能买吗？
答：可以，但要有更大优惠，检查电瓶、轮胎、油液和保修起算时间。

### Q6 保险怎么买？
答：交强险必买，商业险至少三者险 200 万元以上、车损险。按用车环境加座位险、医保外用药责任险。

### Q7 新能源车值得买吗？
答：看充电条件、通勤距离和用车成本。没有固定车位充电要谨慎。

### Q8 贷款买车划算吗？
答：看利率和手续费，有些“零利率”收高额手续费。算总成本再决定。

### Q9 上牌要什么材料？
答：身份证、购车发票、合格证、交强险保单、购置税完税证明，部分城市要居住证。

### Q10 三包包括什么？
答：修理、更换、退货。具体期限和条件按《家用汽车产品修理更换退货责任规定》。[2]

## 4. 避坑提醒

- **只看裸车价**：落地价可能高几万。
- **合同不写配置**：提车发现减配。
- **不写交车日期**：无限期等待。
- **库存车当新车**：看生产日期。
- **强制店内保险**：可谈，但贷款车可能有要求。
- **低配加装冒充高配**：核对配置表。
- **贷款手续费**：算进总成本。
- **不拿合格证**：上牌要用，被抵押很麻烦。

## 5. 特殊情况与应急

- **提车发现质量问题**：拒绝签字，要求换车或书面承诺修复。
- **合格证被抵押**：要求经销商限期赎回，向厂家和市场监管投诉。
- **车辆故障**：按三包规定维修、换车或退车。
- **交通事故**：报交警和保险，保留现场照片。
- **被强制消费**：保留证据，拨 12315 投诉。
- **上牌被拒**：核对材料，问清原因，补办。

## 6. 费用与时间预算

| 项目 | 大概金额 | 说明 |
| --- | --- | --- |
| 裸车 | 几万到几十万元 | 按车型 |
| 购置税 | 车价的 8%–10% | 新能源有减免 |
| 保险 | 4000–8000 元/年 | 首年 |
| 上牌 | 几百元 | 必选 |
| 时间 | 1–3 天 | 提车到上牌 |
