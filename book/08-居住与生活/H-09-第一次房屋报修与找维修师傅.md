# 第一次房屋报修与找维修师傅

> **一句话**：先分清是谁的责任——屋内设备找品牌官方售后，公共区域找物业，租房先叫房东修；搜出来的 400 电话六成有假。
> **适用**：家里第一次遇到跳闸、漏水、堵塞、门锁故障，要找人修的人。
> **不适用**：装修改造看 H-03；燃气泄漏等危险情况先关阀开窗、打燃气公司抢修电话。

## 0. 30 秒速查

- **跳闸**：先看配电箱哪路跳了，拔掉该路电器再合闸；反复跳的别硬合。
- **漏水**：先关总阀，判断来水方向（自家/楼上/公共管道），楼上和公共的分别找人。
- **家电坏**：官方售后电话看产品说明书或品牌官网，别信搜索引擎里的 400。
- **租房**：房东有维修义务，先通知房东；不修的可自行维修后要求房东承担费用。
- **公共区域**：电梯、外墙、公共管道归物业管，打物业报修电话并要工单号。
- **修完留凭证**：报价单、付款记录、更换配件照片，纠纷时都是证据。

## 1. 准备事项

### 1.1 平时备好的信息

- [ ] 物业报修电话和 24 小时值班电话，存手机。
- [ ] 水、电、燃气公司客服和抢修电话，贴冰箱上。
- [ ] 家电说明书留好——官方售后电话印在上面；找不到的去品牌官网查。
- [ ] 知道自家水表、电闸、燃气阀在哪，怎么关。
- [ ] 住房是租的：房东电话和租赁合同里维修条款的位置。

### 1.2 故障发生后先自查（能省一次上门费）

- [ ] 跳闸：拔掉跳闸回路的电器再合闸；能合上就是电器问题，合不上是线路问题，别反复试。
- [ ] 漏水：关总阀后擦干地面，观察水从顶面、墙面还是地面来；楼下漏你家的你也是责任人。
- [ ] 马桶堵：皮搋子先试；水箱不进水看角阀是否关了。
- [ ] 门锁打不开：换电池/充电再试；机械钥匙孔反锁的别硬拧。

### 1.3 叫师傅前问清三件事

- [ ] 上门费多少、检测费多少、修不修都收吗。
- [ ] 大概报价区间，配件怎么算钱。
- [ ] 能否出报价单和收据，保修多久。

## 2. 现场流程

### 2.1 判断责任归谁

- 自家设备（家电、家具、户内水管电路）：自己找品牌售后或维修平台。
- 公共部分（电梯、楼道灯、外墙、主管道、屋面）：物业报修，属共有部分的大修走住宅专项维修资金。
- 楼上邻居责任（他家漏到你家）：先协商，物业可协助联系，不成的走侵权索赔。
- 租的房子：通知房东修，属于房屋和固有设施的维修由出租人负责。

### 2.2 找到正规维修渠道

- 品牌家电：按说明书或官网电话约官方售后，报产品型号和故障描述。
- 通用维修：物业推荐的驻点师傅、连锁家政维修平台，比搜索来的电话可靠。
- 搜索引擎的「400 官方售后」要核实：媒体实测搜索结果六成是假冒号码，报修前打品牌官网公布的客服核实。

### 2.3 上门维修当天

- 做什么：当面描述故障和发生时间；师傅检测后先出报价，确认再修。
- 看什么：更换的配件是不是新品、旧件留不留；拆装过程拍照。
- 说清楚：报价之外不加钱，加钱项目必须事先说明并同意。
- 完成标志：当面验收功能正常，拿报价单/收据，记下保修期。

### 2.4 报修物业（公共部分）

- 打电话报修并要工单号，App 报修的截图留底。
- 约定上门时间，维修后当面验收并在工单上确认。
- 不处理的：凭记录向业委会反映或向住建部门投诉物业。

## 3. 常见问题

### Q1 上门费和维修费怎么算才合理？
答：行情是上门费几十元（修不修都收或检测后抵扣），维修费按项目收。明显高出市场价数倍的报价，当面拒修换人，只付上门费。

### Q2 怎么辨别山寨售后？
答：三个来源最可靠——产品说明书、品牌官网、品牌官方 App。搜索引擎排名靠前的 400 电话不可信，假冒者花钱就能排到官网前面。

### Q3 师傅说「整个部件都得换」怎么办？
答：要求先报价并说明为什么不能修只能换；不放心就说考虑一下，再找官方售后复核。别怕麻烦，差价常在数倍。

### Q4 租的房子坏了，房东拖着不修？
答：书面（微信文字也行）通知房东并给合理期限；仍不修的可自行维修，凭票据要求房东承担费用，依据是民法典第七百一十三条。

### Q5 维修影响使用了能减租吗？
答：因维修影响正常使用的，可以和房东协商相应减少租金或延长租期，写进沟通记录。

### Q6 楼上漏水他家不配合怎么办？
答：先请物业到场查看留记录，明确漏点在他家侧的，物业和社区协调；仍不配合的凭维修票据和鉴定起诉索赔。

### Q7 修完几天又坏了怎么办？
答：凭保修承诺免费返修；口头承诺的按行业惯例主张，书面报价单上写了保修期的最有底气。

### Q8 配件被换走旧件怎么办？
答：旧件你有权留存，换之前说好。旧件也是后续判断维修是否合理的证据。

### Q9 深夜水管爆了找谁？
答：先关总阀止损；公共管道打物业 24 小时值班电话；表前供水问题打自来水公司抢修电话。

### Q10 燃气灶打不着火、闻到燃气味怎么办？
答：闻到异味先关阀、开窗、不动电器开关，撤离后打燃气公司抢修电话；打不着火没异味的可约师傅，但燃气问题优先找燃气公司。

### Q11 找平台师傅和街边店哪个好？
答：平台有订单记录、评价和赔付通道，出问题有抓手；街边店靠熟人推荐，价格可能便宜但维权靠脸。生人第一次合作优先平台。

### Q12 维修费能开发票吗？
答：可以要求。正规经营者应提供收据或发票，开不出来的本身就是一个信号。

## 4. 避坑提醒

- **搜索引擎直接打 400 报修**：假冒官方售后重灾区。售后电话认说明书和官网。
- **电话里不说价就让人上门**：上门费白付。电话里先问清收费结构。
- **「师傅」主动上门推销**：楼道贴的小广告、主动敲门的检测多为套路，一律拒绝。
- **不确认报价就动手修**：修完开天价你没得选。先报价、确认、再修。
- **公共故障自己掏钱修**：主管道、外墙渗漏属公共维修范畴，走物业和维修资金，别自己买单。
- **租房自己先修了再说**：不经通知自己修，费用可能扯皮。先书面通知房东。
- **旧件让师傅带走**：死无对证。旧件留下拍照。

## 5. 特殊情况与应急

- **漏水殃及楼下**：第一步关阀止损、通知楼下住户和物业，现场拍照，定责后按责任分担维修，态度积极能省诉讼。
- **整栋楼停电**：第一步问邻居是否普遍停电，普遍的找物业或供电公司，只你一家跳闸的查自家电路。
- **门锁深夜故障被锁门外**：第一步联系物业值班或开锁公司（公安备案的），开锁后换锁芯并留票据；租房的同步通知房东。
- **维修收费扯皮**：第一步拿报价单和聊天记录，平台单找平台客服，线下店打 12315 投诉。
- **师傅上门出安全问题**：第一时间报警；通过平台约的同步报平台，保留现场记录。

## 6. 费用与时间预算

| 项目 | 大概金额 | 说明 |
| --- | --- | --- |
| 上门/检测费 | 30–100 元 | 部分抵扣进维修费 |
| 小修（疏通、换件） | 50–300 元 | 视项目 |
| 线路/管道检修 | 100–500 元 | 复杂故障上探 |
| 物业公共维修 | 0 元（物业费/维修资金） | 公共部分不另付费 |
| 品牌保修期内维修 | 0 元 | 保内非人为故障免费 |
| 时间 | 半天 | 上门等待为主 |
