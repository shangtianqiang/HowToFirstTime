# A-01 坐飞机 · 行前清单

> 打印后勾选。依据见 [A-01 正文](../book/01-出行与交通/A-01-第一次坐飞机.md)。

## 买票与确认

- [ ] 在航司官网、官方 App 或正规票务平台买票，付款前看完退票、改签规则；需要报销的填好发票信息
- [ ] 填写的姓名、证件号和证件一致，错了可能登不了机
- [ ] 确认航班号、起飞时间、出发航站楼
- [ ] 确认身份证或护照在有效期内，且与购票证件一致
- [ ] 中转票留足转机时间：前一段延误，后一段可能赶不上

## 行李与禁带

- [ ] 确认免费托运行李额和随身行李尺寸，按所乘航司的运输总条件，不套用别家的数字
- [ ] 充电宝只能随身、不能托运：100Wh 以内、标识清楚才能带
- [ ] 100–160Wh 的充电宝要经航司批准，每人限 2 块；超过 160Wh 不能带
- [ ] 无 3C 标识、标识不清、被召回批次的充电宝不能带
- [ ] 液体不能随身：自用化妆品每种 1 件、容器不超过 100mL，要开瓶检查；牙膏、剃须膏不超过 100g 或 100mL
- [ ] 超过 100mL 的液体和喷雾放托运行李；打火机、火柴、刀具不能随身

## 出发前一天

- [ ] 网上值机一般在起飞前一天左右开放，值机后保存电子登机牌或二维码
- [ ] 有托运行李的，到机场还要去柜台或自助托运柜台
- [ ] 查值机截止时间：常见起飞前 30–45 分钟；登机口一般起飞前 15 分钟关闭，以航司公告为准
- [ ] 打包随身行李，证件放在随手可取的位置
- [ ] 确认机场天气和交通；自驾先查停车楼位置和收费标准

## 出门前

- [ ] 身份证或护照（购票时用的那件）
- [ ] 手机和充电宝
- [ ] 登机牌或值机二维码
- [ ] 国内航班通常提前 2 小时到机场，节假日和早晚高峰再多留时间

## 到机场后

- [ ] 看出发大屏确认航站楼和值机区；走错航站楼找摆渡车或问工作人员
- [ ] 办理值机、托运行李，拿好登机牌和行李票
- [ ] 过安检：电脑、平板、充电宝单独拿出；被拦下的禁带物品可托运、自弃或暂存，暂存一般不超过 30 天
- [ ] 按登机牌找到登机口，候机时盯大屏、听广播，登机口可能临时变更
- [ ] 不把钱和证件交给机场代办或“热心人”，只找穿制服的工作人员
- [ ] 按时登机，对号入座，系好安全带

## 落地与出问题找谁

- [ ] 落地后看大屏找行李转盘，核对行李牌编号再拿行李
- [ ] 误机：找航司柜台，承运人原因可免费变更或退票
- [ ] 航班延误或取消：承运人原因可要求餐食住宿，天气等原因费用自理
- [ ] 行李丢失或损坏：当场去行李查询柜台登记，损坏 7 日内、延误 21 日内提出异议
- [ ] 耳朵疼：吞咽、咀嚼、打哈欠，持续不缓解落地后看医生；严重不适拨 120
- [ ] 投诉：先找航司或机场，不满意再打 12326
