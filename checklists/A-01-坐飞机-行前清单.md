# A-01 坐飞机 · 行前清单

> 打印后勾选。依据见 [A-01 正文](../book/01-出行与交通/A-01-第一次坐飞机.md)。

## 出发前 7 天

- [ ] 确认航班号、起飞时间、出发航站楼
- [ ] 确认身份证或护照在有效期内，且与购票证件一致
- [ ] 确认免费托运行李额和随身行李尺寸
- [ ] 确认是否需要提前买行李额或选座
- [ ] 规划去机场的交通和出发时间

## 出发前 24 小时

- [ ] 网上值机（如支持）
- [ ] 检查充电宝：有 3C 标识、标识清楚、额定能量不超过 100Wh
- [ ] 把超过 100mL 的液体、刀具、打火机放进托运行李或留在家里
- [ ] 打包随身行李，证件放在随手可取的位置
- [ ] 确认机场天气和交通状况

## 出门前

- [ ] 身份证或护照
- [ ] 手机和充电宝
- [ ] 登机牌或值机二维码
- [ ] 行李标签和联系方式
- [ ] 国内航班通常提前 2 小时到机场，节假日再多留时间

## 到机场后

- [ ] 找到正确的航站楼和出发层
- [ ] 办理值机、托运行李
- [ ] 过安检：电脑、平板、充电宝单独拿出
- [ ] 找到登机口，留意大屏和广播
- [ ] 按时登机，对号入座

## 出问题找谁

- [ ] 误机：找航司柜台，承运人原因可免费变更或退票
- [ ] 航班延误或取消：承运人原因可要求餐食住宿
- [ ] 行李丢失或损坏：去行李查询柜台，损坏 7 日内、延误 21 日内提出
- [ ] 安检不通过：禁带物品可托运、自弃或暂存
- [ ] 投诉：先找航司或机场，不满意再打 12326
