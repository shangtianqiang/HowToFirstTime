# A-02 坐高铁 · 行前清单

> 打印后勾选。依据见 [A-02 正文](../book/01-出行与交通/A-02-第一次坐高铁.md)。

## 买票前

- [ ] 在 12306 注册并完成实名认证，身份核验“已通过”才能订票
- [ ] 学生先做优惠资质核验：每学年 4 次单程，普速硬座 50%、动车二等座 75%
- [ ] 选好车次、日期和席别，票价随时段和余票浮动，以 12306 显示为准
- [ ] 看清退票费：开车前 8 天以上免费，48 小时到 8 天收 5%，24 到 48 小时收 10%，24 小时以内收 20%、最低 2 元
- [ ] 改签：开车前 48 小时以上改到哪天都免费；开车后改签的车票不能再退
- [ ] 售罄提交 12306 候补（最多 6 个待兑现订单），截止兑现不晚于开车前 20 分钟；别买第三方加速包

## 行李与禁带

- [ ] 确认免费携带行李的重量和尺寸，以车站和 12306 公告为准
- [ ] 充电宝、锂电池单块不超过 100Wh，标志要清楚
- [ ] 普通打火机不超过 2 个，安全火柴不超过 2 小盒
- [ ] 白酒 24%–70%、包装密封可带，累计不超过 3000mL；超过 70% 或标志不清不能带
- [ ] 烟花爆竹、管制刀具、易燃易爆品不能带

## 出发前

- [ ] 确认车次、发车时间和车站，规划去车站的交通
- [ ] 多数车站建议至少提前 30 分钟到；动车组一般开车前 3 分钟停止检票
- [ ] 检票口可能临时变更，候车时留意大屏和广播
- [ ] 给手机充电，身份证放在随手可取的位置
- [ ] 大件行李放行李架或车厢连接处，不堵过道

## 出门前

- [ ] 身份证（购票用的那件）
- [ ] 手机和充电宝
- [ ] 车票信息或 12306 订单，电子客票直接刷身份证进站
- [ ] 身份证消磁、过期：到车站公安制证窗口办临时乘车证明
- [ ] 别把证件和钱交给车站外拉客、“代取票”的陌生人

## 进站上车

- [ ] 进站验证：身份证放闸机刷脸，核验不过走人工通道
- [ ] 过安检：充电宝、液体提前拿出来
- [ ] 按车次找到检票口，看大屏确认检票状态和站台号
- [ ] 刷证或扫码检票，下站台前看清站台号和地标颜色，别走错方向
- [ ] 按票面车厢号上车，对号入座，行李放稳

## 出问题找谁

- [ ] 没赶上车：开车后当日 24 时前，免费改签当日其他列车
- [ ] 坐过站：马上找列车员或列车长，不要出站；出站后再提出车站不受理
- [ ] 中转换乘来不及：找站台工作人员走站内换乘通道；因铁路原因影响换乘，退票不收费
- [ ] 遗失物品：12306 App 登记或拨 12306，车站保管，凭身份证领取
- [ ] 列车晚点：看 12306 和车站广播
