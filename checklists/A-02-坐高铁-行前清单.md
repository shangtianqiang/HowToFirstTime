# A-02 坐高铁 · 行前清单

> 打印后勾选。依据见 [A-02 正文](../book/01-出行与交通/A-02-第一次坐高铁.md)。

## 出发前 7 天

- [ ] 在 12306 完成注册和实名认证，核验结果“已通过”
- [ ] 选好车次、日期和席别
- [ ] 确认票价和退改规则
- [ ] 确认免费携带行李的重量和尺寸
- [ ] 检查哪些物品不能带

## 出发前 24 小时

- [ ] 确认车次、发车时间和车站
- [ ] 确认检票口和候车区域
- [ ] 规划去车站的交通和出发时间
- [ ] 给手机充电，准备身份证

## 出门前

- [ ] 身份证
- [ ] 手机和充电宝
- [ ] 车票信息或 12306 订单
- [ ] 行李，确认不超重、不超尺寸
- [ ] 多数车站建议至少提前 30 分钟到站

## 到车站后

- [ ] 进站验证
- [ ] 过安检
- [ ] 找到检票口
- [ ] 检票进站台
- [ ] 找车厢和座位

## 出问题找谁

- [ ] 没赶上车：开车后当日 24 时前，免费改签当日其他列车
- [ ] 坐过站：找列车员，出站后不受理
- [ ] 遗失物品：12306 登记或拨 12306
- [ ] 列车晚点：看 12306 和车站广播
- [ ] 中转换乘来不及：找站台工作人员
