# A-03 坐火车 · 行前清单

> 打印后勾选。依据见 [A-03 正文](../book/01-出行与交通/A-03-第一次坐火车.md)。

## 买票前

- [ ] 认车次字母：K 快速、T 特快、Z 直达特快，以 12306 显示为准
- [ ] 选席别：硬座最便宜；硬卧下铺方便、中上铺便宜、上铺最安静；软卧是包间
- [ ] 查起售时间，各车站不一样，12306 可查；售罄提交候补，截止兑现不晚于开车前 20 分钟
- [ ] 学生票每学年 4 次单程，先做优惠资质核验
- [ ] 无座票没有固定座位，长途很累，能买卧铺就别省这个钱

## 行李与夜车准备

- [ ] 充电宝单块不超过 100Wh，标志要清楚
- [ ] 打火机不超过 2 个；白酒 24%–70% 累计不超过 3000mL
- [ ] 带外套、颈枕、耳塞、洗漱用品，夜里车厢可能冷
- [ ] 食物和水提前买好，餐车不是每趟都有
- [ ] 充电宝充满电，卧铺车厢的插座数量有限
- [ ] 贵重物品放贴身包，不放行李架
- [ ] 大件行李放行李架或车厢连接处，不堵过道
- [ ] 老人、孕妇、轮椅旅客提前预约重点旅客服务

## 出门前

- [ ] 身份证，有问题去车站公安制证窗口
- [ ] 车票信息或 12306 订单
- [ ] 多数车站建议至少提前 30 分钟到，普速列车一般开车前 5 分钟停止检票
- [ ] 老车站的进站口、天桥、地道可能绕，预留更多时间
- [ ] 贵重物品贴身放，上下车清点行李件数

## 进站上车

- [ ] 进站刷身份证验证，核验不过走人工通道
- [ ] 过安检：充电宝、液体提前拿出来
- [ ] 留意检票广播，刷证或扫码检票，看清站台号再下站台
- [ ] 按车厢号和铺位号上车入座，上铺不方便可问列车员能不能换

## 途中

- [ ] 夜间停站听清站名，别跟着人流下错车；怕睡过头定闹钟或请列车员到站前提醒
- [ ] 停站下车活动别走远；长途每隔一段时间起身活动
- [ ] 不把孩子和贵重物品交给陌生人帮看；车上推销不需要就拒绝
- [ ] 补票、越站在原到站前找列车员；到站不下车继续乘车的，加收已乘区间应补票款的 50%

## 出问题找谁

- [ ] 坐过站：马上找列车员，不要出站；列车长编记录，前方站免费送回
- [ ] 漏乘：开车后当日 24 时前，免费改签当日其他列车
- [ ] 遗失物品：12306 登记或拨 12306，凭身份证领取
- [ ] 身体不适：找列车员，必要时在最近停靠站下车就医
- [ ] 遇盗抢：找列车员或乘警
