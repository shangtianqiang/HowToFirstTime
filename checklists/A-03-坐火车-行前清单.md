# A-03 坐火车 · 行前清单

> 打印后勾选。依据见 [A-03 正文](../book/01-出行与交通/A-03-第一次坐火车.md)。

## 出发前 7 天

- [ ] 确认车次字母、发车时间和车站
- [ ] 选好席别：硬座、硬卧、软卧或无座
- [ ] 确认票价和退改规则
- [ ] 确认起售时间，必要时用候补
- [ ] 查清哪些物品不能带

## 出发前 24 小时

- [ ] 确认车站和进站口
- [ ] 规划去车站的交通和出发时间
- [ ] 准备夜车用品：颈枕、耳塞、洗漱用品、外套
- [ ] 准备食物和饮用水
- [ ] 给手机和充电宝充电

## 出门前

- [ ] 身份证
- [ ] 车票信息或 12306 订单
- [ ] 行李，贵重物品随身放
- [ ] 外套，夜车可能冷
- [ ] 多数车站建议至少提前 30 分钟到站

## 到车站后

- [ ] 进站验证
- [ ] 过安检
- [ ] 候车，留意检票广播
- [ ] 检票上车
- [ ] 找座位或铺位

## 出问题找谁

- [ ] 坐过站：找列车员，列车长编记录，前方站免费送回
- [ ] 漏乘：开车后当日 24 时前，免费改签当日其他列车
- [ ] 需要补票：在原到站前找列车员
- [ ] 遗失物品：12306 登记或拨 12306
- [ ] 身体不适：找列车员，必要时在最近停靠站下车就医
