# A-04 第一次坐地铁 · 清单

> 打印后勾选。依据见 [A-04 正文](../book/01-出行与交通/A-04-第一次坐地铁.md)。

## 出门前

- [ ] 查好线路、换乘站和目的出口编号
- [ ] 查首末班车时间
- [ ] 开通乘车码或确认交通卡余额
- [ ] 手机充满电，必要时带充电宝
- [ ] 确认随身包没有禁限物品

## 进站

- [ ] 按出口编号找到入口
- [ ] 包过安检，人过安检门
- [ ] 买票或扫码进闸，闸门开了再走
- [ ] 看屏蔽门上的终点站名确认方向

## 乘车

- [ ] 站在黄线内，先下后上
- [ ] 扶好站稳，听报站
- [ ] 换乘跟“换乘”标识，不出闸
- [ ] 提前一站往车门移动

## 出站

- [ ] 单程票投入回收口，或扫码、刷卡出闸
- [ ] 按出口编号上到地面
- [ ] 确认随身物品都带齐

## 出问题找谁

- [ ] 闸机不开、票卡失效：找客服中心，按对讲按钮
- [ ] 坐过站：站内到对面坐回去，不出闸
- [ ] 物品遗失：找站台工作人员登记，拨运营方热线
- [ ] 身体不适：下车找工作人员，必要时拨 120
