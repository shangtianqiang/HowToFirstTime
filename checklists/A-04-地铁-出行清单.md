# A-04 第一次坐地铁 · 清单

> 打印后勾选。依据见 [A-04 正文](../book/01-出行与交通/A-04-第一次坐地铁.md)。

## 出门前

- [ ] 用地图 App 查线路：从哪站进、在哪换乘、从哪个出口出
- [ ] 查首末班车时间；赶末班车留出换乘时间，末班车通常不保证换乘
- [ ] 开通乘车码并进站前先打开，或确认交通卡余额；备少量现金防扫码失败
- [ ] 查车站公告：有没有大小交路（区间车）、出入口封闭施工
- [ ] 确认随身包没有易燃易爆、管制刀具等禁限物品

## 进站

- [ ] 按出口编号找到入口，包过安检、人过安检门
- [ ] 单程票在售票机买，支持现金或扫码；带儿童过闸走宽闸机或人工通道
- [ ] 多数城市身高 1.3 米以下儿童免票，以当地运营方公示为准
- [ ] 乘车码对准扫码区、交通卡贴感应区，闸门开了再走
- [ ] 闸机不开找客服中心或按对讲按钮，不翻越、不钻闸、不尾随过闸

## 乘车与换乘

- [ ] 看屏蔽门上的终点站名确认方向，别只看线路颜色——同一条线可能有区间车
- [ ] 站在黄线内候车，先下后上不挡门；挤不上等下一趟
- [ ] 扶好站稳，听报站，提前一站往车门移动
- [ ] 换乘跟“换乘”标识走，不出闸；出闸再进要重新计费
- [ ] 车厢内不饮食，多数城市有规定

## 出站

- [ ] 单程票投入回收口，或扫码、刷卡出闸
- [ ] 票卡失效、余额不足或单程票弄丢：去客服中心补票或处理
- [ ] 按出口编号上到地面
- [ ] 确认随身物品都带齐

## 出问题找谁

- [ ] 坐过站或坐反方向：不出闸，站内换到对面站台坐回去，不重新计费
- [ ] 手机没电、扫码失败：找客服中心说明从哪站进站，按指引补票
- [ ] 物品遗失：记住车厢编号、车门编号和大概时间，找站台工作人员登记，拨运营方热线
- [ ] 身体不适：立即下车找工作人员，多数车站有急救箱，必要时拨 120
- [ ] 大客流或临时封站：听广播和工作人员指挥，从指定出口疏散
