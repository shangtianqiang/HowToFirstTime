# A-05 第一次坐长途大巴 · 清单

> 打印后勾选。依据见 [A-05 正文](../book/01-出行与交通/A-05-第一次坐长途大巴.md)。

## 买票前

- [ ] 查班次：出发站、到达站、发车时间、运行时长和票价
- [ ] 在正规客运站窗口、售票机或官方平台实名购票，看清退改规则
- [ ] 对比同线路高铁、火车，可能更快，价格未必更贵
- [ ] 查天气和路况，雨雪雾天可能停运，出发前打客运站电话确认
- [ ] 长途夜车选卧铺或航空座椅，问清是否配安全带

## 出发前

- [ ] 确认发车站是哪一个，大城市有多个客运站，别跑错
- [ ] 发车时间以车站公告为准，购票短信上的时间可能因调度调整
- [ ] 带身份证，儿童带证件或户口簿
- [ ] 提前 30 分钟到站，节假日留 1 小时
- [ ] 晕车药提前半小时吃，选前排靠窗座位；备水、纸巾和外套，车上空调可能偏冷
- [ ] 手机存好客运站电话，把车次和车牌发给家人

## 进站上车

- [ ] 出示身份证和车票，行李过安检
- [ ] 看候车厅大屏找检票口，发车前 10–20 分钟检票
- [ ] 上车前核对车牌和线路牌，和车票信息不一致就下车
- [ ] 站外揽客不上车：没有安检、保险和票据，出了事故难维权
- [ ] 按座位号上车，大件行李放行李舱，贵重物品随身

## 车上

- [ ] 全程系安全带，包括后排
- [ ] 记下随车电话和车牌号
- [ ] 留意是否超员（过道加座、行李堆到门口）和司机危险驾驶
- [ ] 中途停靠看好行李，贵重物品贴身放
- [ ] 车上有人推销药品、特产，不买

## 出问题找谁

- [ ] 跑错站：立刻联系购票平台改签或退票，打车去正确车站，保留打车票
- [ ] 错过班次：到服务台问改签下一班，通常收手续费
- [ ] 车晚点、停运：看车站公告，到服务台问退改；天气原因停运通常全额退票
- [ ] 超员、危险驾驶：记下车牌、时间、路段，拨 12328 举报
- [ ] 事故：听司机指挥下车到护栏外，拨 122、120，保留车票和现场照片
- [ ] 行李丢失或拿错：联系司机和客运站调度，登记特征，必要时报警
- [ ] 身体不适：告诉司机就近服务区停车，严重时拨 120
