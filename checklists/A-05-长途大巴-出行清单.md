# A-05 第一次坐长途大巴 · 清单

> 打印后勾选。依据见 [A-05 正文](../book/01-出行与交通/A-05-第一次坐长途大巴.md)。

## 买票前

- [ ] 确认出发客运站名称和地址
- [ ] 对比高铁、火车、大巴的时间和价格
- [ ] 通过官方渠道实名购票
- [ ] 看清退改规则
- [ ] 查天气和路况

## 出发前

- [ ] 带身份证，儿童带证件或户口簿
- [ ] 提前 30 分钟到站，节假日留 1 小时
- [ ] 大件行李打包，贵重物品随身
- [ ] 准备晕车药、水、外套
- [ ] 把车次和车牌发给家人

## 上车后

- [ ] 核对车牌和线路牌
- [ ] 系好安全带
- [ ] 记下随车电话
- [ ] 观察是否超员、司机是否危险驾驶
- [ ] 中途停靠看好行李

## 出问题找谁

- [ ] 跑错站：联系购票平台改签，打车去正确车站
- [ ] 车晚点、停运：到服务台问退改
- [ ] 超员、危险驾驶：拨 12328 举报
- [ ] 事故：拨 122、120，保留车票和照片
