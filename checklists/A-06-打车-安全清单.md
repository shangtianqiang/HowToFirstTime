# A-06 第一次打网约车/出租车 · 清单

> 打印后勾选。依据见 [A-06 正文](../book/01-出行与交通/A-06-第一次打网约车与出租车.md)。

## 叫车前

- [ ] 用官方 App，不装陌生来源的软件
- [ ] 设置紧急联系人
- [ ] 选有明显标志的上车点
- [ ] 看预估价格和路线
- [ ] 深夜把车牌和预计到达时间发给家人

## 上车前

- [ ] 车牌一致
- [ ] 车型、颜色一致
- [ ] 司机姓名、头像一致
- [ ] 平台显示已接单
- [ ] 任何一项不符，取消并举报

## 车上

- [ ] 坐后排，系安全带
- [ ] 确认目的地和路线
- [ ] 打开行程分享
- [ ] 留意是否绕路
- [ ] 不透露独居、独行信息

## 下车

- [ ] 确认账单明细
- [ ] 支付并索要发票
- [ ] 检查手机、钥匙、包
- [ ] 有异议先支付再申诉

## 出问题找谁

- [ ] 人车不符：取消订单，平台举报
- [ ] 绕路、乱收费：平台申诉，拨 12328
- [ ] 骚扰、威胁：下车到人多处，拨 110
- [ ] 事故：拨 122、120，拍照留证
