# A-06 第一次打网约车/出租车 · 清单

> 打印后勾选。依据见 [A-06 正文](../book/01-出行与交通/A-06-第一次打网约车与出租车.md)。

## 叫车前

- [ ] 用应用商店的官方 App，不装陌生链接、二维码来的“打车软件”
- [ ] 完成实名认证、绑定支付方式，设置紧急联系人
- [ ] 选有明显标志的上车点，避免司机找不到或上错车
- [ ] 看预估价格和路线，心里有数
- [ ] 备少量现金或充电宝，防手机没电无法支付

## 上车前

- [ ] 车牌号、车型、颜色和 App 显示一致
- [ ] 司机姓名、头像一致，平台显示“已接单”而不是私下揽客
- [ ] 任何一项不符：不上车，取消订单并在平台举报，必要时拨 12328
- [ ] 拦出租车在候客点或允许停车的路段，不在机动车道、路口、斑马线上拦
- [ ] 上车前看车身标识、顶灯、车牌，确认是正规巡游出租车
- [ ] 车站、机场出口的“包车”“拼车”多为黑车，不坐

## 车上

- [ ] 坐后排右侧，系安全带
- [ ] 再次确认目的地，要求按导航走
- [ ] 出租车要求打表；不打表、议价的可下车换一辆
- [ ] 打开行程分享，深夜尤其要做
- [ ] 留意路线是否明显偏离、司机是否频繁接打电话
- [ ] 不透露独居、独行信息；不扫陌生人给的领券二维码

## 下车与支付

- [ ] 过路费、停车费通常由乘客承担，上车前问清
- [ ] 下车前核对账单明细，看有没有不明附加费
- [ ] 支付并索要发票，丢东西、投诉、报销都要凭证
- [ ] 检查手机、钥匙、包，后排和脚下都看一眼
- [ ] 对费用有异议：先支付再平台申诉，不现场争执

## 出问题找谁

- [ ] 人车不符：取消订单，平台举报“人车不符”，必要时拨 12328
- [ ] 绕路、乱收费：当场指出，保留行程记录和账单，平台申诉，不成拨 12328 或 12345
- [ ] 骚扰、威胁：要求靠边停车，下车到人多处，拨 110，并平台投诉
- [ ] 事故：先确认人身安全，拨 122、120，拍照留证，联系平台
- [ ] 东西落在车上：App“失物招领”联系司机；出租车凭发票上的车牌号联系公司
- [ ] 出租车拒载：记下车牌、时间、地点，拨 12328 投诉
