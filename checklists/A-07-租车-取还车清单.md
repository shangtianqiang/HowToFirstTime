# A-07 第一次租车自驾 · 清单

> 打印后勾选。依据见 [A-07 正文](../book/01-出行与交通/A-07-第一次租车自驾.md)。

## 订车

- [ ] 比较平台、车型和取还车点
- [ ] 看清押金、免赔额、里程限制
- [ ] 确认异地还车费
- [ ] 确认门店营业时间
- [ ] 查目的地限行政策

## 取车

- [ ] 带身份证、驾驶证、信用卡
- [ ] 绕车拍照录像
- [ ] 记录划痕、凹陷、轮胎
- [ ] 拍油量、里程、仪表盘
- [ ] 确认备胎、三角牌、灭火器
- [ ] 验车单双方签字

## 上路

- [ ] 调整座椅和后视镜
- [ ] 试刹车、灯光
- [ ] 系安全带
- [ ] 看仪表警示灯
- [ ] 车辆异常立即联系门店换车

## 还车

- [ ] 加满油或按合同油量
- [ ] 清理垃圾
- [ ] 带齐随车物品
- [ ] 核对还车验车单
- [ ] 保留取车照片和合同

## 出问题找谁

- [ ] 事故：拨 122、120，报保险和门店
- [ ] 故障：靠边、双闪、三角牌，联系救援
- [ ] 押金纠纷：平台投诉或拨 12315
- [ ] 违章：按合同处理，保留凭证
