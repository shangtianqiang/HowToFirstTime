# A-07 第一次租车自驾 · 清单

> 打印后勾选。依据见 [A-07 正文](../book/01-出行与交通/A-07-第一次租车自驾.md)。

## 订车

- [ ] 同一车型多平台、多取车点比价；低价订单可能不含基础保险，或里程限制很严
- [ ] 看清合同：押金、免赔额、里程限制、异地还车费、提前还车规则
- [ ] 免赔额高就加购不计免赔，先算一笔账
- [ ] 确认驾龄要求：多数公司要求满 1 年，部分车型 2 年以上；部分城市对 25 岁以下加收费用
- [ ] 确认取还车点营业时间，红眼航班选 24 小时门店
- [ ] 确认是非营运车辆，不能跑网约车、货运；私人租车保险可能拒赔，选正规租赁公司
- [ ] 查目的地限行政策：外地牌照限行、进京证、景区通行证

## 取车

- [ ] 带身份证、驾驶证（正副页）、信用卡（额度够押金预授权）
- [ ] 绕车一圈拍照录像，重点拍前后保险杠、轮毂、车门、挡风玻璃
- [ ] 记录划痕、凹陷、轮胎磨损，拍油量刻度、里程数、仪表盘
- [ ] 确认备胎和工具、三角警示牌、灭火器
- [ ] 拿好钥匙、行驶证、保险单；验车单双方确认，照片带时间戳
- [ ] 把租车合同、保险单、门店电话存到手机
- [ ] 下载离线地图，查沿途加油站、充电桩分布
- [ ] 把行程和预计到达时间发给家人

## 上路

- [ ] 调整座椅和后视镜，系安全带，试刹车和灯光
- [ ] 看仪表盘警示灯、油量、胎压
- [ ] 按导航行驶，遵守限速，不疲劳驾驶；留意限行标志和施工路段
- [ ] 高原、山区驾驶：先查刹车和胎压，控制车速，不夜间赶山路
- [ ] 异响或警示灯亮：立即靠边停车，联系门店换车

## 还车

- [ ] 提前加满油再还，少油按门店价补，通常高于市场油价
- [ ] 清理垃圾，车内不吸烟，多数合同禁烟
- [ ] 带齐随车物品，核对还车验车单，确认无新增损伤
- [ ] 对损伤认定有异议：出示取车时的照片和视频
- [ ] 违章押金通常保留 30 天；取车照片和合同留到押金到账

## 出问题找谁

- [ ] 事故：先救人，拨 122、120，拍照，报保险和门店，不私了、不擅自维修
- [ ] 故障：靠边、开双闪、放三角牌，人撤到护栏外，联系门店救援，不自行找修理厂
- [ ] 车被砸、被盗：报警，保护现场，联系门店和保险
- [ ] 不把车借给他人：合同只允许登记驾驶人开，出事故保险可能不赔
- [ ] 押金纠纷：出示合同、验车照片和还车单，向平台投诉或拨 12315
