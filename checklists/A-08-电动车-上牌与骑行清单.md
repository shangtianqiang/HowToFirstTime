# A-08 第一次骑电动车上路 · 清单

> 打印后勾选。依据见 [A-08 正文](../book/01-出行与交通/A-08-第一次骑电动车上路.md)。

## 买车前

- [ ] 看合格证上的车辆类型
- [ ] 确认最高车速、功率、电压
- [ ] 确认有脚踏骑行功能
- [ ] 需要驾驶证的车型，先确认自己有没有 F 证或 E 证

## 上牌

- [ ] 身份证
- [ ] 购车发票
- [ ] 合格证
- [ ] 交强险凭证（机动车类）
- [ ] 骑车到登记点验车

## 上路前

- [ ] 3C 认证头盔，系好扣带
- [ ] 检查刹车、胎压、灯光、电量
- [ ] 夜间穿反光背心
- [ ] 不加装雨棚、挡风被
- [ ] 不解除限速

## 骑行

- [ ] 走非机动车道或靠右行驶
- [ ] 不逆行、不闯红灯
- [ ] 不载人，或按当地规定载一名儿童
- [ ] 不看手机
- [ ] 路口减速，注意右转机动车

## 充电与停放

- [ ] 停在划定区域
- [ ] 在集中充电设施充电
- [ ] 电池不进楼、不入户
- [ ] 不飞线充电
- [ ] 充电时有人看管或使用定时断电

## 出问题找谁

- [ ] 事故：先救人，拨 122、120，拍照
- [ ] 电池起火：断电撤离，拨 119
- [ ] 车辆被盗：拨 110，提供车牌和车架号
- [ ] 被查扣：配合出示牌照和证件
