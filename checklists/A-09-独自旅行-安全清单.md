# A-09 第一次独自旅行 · 清单

> 打印后勾选。依据见 [A-09 正文](../book/01-出行与交通/A-09-第一次独自旅行.md)。

## 出发前

- [ ] 定好每天住哪、去哪、怎么走，留出机动时间
- [ ] 只订有营业执照的正规酒店或民宿，不住无证小旅馆、日租房
- [ ] 买旅游意外险，看清免责条款（尤其高风险项目）和救援电话
- [ ] 查景区实名预约和限流，走官方渠道，不买黄牛票
- [ ] 存好当地 110、120、景区派出所和酒店前台电话
- [ ] 把行程、酒店地址和同行联系方式发给至少一位家人
- [ ] 约定每天报平安的时间

## 随身带

- [ ] 身份证，复印件和手机照片分开存
- [ ] 银行卡和少量现金分开放，不把所有钱放一个包
- [ ] 手机、充电宝、充电线
- [ ] 常用药、创可贴
- [ ] 酒店订单和地址截图
- [ ] 保险单和救援电话

## 住宿

- [ ] 出示身份证实名登记，确认房号、价格和退房时间
- [ ] 进房检查门锁、猫眼，看清消防通道位置
- [ ] 夜间反锁房门，不给陌生人开门
- [ ] 不把实时定位发到公开社交平台
- [ ] 退房前检查房间，别落下充电器、证件，拿好发票

## 出行

- [ ] 走正规出租车上客点，不跟揽客的人走
- [ ] 不买低价一日游，选正规旅行社并签合同
- [ ] 夜间走照明好、人多的主路，不去偏僻景区和无照明路段
- [ ] 打车坐后排，核对车牌，分享行程
- [ ] 迷路用地图 App 定位，问景区工作人员，不跟陌生人走
- [ ] 不透露独自出行信息
- [ ] 感觉被跟踪：进便利店、酒店大堂等公共场所，拨 110，不直接回住处

## 出问题找谁

- [ ] 证件丢失：报警挂失，到派出所或政务大厅办临时身份证明
- [ ] 生病受伤：拨 120，联系酒店前台协助，保留病历和发票用于保险理赔
- [ ] 被盗被抢：人身安全优先，脱险后拨 110，挂失银行卡
- [ ] 航班列车取消：联系承运方改签，保留凭证，必要时申请住宿安排
- [ ] 极端天气：听当地应急部门指挥，停止户外活动，联系家人报平安
- [ ] 其他求助：拨 12345 政务热线
