# A-09 第一次独自旅行 · 清单

> 打印后勾选。依据见 [A-09 正文](../book/01-出行与交通/A-09-第一次独自旅行.md)。

## 出发前

- [ ] 定好每天住哪、去哪、怎么走
- [ ] 只订正规酒店或民宿
- [ ] 买旅游意外险
- [ ] 查景区预约和限流
- [ ] 把行程发给家人
- [ ] 约定每天报平安时间

## 随身带

- [ ] 身份证，复印件和照片分开存
- [ ] 银行卡、少量现金
- [ ] 手机、充电宝、充电线
- [ ] 常用药
- [ ] 酒店订单和地址截图
- [ ] 保险单和救援电话

## 住宿

- [ ] 实名登记
- [ ] 检查门锁、猫眼
- [ ] 记住消防通道位置
- [ ] 不给陌生人开门
- [ ] 夜间反锁

## 出行

- [ ] 走正规出租车上客点
- [ ] 不跟揽客的人走
- [ ] 不买低价一日游
- [ ] 夜间走主路
- [ ] 感觉被跟踪进公共场所并拨 110

## 出问题找谁

- [ ] 证件丢失：报警挂失，办临时身份证明
- [ ] 生病受伤：拨 120，联系酒店协助
- [ ] 被盗被抢：拨 110，挂失银行卡
- [ ] 航班列车取消：联系承运方改签
