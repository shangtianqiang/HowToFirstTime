# A-10 第一次春运回家 · 清单

> 打印后勾选。依据见 [A-10 正文](../book/01-出行与交通/A-10-第一次春运回家.md)。

## 提前准备

- [ ] 12306 注册实名认证，乘车人身份核验通过
- [ ] 学生完成优惠资质核验，按优惠区间购票，超出区间要补票
- [ ] 查春运起止日期（通常 40 天），查起售时间并定闹钟
- [ ] 列 3 个备选车次
- [ ] 准备中转、邻站、飞机、大巴备选方案
- [ ] 老人、孕妇、残障旅客提前在 12306 预约重点旅客服务

## 抢票

- [ ] 起售时间准时下单
- [ ] 售罄立即提交候补：预付票款，未兑现自动退款
- [ ] 候补勾选“接受新增列车”，提高成功率
- [ ] 不用第三方加速包，不买黄牛票，不轻信“内部票”
- [ ] 不买“买长乘短”再越站，可能补不到票按无票处理

## 出发

- [ ] 身份证原件（不能用复印件进站）
- [ ] 手机，12306 App 已登录，车票信息截图发给家人约好接站
- [ ] 备少量现金
- [ ] 至少提前 1 小时到站，春运安检排长队
- [ ] 确认车站是东站、西站还是南站
- [ ] 检查充电宝、酒类是否合规；年货不超重、不带活禽

## 车站

- [ ] 实名验证
- [ ] 安检；带了禁限物品可寄存、快递或放弃
- [ ] 看大屏确认候车室和检票口
- [ ] 检票后下站台，地面湿滑、人多，不奔跑
- [ ] 按车厢号上车，对号入座

## 出问题找谁

- [ ] 跑错站：打车去正确车站，联系 12306 看能否改签
- [ ] 没带身份证：到车站公安制证窗口办临时身份证明
- [ ] 上错车：立即找列车员，下一站下车换乘
- [ ] 晚点停运：看公告，办理改签退票，保留凭证
- [ ] 行李丢失：找列车员或车站服务台登记，拨 12306
- [ ] 身体不适：找列车员广播寻医，严重时下一站下车拨 120
