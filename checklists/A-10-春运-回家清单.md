# A-10 第一次春运回家 · 清单

> 打印后勾选。依据见 [A-10 正文](../book/01-出行与交通/A-10-第一次春运回家.md)。

## 提前准备

- [ ] 12306 实名认证完成
- [ ] 乘车人身份核验
- [ ] 学生完成优惠资质核验
- [ ] 查清起售时间
- [ ] 列 3 个备选车次
- [ ] 准备中转、邻站、飞机、大巴备选方案

## 抢票

- [ ] 起售时间准时下单
- [ ] 售罄立即候补
- [ ] 候补勾选接受新增列车
- [ ] 不用第三方加速包
- [ ] 不买黄牛票

## 出发

- [ ] 身份证原件
- [ ] 车票信息截图
- [ ] 至少提前 1 小时到站
- [ ] 确认车站是东站、西站还是南站
- [ ] 检查充电宝、酒类是否合规
- [ ] 年货不超重、不带活禽

## 车站

- [ ] 实名验证
- [ ] 安检
- [ ] 看大屏确认候车室和检票口
- [ ] 检票后下站台
- [ ] 按车厢号上车

## 出问题找谁

- [ ] 跑错站：打车去正确车站，联系 12306
- [ ] 没带身份证：车站公安制证窗口
- [ ] 晚点停运：看公告，办理改签退票
- [ ] 行李丢失：找列车员或车站服务台
- [ ] 身体不适：找列车员，拨 120
