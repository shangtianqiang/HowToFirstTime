# A-11 第一次住酒店/民宿 · 清单

> 打印后勾选。依据见 [A-11 正文](../book/01-出行与交通/A-11-第一次住酒店与民宿.md)。

## 订房前

- [ ] 对比平台价格和酒店官方渠道价格
- [ ] 看清退改规则和取消政策，截图保存
- [ ] 看押金说明和金额
- [ ] 翻近三个月差评，重点看卫生、隔音、安全
- [ ] 民宿确认地址、取钥匙方式和联系人
- [ ] 订单截图保存，含房型、价格、订单号
- [ ] 不接受脱离平台的私下转账

## 出门前

- [ ] 身份证在有效期内，境外旅客备好护照
- [ ] 手机充满电，订单可离线查看
- [ ] 充电线、充电宝
- [ ] 洗漱用品和拖鞋（部分城市酒店不主动提供一次性用品）
- [ ] 常用药品
- [ ] 未成年人入住，备好监护人联系方式

## 到店办理

- [ ] 核对房型、价格、入住天数和订单一致
- [ ] 一人一证实名登记
- [ ] 问清押金金额、退还时限，留凭证拍照
- [ ] 记下前台电话和退房时间
- [ ] 记下早餐时间和地点

## 进房自检

- [ ] 试门锁，反锁，挂防盗扣
- [ ] 猫眼没有被堵或装反
- [ ] 看门后疏散图，记住两个安全出口方向
- [ ] 楼道疏散通道没有被杂物堵住
- [ ] 烟感器、喷淋头完好，知道灭火器位置
- [ ] 床品无毛发污渍，不干净当场要求更换
- [ ] 试热水、灯光、空调、窗户锁
- [ ] 关灯拉帘，手机相机扫一圈可疑反光点
- [ ] 重点查正对床位的插座、烟感、装饰画、纸巾盒
- [ ] 贵重物品放保险箱或交前台

## 退房

- [ ] 查床底、枕头下、插座旁、保险箱
- [ ] 带齐身份证、充电线等随身物品
- [ ] 迷你吧消费清单核对无误
- [ ] 确认押金退还方式和到账时限
- [ ] 订单与押金凭证留到退款到账

## 出问题找谁

- [ ] 发现摄像头：不拆除，拍照留证，拨 110，通知酒店和平台
- [ ] 财物丢失：报前台，报警 110，尽快申请调监控
- [ ] 到店无房：要求换房，或让平台安排同级酒店并补差价
- [ ] 涨价毁约、卫生纠纷：留证据，打 12315 或 12345
- [ ] 火警：低姿走疏散通道，不坐电梯
- [ ] 突发疾病：拨 120，请前台协助
