# A-12 第一次长途自驾游 · 清单

> 打印后勾选。依据见 [A-12 正文](../book/01-出行与交通/A-12-第一次长途自驾游.md)。

## 提前 7 天

- [ ] 定路线和总里程，看服务区分布
- [ ] 排好每天的驾驶时长，500 公里以上分两天走
- [ ] 查驾驶证、行驶证有效期，交强险在保险期内
- [ ] 查沿途限行、景区预约要求
- [ ] 驾照在实习期的，约好驾龄 3 年以上的陪同人员

## 提前 24 小时

- [ ] 胎压冷胎测量，含备胎，对照车门 B 柱标准值
- [ ] 轮胎无鼓包、裂纹、扎钉，花纹没磨到标记
- [ ] 机油液位在上下刻度之间
- [ ] 玻璃水加满，冬天用防冻型
- [ ] 冷却液、刹车油液位正常
- [ ] 大灯、刹车灯、转向灯、双闪逐个试
- [ ] 备胎、千斤顶、轮胎扳手、三角警示牌、反光背心齐全
- [ ] 加满油、充满电
- [ ] 确认 ETC 状态，另备少量现金
- [ ] 查沿途天气，有雨雪雾调整行程

## 出发前

- [ ] 睡够觉，熬夜和酒后不开车
- [ ] 行李装好，不挡后视镜视野，重物放低处
- [ ] 儿童安全座椅装好，孩子坐后排
- [ ] 手机满电，带充电线和充电宝
- [ ] 下载离线地图
- [ ] 路线和预计到达时间发给家人
- [ ] 带饮用水、零食和常用药品
- [ ] 绕车一圈，看轮胎和车底渗漏，看仪表盘警示灯

## 途中

- [ ] 每 2 小时或约 200 公里进一次服务区
- [ ] 连续驾驶不超 4 小时，休息不少于 20 分钟
- [ ] 时速超 100 公里，跟车保持 100 米以上
- [ ] 不占用应急车道行驶或停车
- [ ] 错过出口就到下一个出口绕回，不倒车不逆行
- [ ] 油量或电量低于一半就补
- [ ] 雨雾天开灯降速，雾天开雾灯和双闪
- [ ] 超车后回原车道，不长时间占用最左侧车道

## 到达后

- [ ] 停正规停车场，贵重物品带走或收进后备箱
- [ ] 记好停车位置和缴费方式
- [ ] 给家人报平安

## 出问题找谁

- [ ] 高速事故或故障：车靠边、人撤离、即报警，拨 12122
- [ ] 普通道路事故：拨 122
- [ ] 有人受伤：先拨 120
- [ ] 需要拖车救援：高速拨 12122，或走保险的道路救援
- [ ] 住宿、门票等消费纠纷：拨 12315 或 12345
