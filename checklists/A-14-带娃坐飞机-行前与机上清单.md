# A-14 第一次带娃坐飞机 · 清单

> 打印后勾选。依据见 [A-14 正文](../book/01-出行与交通/A-14-第一次带娃坐飞机.md)。

## 订票时

- [ ] 核对年龄：满 14 天才能飞；婴儿票（<2 岁）10% 不占座，儿童票（2–12 岁）50% 占座
- [ ] 航司 App/官网购票后加购婴儿/儿童票，客服核对人头
- [ ] 长航线：立即申请婴儿摇篮（隔板座位，量少先到先得）
- [ ] 提前 24 小时以上订儿童餐

## 随身包

- [ ] 出生医学证明或户口簿原件（安检登机核对）
- [ ] 奶粉分装、安抚奶嘴、保温杯
- [ ] 尿不湿、湿巾、换洗衣物一套
- [ ] 小玩具、熟悉的毯子、儿童耳机
- [ ] 婴儿背带（配合婴儿安全带用）

## 机场

- [ ] 提前 1.5–2 小时到，值机报婴儿票、要前排/摇篮位
- [ ] 婴儿车挂登机口托运牌，推到登机口再交
- [ ] 安检：婴儿食品单独取出说明（不受 100 毫升限制）
- [ ] 申请优先登机

## 机上

- [ ] 婴儿安全带扣在成人安全带上
- [ ] 护耳时机：离地滑跑时喂奶/奶嘴，广播下降时再喂一次
- [ ] 起降全程抱在身上，收好小桌板设备
- [ ] 落地检查座位口袋：奶瓶、玩具、证件

## 应急

- [ ] 孩子突发不适：联系航司改签（婴儿病退较宽松）
- [ ] 证件忘带：机场警务室办临时乘机证明
- [ ] 落地后耳痛哭闹不止：就医排查中耳问题
