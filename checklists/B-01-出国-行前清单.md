# B-01 出国 · 行前清单

> 打印后勾选。依据见 [B-01 正文](../book/02-证件与跨境/B-01-第一次出国.md)。政策变化快，出发前必须再查官方页面。

## 出发前 1–3 个月

- [ ] 确认护照有效期和空白页
- [ ] 确认目的地要不要签证、要哪种签证
- [ ] 准备签证材料：照片、行程、机酒、财力证明、在职证明
- [ ] 预约送签或面签
- [ ] 订机票和住宿，确认退改规则
- [ ] 买旅行保险，确认医疗和转运保障
- [ ] 查目的地入境要求：疫苗、健康申报、入境卡

## 出发前 1 周

- [ ] 确认签证已出签，信息无误
- [ ] 确认护照、签证、机票、住宿订单齐全
- [ ] 准备境外支付：信用卡、现金、移动支付
- [ ] 准备通讯：漫游、eSIM 或当地卡
- [ ] 把使领馆电话和 12308 存进手机，再抄一份
- [ ] 把行程和联系方式发给家人

## 出发前 24 小时

- [ ] 确认航班、航站楼和起飞时间
- [ ] 确认行李额和禁带物品
- [ ] 确认入境国海关申报要求
- [ ] 检查护照和签证放在随身包
- [ ] 给手机和充电宝充电

## 到机场后

- [ ] 办理值机、托运行李
- [ ] 出境边检
- [ ] 安检
- [ ] 找到登机口
- [ ] 填好入境卡或健康申报（如需要）

## 出问题找谁

- [ ] 拒签：看拒签信理由，补充材料后再申请
- [ ] 拒绝入境：配合检查，联系中国驻当地使领馆
- [ ] 航班延误或取消：找航司柜台改签
- [ ] 护照或财物丢失：先报警，再联系使领馆
- [ ] 领事保护：12308 或当地使领馆领保电话
