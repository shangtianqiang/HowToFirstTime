# B-02 第一次办护照/通行证 · 清单

> 打印后勾选。依据见 [B-02 正文](../book/02-证件与跨境/B-02-第一次办护照与通行证.md)。

## 出发前

- [ ] 确认办护照还是通行证
- [ ] 在移民局平台预约
- [ ] 带身份证原件
- [ ] 未成年人带监护证明
- [ ] 换发带旧证，补发带遗失说明
- [ ] 穿深色上衣，不戴美瞳和首饰

## 窗口

- [ ] 取号
- [ ] 填表
- [ ] 拍照
- [ ] 采集指纹和签名
- [ ] 核对姓名、拼音、出生地
- [ ] 缴费并保留回执

## 取证

- [ ] 带身份证和回执
- [ ] 核对姓名、拼音、性别、出生日期
- [ ] 核对证件号码和有效期
- [ ] 有错误当场申请更正

## 出问题找谁

- [ ] 急事出国：问窗口加急通道
- [ ] 证件遗失：派出所报案，窗口补发
- [ ] 境外遗失：联系中国使领馆
- [ ] 政策疑问：拨 12367
