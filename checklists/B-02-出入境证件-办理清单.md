# B-02 第一次办护照/通行证 · 清单

> 打印后勾选。依据见 [B-02 正文](../book/02-证件与跨境/B-02-第一次办护照与通行证.md)。

## 办证前

- [ ] 确认办护照还是通行证：出国用护照，只去港澳台办通行证、另办签注
- [ ] 在移民局 App、小程序或政务平台预约，避开周一上午和节假日前后
- [ ] 带身份证原件；多数城市全国通办，不用回户籍地
- [ ] 未成年人：监护人陪同，带监护关系证明和监护人身份证
- [ ] 换发带旧证，补发带遗失说明或报案证明
- [ ] 国家工作人员、登记备案人员：先按单位规定审批
- [ ] 照片要求：白底、深色上衣、不戴美瞳首饰、不化浓妆

## 窗口办理

- [ ] 取号等叫号，提交身份证
- [ ] 填申请表，现场拍照、采集指纹和签名
- [ ] 核对屏幕上的姓名、拼音、出生地，有生僻字当场提出
- [ ] 缴费并保留票据和受理回执

## 取证

- [ ] 一般 7–20 个工作日，凭回执和身份证领证或选邮寄
- [ ] 核对姓名、拼音、性别、出生日期、证件号码、有效期
- [ ] 有错误当场申请更正，别签收后再处理
- [ ] 工本费：护照 120 元，港澳、台湾通行证各 60 元

## 用证提醒

- [ ] 出行前查签注次数和有效期：通行证有效不等于签注有效
- [ ] 护照剩余有效期不足 6 个月，多数国家拒绝入境或登机
- [ ] 国内住宿、乘车仍用身份证，护照别当身份证用
- [ ] 证件随身带，不放进托运行李
- [ ] 旧证交回或过期后不能再出国，等新证到手再订机票

## 出问题找谁

- [ ] 急事出国：向窗口说明情况、提供证明，问加急通道
- [ ] 证件遗失：派出所报案，出入境窗口补发
- [ ] 境外遗失：联系中国驻当地使领馆补办旅行证
- [ ] 加急代办广告：官方没有付费加急中介，别信
- [ ] 政策疑问：拨 12367 或查国家移民管理局官网
