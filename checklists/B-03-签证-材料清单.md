# B-03 第一次办签证 · 清单

> 打印后勾选。依据见 [B-03 正文](../book/02-证件与跨境/B-03-第一次办签证.md)。

## 申请前

- [ ] 确认目的国签证类型
- [ ] 查是否免签、落地签或电子签
- [ ] 护照剩余有效期 6 个月以上
- [ ] 护照至少 2 页空白
- [ ] 查受理时长和预约规则
- [ ] 订可退的机票和酒店

## 材料

- [ ] 护照原件和复印件
- [ ] 符合规格的照片
- [ ] 签证申请表
- [ ] 身份证、户口簿复印件
- [ ] 在职或在读证明
- [ ] 银行流水、存款证明
- [ ] 行程单、住宿证明
- [ ] 旅行保险
- [ ] 邀请函（如需）

## 送签

- [ ] 在线填表并预约
- [ ] 按时间到签证中心
- [ ] 交材料、录指纹
- [ ] 缴费并保留回执
- [ ] 记下查询编号

## 领取

- [ ] 核对姓名、护照号
- [ ] 核对签证有效期和停留天数
- [ ] 核对入境次数
- [ ] 信息有误立即联系更正

## 出问题找谁

- [ ] 拒签：看拒签信，补齐材料再申请
- [ ] 护照寄丢：联系签证中心和快递，报警
- [ ] 时间紧：问加急服务
- [ ] 入境被拒：联系中国驻当地使领馆
