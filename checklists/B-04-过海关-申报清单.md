# B-04 第一次过海关 · 清单

> 打印后勾选。依据见 [B-04 正文](../book/02-证件与跨境/B-04-第一次过海关.md)。

## 出发前

- [ ] 查海关总署最新公告
- [ ] 列购物清单并算总价
- [ ] 烟酒不超量
- [ ] 不带肉类、水果、种子
- [ ] 确认健康申报要求
- [ ] 贵重物品放随身行李

## 入境

- [ ] 卫生检疫，出示健康申报码
- [ ] 边检，走中国公民通道
- [ ] 取全部托运行李
- [ ] 无申报走绿色，有申报走红色
- [ ] 主动申报超量物品
- [ ] 保留购物小票

## 不做什么

- [ ] 不帮陌生人带行李
- [ ] 不拆包装、不剪标签造假
- [ ] 不带象牙、玳瑁等濒危制品
- [ ] 不隐瞒超额外币现钞

## 出问题找谁

- [ ] 被查验：配合开箱，如实说明
- [ ] 物品被扣：索取扣留凭单
- [ ] 带药品：备好处方和说明书
- [ ] 政策疑问：拨 12360
