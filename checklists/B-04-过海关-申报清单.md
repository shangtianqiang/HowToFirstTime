# B-04 第一次过海关 · 清单

> 打印后勾选。依据见 [B-04 正文](../book/02-证件与跨境/B-04-第一次过海关.md)。

## 出发前

- [ ] 查海关总署最新公告：免税额度、禁限物品目录、健康申报要求
- [ ] 列购物清单算总价：境外自用物品超 5000 元主动申报
- [ ] 口岸进境免税店购物另有 3000 元额度
- [ ] 烟酒按限带：香烟 400 支、雪茄 100 支、12 度以上酒 1500 毫升
- [ ] 不带肉类、蛋、奶、新鲜水果、种子和土壤
- [ ] 不买象牙、玳瑁等濒危动植物制品
- [ ] 处方药带处方和说明书，麻醉、精神类药品先查限制

## 入境现场

- [ ] 落地前填好入境卡和海关申报单（纸质或电子申报）
- [ ] 购物小票和发票收好，便于海关估价
- [ ] 要申报的物品放随身行李，方便取出
- [ ] 卫生检疫：出示健康申报码，配合体温检测
- [ ] 边检走中国公民通道或自助通道
- [ ] 核对行李牌，取齐全部托运行李
- [ ] 无申报走绿色通道，有申报走红色通道填单
- [ ] 拿不准超没超额：走红色通道问关员

## 红线

- [ ] 不帮陌生人带行李和物品
- [ ] 不拆包装、不剪标签
- [ ] 超额主动申报：隐瞒被查出有行政处罚和信用记录
- [ ] 电子烟烟弹超量也要申报
- [ ] 不隐瞒超额外币现钞：超等值 5000 美元要申报

## 出问题找谁

- [ ] 被查验：配合开箱，如实说明来源和用途
- [ ] 物品被扣：索取扣留凭单，按通知退运、补税或放弃
- [ ] 申报单丢失：向关员说明，重新填写
- [ ] 政策疑问：拨 12360 或用「海关旅客指尖服务」小程序
