# B-05 第一次境外支付与通讯 · 清单

> 打印后勾选。依据见 [B-05 正文](../book/02-证件与跨境/B-05-第一次境外支付与通讯.md)。

## 支付

- [ ] 一张银联卡、一张 Visa/Mastercard
- [ ] 开通境外交易
- [ ] 设置交易提醒和限额
- [ ] 换少量当地现金
- [ ] 卡号和客服电话抄在纸上
- [ ] 卡和现金分开放

## 通讯

- [ ] 确认手机支持漫游
- [ ] 买漫游流量包或当地卡
- [ ] 确认是否支持 eSIM
- [ ] 下载离线地图和翻译 App
- [ ] 记下酒店地址的当地语言写法

## 设备

- [ ] 转换插头
- [ ] 充电宝符合航空规定
- [ ] 充电线
- [ ] 护照签证复印件

## 安全

- [ ] 刷卡遮挡密码
- [ ] 选当地货币结算
- [ ] 不在公共 Wi-Fi 登录网银
- [ ] 每天给家人报平安

## 出问题找谁

- [ ] 盗刷：App 锁卡，打银行客服，报警
- [ ] 吞卡：联系 ATM 所属银行
- [ ] 手机丢失：远程锁定，补卡，改密码
- [ ] 紧急求助：当地警方、12308
