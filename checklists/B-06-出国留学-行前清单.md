# B-06 第一次出国留学 · 清单

> 打印后勾选。依据见 [B-06 正文](../book/02-证件与跨境/B-06-第一次出国留学.md)。

## 申请

- [ ] 查教育部涉外监管信息网名单
- [ ] 确认专业和录取要求
- [ ] 算清学费、生活费、保险
- [ ] 准备资金证明
- [ ] 中介合同写清服务和退款

## 签证

- [ ] 护照有效期覆盖学习期
- [ ] 录取通知书
- [ ] 资金证明
- [ ] 语言成绩
- [ ] 签证申请表和照片
- [ ] 体检和疫苗记录
- [ ] 无犯罪记录证明（如需）

## 行前

- [ ] 订机票和临时住宿
- [ ] 买留学保险
- [ ] 办境外可用的银行卡
- [ ] 扫描备份所有证件
- [ ] 记下使领馆电话和 12308
- [ ] 查当地住宿登记时限

## 落地

- [ ] 入境并核对停留期
- [ ] 学校报到注册
- [ ] 住宿登记
- [ ] 银行开户
- [ ] 手机卡
- [ ] 居留许可
- [ ] 保险生效确认

## 出问题找谁

- [ ] 签证被拒：补材料再申请
- [ ] 护照丢失：报警，联系使领馆
- [ ] 学业困难：学校国际学生办公室
- [ ] 安全事件：当地警方、使领馆、12308
