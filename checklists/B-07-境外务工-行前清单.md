# B-07 第一次境外务工 · 清单

> 打印后勾选。依据见 [B-07 正文](../book/02-证件与跨境/B-07-第一次境外务工.md)。

## 选企业

- [ ] 查商务部对外劳务合作企业名录
- [ ] 确认有对应国家项目
- [ ] 不通过个人中介
- [ ] 问清岗位、工资、工时、食宿
- [ ] 警惕高薪零门槛广告

## 合同

- [ ] 服务合同
- [ ] 劳动合同及中文译本
- [ ] 工资币种和发放方式
- [ ] 加班费和休息日
- [ ] 保险和工伤处理
- [ ] 解除条件和退费
- [ ] 不收押金、不扣押证件

## 出境

- [ ] 护照
- [ ] 工作签证
- [ ] 体检和疫苗记录
- [ ] 技能证书
- [ ] 合同和邀请函
- [ ] 使领馆电话和 12308

## 落地

- [ ] 居留许可
- [ ] 税号、社保号
- [ ] 银行开户
- [ ] 保险生效
- [ ] 使领馆登记
- [ ] 把住址和雇主电话告诉家人

## 出问题找谁

- [ ] 欠薪：当地劳工部门、使领馆
- [ ] 护照被扣：报警、使领馆补办
- [ ] 人身受限：报警、12308
- [ ] 工伤：就医、报保险、保留单据
