# B-07 第一次境外务工 · 清单

> 打印后勾选。依据见 [B-07 正文](../book/02-证件与跨境/B-07-第一次境外务工.md)。

## 选企业

- [ ] 提前 2–6 个月开始办，查商务部对外劳务合作企业名录
- [ ] 确认企业有对应国家的项目备案
- [ ] 不通过个人中介，不轻信"老乡"介绍
- [ ] 问清岗位、工资、工时、合同期限、食宿、保险
- [ ] 警惕"高薪、零门槛、包机票"的招工广告，口头承诺不写进合同就不算数

## 合同与费用

- [ ] 签对外劳务合作服务合同
- [ ] 签与境外雇主的劳动合同，附中文译本，逐条确认再签字
- [ ] 写清工资币种、发放方式、加班费、休息日
- [ ] 写清保险、工伤处理、解除条件、违约责任
- [ ] 服务费有上限，不交押金、不交保证金
- [ ] 口头承诺的高薪不写进合同就不算数

## 行前准备

- [ ] 办护照和工作签证，有效期覆盖合同期；旅游、商务、探亲签不能打工
- [ ] 按目的国要求体检，带疫苗记录和技能证书
- [ ] 记下企业负责人、境外雇主、使领馆电话和 12308
- [ ] 合同、护照、签证扫描备份给家人，把住址和雇主电话告诉家人
- [ ] 了解目的国法律、宗教习俗、气候和安全形势

## 出境与落地

- [ ] 边检出示护照、工作签证、合同
- [ ] 入境出示雇主邀请函，核对入境章上的居留期限
- [ ] 按当地规定时限办居留许可
- [ ] 办税号、社保号，由雇主协助
- [ ] 带护照、合同、住址证明开银行账户
- [ ] 确认保险生效，覆盖工伤和医疗；部分国家到使领馆登记

## 工作期间

- [ ] 按合同岗位工作，不擅自换雇主、换岗位
- [ ] 保留工资单、工时记录、加班记录
- [ ] 合同外加班留记录，按当地法律主张加班费
- [ ] 合同到期想留下：走合法渠道变更签证，不擅自滞留

## 出问题找谁

- [ ] 欠薪：书面催告，向当地劳工部门投诉，联系使领馆
- [ ] 护照被扣：向当地警方报案，联系使领馆补办旅行证
- [ ] 人身受限：找机会报警或联系家人，拨 12308
- [ ] 工伤：先就医，保留诊断和费用单据，报保险和雇主
- [ ] 被遣返：保留遣返文件，回国后咨询法律途径
- [ ] 战乱、疫情：关注使领馆安全提醒，按应急预案撤离
