# B-08 第一次回国入境 · 清单

> 打印后勾选。依据见 [B-08 正文](../book/02-证件与跨境/B-08-第一次回国入境.md)。

## 登机前

- [ ] 护照在有效期内
- [ ] 购物小票集中放好
- [ ] 查海关免税额度和禁限物品
- [ ] 需要申报的提前填单
- [ ] 健康申报按要求填写

## 入境

- [ ] 护照和登机牌随身
- [ ] 卫生检疫
- [ ] 走中国公民通道
- [ ] 取齐托运行李
- [ ] 无申报走绿色，有申报走红色
- [ ] 配合海关查验

## 回国后

- [ ] 社保续缴或参保
- [ ] 档案接续
- [ ] 国外学历认证（如需）
- [ ] 银行、手机号恢复使用
- [ ] 驾驶证换证（如到期）

## 出问题找谁

- [ ] 护照丢失：使领馆补旅行证
- [ ] 行李丢失：航空公司行李查询
- [ ] 物品被扣：索取扣留凭单
- [ ] 政策疑问：12360、12367
