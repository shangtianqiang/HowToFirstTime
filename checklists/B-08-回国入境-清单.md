# B-08 第一次回国入境 · 清单

> 打印后勾选。依据见 [B-08 正文](../book/02-证件与跨境/B-08-第一次回国入境.md)。

## 登机前

- [ ] 确认护照在有效期内，快过期的先在境外换发或回国补办
- [ ] 整理行李，购物小票集中放好
- [ ] 查海关总署免税额度、禁限物品的最新公告
- [ ] 境外购物通常 5000 元以内免税，超了主动申报
- [ ] 肉类、蛋奶、新鲜水果、蔬菜、种子不带
- [ ] 有需要申报的物品，提前填好申报单

## 飞机上

- [ ] 填写入境卡（如发放）
- [ ] 按当时海关要求，用"海关旅客指尖服务"填健康申报
- [ ] 护照、登机牌、申报二维码放随手可取的位置
- [ ] 不帮陌生人带行李，不明物品责任在携带人

## 入境通关

- [ ] 卫生检疫：出示健康申报码，配合体温检测
- [ ] 边检走中国公民通道或自助通道，别排错
- [ ] 自助通道：放护照、看镜头、按指纹，失败改走人工
- [ ] 核对行李牌，取齐全部托运行李
- [ ] 无申报走绿色通道，有申报走红色通道交单
- [ ] 配合海关查验，物品被扣留的索取扣留凭单

## 回国后

- [ ] 重新就业由单位续缴社保，灵活就业可以个人身份参保
- [ ] 办理档案接续
- [ ] 国外学历到留服中心网上服务大厅办认证
- [ ] 核对入境章与入境日期，留存备查
- [ ] 带宠物回国的：提前办检疫审批、狂犬疫苗和抗体检测，从指定口岸入境

## 出问题找谁

- [ ] 护照丢失：联系中国使领馆补办旅行证，保留报警记录
- [ ] 行李丢失：找航空公司行李查询柜台填单，保留登机牌
- [ ] 被边检问询：如实说明出境目的和停留时间
- [ ] 身体不适：找机场医疗点，必要时拨 120
- [ ] 政策疑问：12360（海关）、12367（移民局）
