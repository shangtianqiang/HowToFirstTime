# B-10 第一次办公证 · 清单

> 打印后勾选。依据见 [B-10 正文](../book/02-证件与跨境/B-10-第一次办公证.md)。

## 办之前

- [ ] 想清用途：留学、移民、卖房委托、诉讼、继承，决定办哪种公证
- [ ] 问用件机构：公证书种类、份数、语种、是否要认证或附加证明书
- [ ] 打当地公证处电话：报事项，确认材料清单和是否预约
- [ ] 确认在哪办：住所地、经常居住地或事项发生地公证处
- [ ] 涉外公证选有涉外资质的公证处
- [ ] 按对方要求的时间办，办早了可能过期重办

## 带齐原件

- [ ] 身份证、户口簿原件（公证核对的是原件，复印件不行）
- [ ] 委托公证：委托书文本 + 事项证明（如房产证）
- [ ] 学历公证：毕业证、学位证原件
- [ ] 无犯罪公证：多数地区由公证处代核查，先问
- [ ] 出生/亲属关系公证：出生医学证明或户籍档案材料
- [ ] 代办的：代办人身份证 + 载明事项和权限的书面委托

## 办理中

- [ ] 填公证申请表，核对受理通知上的事项、份数、收费、出证时间
- [ ] 材料不齐的按一次性告知补齐，别跑第二趟还不齐
- [ ] 谈话笔录逐条核对再签字
- [ ] 委托权限别写"全权"，限定事项和期限
- [ ] 缴费留回执，法定 15 个工作日内出证
- [ ] 一份公证书一般对应一个用途，多机构使用要办多份

## 涉外用途

- [ ] 去海牙缔约国：公证后办附加证明书（Apostille），不再办领事认证
- [ ] 去非缔约国：仍需领事认证（外交部认证 + 驻华使领馆认证）
- [ ] 翻译件在公证处一并办理，自己翻译的容易被退回
- [ ] 人在国外：先问国内公证处能否线上办，或在驻外使领馆办委托公证

## 出问题找谁

- [ ] 材料补正：按一次性告知清单补齐
- [ ] 公证书有误：向原公证处申请复查
- [ ] 在国外被要求补充认证：先向用件机构确认要 Apostille 还是领事认证
- [ ] 行动不便：联系公证处申请上门公证
- [ ] 咨询：12348 法律服务热线
