# B-10 第一次办公证 · 清单

> 打印后勾选。依据见 [B-10 正文](../book/02-证件与跨境/B-10-第一次办公证.md)。

## 办之前

- [ ] 问用件机构：公证书种类、份数、语种、是否要认证/Apostille
- [ ] 打当地公证处电话：确认材料清单和是否预约
- [ ] 确认在哪办：住所地/经常居住地/事项发生地公证处

## 带齐原件

- [ ] 身份证、户口簿
- [ ] 委托公证：委托书文本 + 事项证明（如房产证）
- [ ] 学历公证：毕业证、学位证
- [ ] 无犯罪公证：先问公证处是否代核查
- [ ] 出生/亲属关系公证：出生证明或户籍档案材料
- [ ] 代办的：代办人身份证 + 书面委托

## 办理中

- [ ] 填申请表，看清事项、份数、收费
- [ ] 谈话笔录逐条核对再签字
- [ ] 缴费留回执，记下取件时间（法定 15 个工作日内）

## 涉外用途

- [ ] 去海牙缔约国：公证后办附加证明书（Apostille）
- [ ] 去非缔约国：仍需领事认证
- [ ] 翻译件在公证处一并办理

## 出问题找谁

- [ ] 材料补正：按一次性告知清单补齐
- [ ] 公证书有误：向原公证处申请复查
- [ ] 咨询：12348 法律服务热线
