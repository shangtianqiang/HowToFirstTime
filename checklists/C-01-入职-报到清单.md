# C-01 入职 · 报到清单

> 打印后勾选。依据见 [C-01 正文](../book/03-工作与职业/C-01-第一次入职.md)。

## 入职前

- [ ] 确认报到时间、地点和联系人
- [ ] 准备身份证和复印件
- [ ] 准备学历、学位证书
- [ ] 准备照片
- [ ] 准备银行卡
- [ ] 准备体检报告
- [ ] 确认三方协议、报到证、档案怎么处理
- [ ] 问清着装要求和第一天安排

## 报到当天

- [ ] 找 HR 报到
- [ ] 签劳动合同，逐条看清
- [ ] 确认试用期长度和工资不低于法定下限
- [ ] 确认工作内容、地点和工时
- [ ] 确认社保、公积金什么时候开始缴
- [ ] 确认发薪日和工资构成
- [ ] 办理门禁、工牌、邮箱、办公账号
- [ ] 拿到一份签字盖章的合同原件

## 第一周

- [ ] 认识直属领导和带教师傅
- [ ] 问清团队分工和协作方式
- [ ] 问清请假、报销、加班流程
- [ ] 保存工资条和社保查询方式
- [ ] 记下试用期考核节点

## 出问题找谁

- [ ] 公司不签合同：保留证据，可主张二倍工资
- [ ] 试用期被辞退：要求书面通知和理由
- [ ] 社保未缴：向社保征收机构举报或拨 12333
- [ ] 工资少发或拖欠：先核对，再向劳动保障监察投诉
- [ ] 档案或户口问题：找学校就业办、人才中心或 HR
