# C-01 入职 · 报到清单

> 打印后勾选。依据见 [C-01 正文](../book/03-工作与职业/C-01-第一次入职.md)。

## 入职前

- [ ] 确认报到时间、地点和联系人，问清着装要求和第一天安排
- [ ] 准备身份证和复印件
- [ ] 准备学历、学位证书，有的公司要学信网验证报告
- [ ] 准备照片
- [ ] 准备发工资用的银行卡
- [ ] 准备体检报告
- [ ] 社招：备好离职证明和社保转移材料
- [ ] 确认三方协议、报到证、档案怎么处理，签三方前看清违约金条款

## 报到签合同

- [ ] 找 HR 报到，交材料，不齐的问清能否后补
- [ ] 签劳动合同，逐条看清，空白处都填好
- [ ] 确认试用期长度合法，工资不低于法定下限
- [ ] 确认工作内容、工作地点和工时制度
- [ ] 确认社保、公积金什么时候开始缴（用工 30 日内要办社保登记）
- [ ] 确认发薪日和工资构成
- [ ] 违约金只有专项培训服务期和竞业限制两种情形，其他条款可能无效
- [ ] 拿到一份签字盖章的合同原件，口头承诺尽量写进合同

## 办手续

- [ ] 办门禁、工牌、邮箱、办公账号
- [ ] 领员工手册，看考勤制度和报销制度
- [ ] 问清请假、加班、报销流程
- [ ] 确认工资卡已登记

## 第一个月

- [ ] 认识直属领导和带教师傅，问清团队分工和协作方式
- [ ] 问"这周先做什么、做到什么程度算完成"，拿一份本周任务清单
- [ ] 记下试用期考核节点，记录自己的工作成果
- [ ] 第一份工资条核对应发、代扣、实发
- [ ] 在个人所得税 App 填报专项附加扣除
- [ ] 保存工资条和社保查询方式

## 出问题找谁

- [ ] 公司不签合同：保留证据，满 1 个月可主张二倍工资
- [ ] 试用期被辞退：要求书面通知和理由
- [ ] 社保未缴：向社保征收机构举报或拨 12333
- [ ] 工资少发或拖欠：先核对，再向劳动保障监察投诉
- [ ] 档案或户口问题：找学校就业办、人才中心或 HR
- [ ] 被收押金、培训费、服装费：先问依据，必要时投诉
