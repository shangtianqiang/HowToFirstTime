# C-02 第一次面试 · 清单

> 打印后勾选。依据见 [C-02 正文](../book/03-工作与职业/C-02-第一次面试.md)。

## 面试前

- [ ] 查公司登记信息、信用记录和近期新闻
- [ ] 确认岗位职责、工作地点、工时和报酬
- [ ] 工厂、化工、建筑等岗位：问职业危害和安全生产状况
- [ ] 对照岗位硬条件，缺的提前想好怎么答
- [ ] 准备简历、学历证书、作品或项目材料
- [ ] 准备 30–60 秒自我介绍，经历用事实和数字讲
- [ ] 准备 3 个问面试官的问题
- [ ] 确认面试形式、地址、联系人和轮次

## 面试当天

- [ ] 提前 10–15 分钟到，迟到先打电话
- [ ] 着装干净整洁，按行业调整，拿不准先问 HR
- [ ] 带简历、证件和作品
- [ ] 记下面试官问的重点
- [ ] 不会的说自己的理解，不硬编
- [ ] 问试用期考核标准、转正条件
- [ ] 问工资构成、社保、发薪日和加班出差频率
- [ ] 问结果什么时候通知；第一轮不先问年假和涨薪

## 面试后与 offer

- [ ] 24 小时内发感谢邮件，提一个面试中的具体点
- [ ] 约定时间没回复，礼貌问一次进度
- [ ] 保留面试通知、聊天记录和邮件
- [ ] offer 要书面，写明岗位、工资、试用期和答复期限
- [ ] 核对 offer：岗位、地点、工资构成、社保、报到时间
- [ ] 对比多个 offer 看岗位、工资、地点和发展，别同时答应两家
- [ ] 要拒的尽早礼貌回复，别拖着

## 出问题找谁

- [ ] 面试地点在酒店房间、居民楼、无公司标识：先核实再进去
- [ ] 身份证原件、银行卡密码不交给单位
- [ ] 被问婚育、怀孕：可以拒答，保留证据
- [ ] 被要求乙肝检测：拒绝并投诉
- [ ] 被收押金、扣证件：拒绝并拨 12333
- [ ] 遇到培训贷、招转培、付费内推：停止沟通并举报
