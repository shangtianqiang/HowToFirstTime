# C-02 第一次面试 · 清单

> 打印后勾选。依据见 [C-02 正文](../book/03-工作与职业/C-02-第一次面试.md)。

## 面试前

- [ ] 查公司登记信息、信用记录和近期新闻
- [ ] 确认岗位职责、工作地点、工时和报酬
- [ ] 准备简历、学历证书、作品或项目材料
- [ ] 准备 30–60 秒自我介绍
- [ ] 准备 3 个问面试官的问题
- [ ] 确认面试形式、地址和联系人

## 面试当天

- [ ] 提前 10–15 分钟到，迟到先打电话
- [ ] 着装干净整洁，按行业调整
- [ ] 带简历、证件和作品
- [ ] 记下面试官问的重点
- [ ] 问清试用期、工资构成、社保、发薪日

## 面试后

- [ ] 24 小时内发感谢邮件
- [ ] 约定时间没回复，礼貌问一次
- [ ] 保留面试通知、聊天记录和邮件
- [ ] 对比 offer 时看岗位、工资、地点和发展

## 出问题找谁

- [ ] 被问婚育、怀孕：可以拒答，保留证据
- [ ] 被要求乙肝检测：拒绝并投诉
- [ ] 被收押金、扣证件：拒绝并拨 12333
- [ ] 遇到培训贷、招转培：停止沟通并举报
