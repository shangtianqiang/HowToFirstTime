# C-03 第一次签劳动合同 · 清单

> 打印后勾选。依据见 [C-03 正文](../book/03-工作与职业/C-03-第一次签劳动合同.md)。

## 试用期红线

- [ ] 对照试用期上限：合同 3 个月到 1 年最多 1 个月，1 到 3 年最多 2 个月，3 年以上最多 6 个月
- [ ] 合同不满 3 个月或以完成一定任务为期限的，不得约定试用期
- [ ] 同一单位只能约定一次试用期，换岗、续签不能再约
- [ ] 只写试用期不写合同期的，试用期不成立
- [ ] 试用期工资不低于同岗位最低档或合同工资的 80%，且不低于当地最低工资

## 核心条款

- [ ] 逐条读合同，不签空白合同
- [ ] 确认合同期限、工作内容和工作地点
- [ ] 确认工资构成、发薪日和工时制度
- [ ] 确认社保、公积金起缴时间
- [ ] 违约金只有专项培训服务期和竞业限制两种情形
- [ ] 竞业限制最多 2 年、按月给补偿；普通岗位被要求签，问清原因和范围

## 签合同时

- [ ] 空白处填好或划掉，岗位、地点、工资、试用期写清楚，不写"按公司规定"
- [ ] 有疑问当场问；被催签可要求带走草稿看一天
- [ ] 双方签字盖章，确认合同文本双方各执一份
- [ ] 确认附件、员工手册、岗位说明书已看过并留一份
- [ ] 口头承诺的工资、奖金、岗位尽量写进合同

## 电子合同

- [ ] 确认可靠电子签名和数据电文，和书面合同同等效力
- [ ] 要求免费提供至少一份纸质件
- [ ] 下载并保存电子合同和签署记录
- [ ] 看清条款再点"同意"，不一路点过去

## 签完之后

- [ ] 保存合同原件和附件
- [ ] 保存工资条、考勤和社保记录
- [ ] 保存 offer、入职通知和沟通记录
- [ ] 合同丢失：找单位补一份或复印盖章

## 出问题找谁

- [ ] 公司不签合同：保留证据，满 1 个月可主张二倍工资
- [ ] 被逼签空白合同：拒绝，保留录音和聊天记录并投诉
- [ ] 条款违法（如"自愿放弃社保"）：向劳动监察投诉或申请仲裁
- [ ] 不给合同原件：拍照留存并投诉
- [ ] 试用期被辞退：要书面理由，认为违法申请仲裁
