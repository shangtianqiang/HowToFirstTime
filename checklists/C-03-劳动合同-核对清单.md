# C-03 第一次签劳动合同 · 清单

> 打印后勾选。依据见 [C-03 正文](../book/03-工作与职业/C-03-第一次签劳动合同.md)。

## 签之前

- [ ] 逐条读合同，不签空白合同
- [ ] 确认合同期限、试用期和转正条件
- [ ] 确认工资构成、发薪日和工时
- [ ] 确认社保、公积金起缴时间
- [ ] 问清服务期、竞业限制和违约金
- [ ] 确认工作内容和工作地点

## 签合同时

- [ ] 空白处填好或划掉
- [ ] 双方签字盖章
- [ ] 确认合同文本双方各执一份
- [ ] 确认附件、员工手册、岗位说明书

## 电子合同

- [ ] 确认可靠电子签名和数据电文
- [ ] 要求免费提供至少一份纸质件
- [ ] 下载并保存电子合同和签署记录

## 签完之后

- [ ] 保存合同原件和附件
- [ ] 保存工资条、考勤和社保记录
- [ ] 保存 offer、入职通知和沟通记录

## 出问题找谁

- [ ] 公司不签合同：保留证据，满 1 个月可主张二倍工资
- [ ] 被逼签空白合同：拒绝并投诉
- [ ] 条款违法：向劳动监察投诉或申请仲裁
- [ ] 不给合同原件：拍照留存并投诉
