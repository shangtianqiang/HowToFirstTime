# C-04 第一次拿工资与五险一金 · 清单

> 打印后勾选。依据见 [C-04 正文](../book/03-工作与职业/C-04-第一次拿工资与五险一金.md)。

## 入职时

- [ ] 确认发薪日和工资构成：基本工资、绩效、补贴、奖金、提成
- [ ] 确认社保、公积金起缴时间
- [ ] 确认工资卡登记
- [ ] 问清加班费和请假工资怎么算
- [ ] "自愿放弃社保"的约定通常无效，单位仍要缴

## 第一份工资

- [ ] 核对到账金额和工资条：应发、代扣、实发能对上
- [ ] 代扣看养老、医疗、失业、公积金和个税
- [ ] 发薪日遇节假日应提前到最近的工作日
- [ ] 金额不对先找 HR 或财务核对
- [ ] 工资发现金不走银行的，留好工资条和签收记录
- [ ] 保存工资条和银行流水，至少留到离职后一年

## 加班费对照

- [ ] 工作日延长工时：不低于 150%
- [ ] 休息日不能补休：不低于 200%
- [ ] 法定节假日：不低于 300%，不能只调休
- [ ] 留考勤、排班表和加班通知，离职时可一起主张

## 查社保公积金

- [ ] 社保用国家社会保险公共服务平台或掌上 12333
- [ ] 查五险参保状态和缴费基数，是否都在缴
- [ ] 查缴费月数和个人账户，和工资条代扣对上
- [ ] 公积金用全国住房公积金小程序或 12329
- [ ] 查余额、缴存基数和月缴存额
- [ ] 医保断缴 3 个月内可补缴；试用期也要缴社保

## 出问题找谁

- [ ] 工资少发：核对考勤和绩效，先找 HR
- [ ] 社保漏缴：拨 12333 或向社保征收机构举报
- [ ] 公积金少缴：向公积金中心投诉
- [ ] 拖欠工资：向劳动保障监察投诉或申请劳动仲裁
- [ ] 按最低基数缴社保影响待遇，发现可提出核对
