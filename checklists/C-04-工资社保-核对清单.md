# C-04 第一次拿工资与五险一金 · 清单

> 打印后勾选。依据见 [C-04 正文](../book/03-工作与职业/C-04-第一次拿工资与五险一金.md)。

## 入职时

- [ ] 确认发薪日和工资构成
- [ ] 确认社保、公积金起缴时间
- [ ] 确认工资卡登记
- [ ] 问清加班费和请假工资怎么算

## 第一份工资

- [ ] 看工资条上的应发、代扣、实发
- [ ] 核对社保、公积金、个税代扣
- [ ] 保存工资条和银行流水
- [ ] 金额不对先找 HR 核对

## 查社保

- [ ] 用国家社会保险公共服务平台或掌上 12333
- [ ] 查五险参保状态和缴费基数
- [ ] 查缴费月数和个人账户
- [ ] 发现漏缴向社保征收机构反映

## 查公积金

- [ ] 用全国住房公积金小程序或 12329
- [ ] 查余额、缴存基数和月缴存额
- [ ] 单位少缴向公积金中心投诉

## 出问题找谁

- [ ] 工资少发：核对考勤和绩效，找 HR
- [ ] 社保漏缴：拨 12333 或向社保征收机构举报
- [ ] 公积金少缴：向公积金中心投诉
- [ ] 拖欠工资：向劳动保障监察投诉
