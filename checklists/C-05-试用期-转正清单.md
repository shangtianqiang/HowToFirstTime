# C-05 第一次过试用期 · 清单

> 打印后勾选。依据见 [C-05 正文](../book/03-工作与职业/C-05-第一次过试用期.md)。

## 入职时

- [ ] 核对试用期长度是否合法：合同 3 个月到 1 年最多 1 个月，1 到 3 年最多 2 个月，3 年以上最多 6 个月
- [ ] 同一单位只能约定一次试用期；被要求延长试用期，超过法定上限的无效
- [ ] 确认试用期工资：不低于同岗位最低档或合同工资的 80%，且不低于当地最低工资
- [ ] 要书面考核标准：考核指标、考核时间、由谁评定
- [ ] 确认社保开始缴纳月份，试用期也要缴，不能等转正
- [ ] 问清转正流程和生效日期

## 试用期

- [ ] 明确岗位职责和汇报关系
- [ ] 每周记录工作内容和成果
- [ ] 保存考核表、邮件、聊天记录，考核争议时这些是证据
- [ ] 按时提交周报月报
- [ ] 主动问反馈，别等最后一天
- [ ] 查社保缴费记录
- [ ] 想离职：提前 3 日通知单位，做好交接并留书面记录

## 转正前

- [ ] 对照考核标准逐项自查
- [ ] 准备转正申请，附工作总结和成果，记下材料截止时间
- [ ] 和直属领导沟通，确认是否有差距
- [ ] 核对工资条和社保公积金

## 转正后

- [ ] 收到书面转正通知，口头通知的要求补书面
- [ ] 确认生效日期和工资调整
- [ ] 确认社保公积金按新标准执行
- [ ] 试用期算工龄，包含在合同期限内

## 出问题找谁

- [ ] 不缴社保：社保稽核部门、12333
- [ ] 工资低于标准：劳动监察、仲裁
- [ ] 被辞退：要书面理由和证据，申请仲裁
- [ ] 被逼写"个人原因"辞职：拒绝并保留证据
- [ ] 考核不公：书面提出异议，要求复核，保留邮件和聊天记录
- [ ] 转正后被降薪：单方降薪需协商一致，否则可仲裁
