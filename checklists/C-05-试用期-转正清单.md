# C-05 第一次过试用期 · 清单

> 打印后勾选。依据见 [C-05 正文](../book/03-工作与职业/C-05-第一次过试用期.md)。

## 入职时

- [ ] 核对试用期长度是否合法
- [ ] 确认试用期工资
- [ ] 要书面考核标准
- [ ] 确认社保开始缴纳月份
- [ ] 问清转正流程和生效日期

## 试用期

- [ ] 明确岗位职责和汇报关系
- [ ] 每周记录工作成果
- [ ] 保存考核表、邮件、聊天记录
- [ ] 按时提交周报月报
- [ ] 主动问反馈
- [ ] 查社保缴费记录

## 转正前

- [ ] 对照标准自查
- [ ] 准备转正申请
- [ ] 和直属领导沟通差距
- [ ] 核对工资条和社保

## 转正后

- [ ] 收到书面转正通知
- [ ] 确认生效日期
- [ ] 确认工资调整
- [ ] 确认社保公积金基数

## 出问题找谁

- [ ] 不缴社保：社保稽核部门、12333
- [ ] 工资低于标准：劳动监察、仲裁
- [ ] 被辞退：要书面理由和证据，申请仲裁
- [ ] 被逼写“个人原因”辞职：拒绝并保留证据
