# C-06 第一次汇报/述职 · 清单

> 打印后勾选。依据见 [C-06 正文](../book/03-工作与职业/C-06-第一次汇报述职.md)。

## 准备

- [ ] 确认汇报对象和目的
- [ ] 确认时长和形式
- [ ] 拿到评分标准（如有）
- [ ] 列三个重点
- [ ] 统一数据口径
- [ ] 准备 10 个可能被问的问题

## 材料

- [ ] 第一页写结论
- [ ] 每页一个观点
- [ ] 数据有来源
- [ ] 细节放附录
- [ ] 准备 PDF 备份
- [ ] 提前 1 天发材料

## 现场

- [ ] 开场说明主题和时长
- [ ] 先讲结论
- [ ] 控制时间，留问答
- [ ] 不会的问题记下来
- [ ] 承诺回复时间

## 会后

- [ ] 发补充材料
- [ ] 回复未答问题
- [ ] 找关键听众沟通
- [ ] 记录改进点

## 出问题找谁

- [ ] 投影故障：用打印版或口头讲
- [ ] 时间被压缩：只讲结论和下一步
- [ ] 数据被质疑：说明来源，会后核对
- [ ] 领导缺席：会后单独补报
