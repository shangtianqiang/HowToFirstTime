# C-06 第一次汇报/述职 · 清单

> 打印后勾选。依据见 [C-06 正文](../book/03-工作与职业/C-06-第一次汇报述职.md)。

## 准备

- [ ] 确认汇报对象和目的
- [ ] 确认时长和形式，10 分钟汇报准备 8 分钟内容，留 2 分钟缓冲
- [ ] 拿到评分标准（如有）
- [ ] 列三个重点，其余放附录
- [ ] 统一数据口径：目标、完成、差距、原因用同一口径
- [ ] 准备 10 个可能被问的问题和答案出处
- [ ] 完整排练至少 3 遍，计时

## 材料

- [ ] 第一页写结论：做了什么、结果如何、要什么支持，配关键数字
- [ ] 10 分钟讲 8–12 页，每页一个观点
- [ ] 数据有来源，细节放附录
- [ ] 问题带方案，至少两个选项
- [ ] 下一步写清责任人、时间点、验收标准
- [ ] 备份文件放 U 盘、云端、邮件，不只存本地
- [ ] 准备 PDF 备份和打印版（如需）
- [ ] 提前 1 天发材料

## 现场

- [ ] 开场说明主题和时长
- [ ] 先讲结论，不从头讲流水账
- [ ] 控制时间，留问答
- [ ] 听完整问题再答，没听清先复述确认
- [ ] 不会的问题记下来
- [ ] 承诺回复时间，不硬编数据

## 会后

- [ ] 发补充材料
- [ ] 回复未答问题
- [ ] 找关键听众沟通
- [ ] 记录改进点

## 出问题找谁

- [ ] 投影故障：用打印版或口头讲结论，会后补发材料
- [ ] 时间被压缩：只讲结论和下一步
- [ ] 数据被质疑：说明来源和口径，会后核对
- [ ] 领导缺席：照常讲给主持人，会后单独补报
- [ ] 线上汇报断网：提前测试设备，备好电话接入方式
