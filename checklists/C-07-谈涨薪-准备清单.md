# C-07 第一次谈涨薪 · 清单

> 打印后勾选。依据见 [C-07 正文](../book/03-工作与职业/C-07-第一次谈涨薪.md)。

## 准备

- [ ] 选对时机
- [ ] 整理 12 个月业绩，带数字
- [ ] 查市场薪酬区间
- [ ] 明确目标涨幅和底线
- [ ] 准备备选方案
- [ ] 写面谈提纲

## 面谈

- [ ] 正式预约 30 分钟
- [ ] 先讲贡献
- [ ] 再讲诉求和数字
- [ ] 问清拒绝原因
- [ ] 约定下次评估时间
- [ ] 不威胁、不比较同事

## 结果

- [ ] 口头承诺发邮件确认
- [ ] 书面确认金额和生效日期
- [ ] 核对工资条
- [ ] 更新合同或调薪通知

## 出问题找谁

- [ ] 领导拖延：到期邮件跟进
- [ ] 公司违约：书面催告，申请仲裁
- [ ] 被穿小鞋：保留记录，评估换岗
- [ ] 决定跳槽：先拿书面 offer
