# C-07 第一次谈涨薪 · 清单

> 打印后勾选。依据见 [C-07 正文](../book/03-工作与职业/C-07-第一次谈涨薪.md)。

## 备齐依据

- [ ] 整理过去 12 个月业绩：目标、完成率、带来的收入或节省的成本
- [ ] 列出额外职责：带新人、跨部门项目、值班
- [ ] 截图保存招聘网站同岗位同城市的薪资区间
- [ ] 了解同级别同事的职责范围，不打听具体工资
- [ ] 看公司经营状况：财报、融资、裁员消息
- [ ] 定目标涨幅给区间（通常 10%–20%），写明底线和希望生效的月份
- [ ] 想好备选方案：调岗、增加补贴、远程天数、培训机会
- [ ] 备好一页业绩清单、市场薪酬截图、调薪申请邮件草稿和面谈提纲

## 选时机约面谈

- [ ] 挑绩效评估周期、项目交付后、公司业绩好时谈
- [ ] 公司裁员、亏损、领导刚换人时不提
- [ ] 邮件或即时通讯预约 30 分钟，说明想聊职业发展和薪酬
- [ ] 约在会议室正式谈，不在走廊、饭桌上提
- [ ] 试用期内不谈，转正评估时再谈

## 面谈沟通

- [ ] 先讲贡献再讲诉求，讲结果不只讲苦劳
- [ ] 给出明确数字和目标值，不只说"想涨一点"
- [ ] 对方说预算有限：问清是预算、绩效还是岗位级别问题
- [ ] 争取替代方案：分期调整、下次评估时间、补贴、培训
- [ ] 不拿同事工资比较，不威胁离职，不越级投诉
- [ ] 当场没结果，约定明确回复时间

## 结果确认

- [ ] 口头承诺当天发邮件确认
- [ ] 书面确认调薪金额、生效日期和发放方式
- [ ] 更新合同或拿书面调薪通知
- [ ] 看调薪是否牵动岗位、工时、绩效条款
- [ ] 调薪生效后核对工资条，金额不对当场提出

## 出问题找谁

- [ ] 领导拖延：到期邮件跟进
- [ ] 公司违反承诺：书面催告，必要时申请劳动仲裁
- [ ] 被穿小鞋：保留沟通记录，评估换部门或换公司
- [ ] 调薪后工作量暴增：重新评估职责和薪酬是否匹配
- [ ] 遭遇歧视性对待：保留证据，向 HR 或工会反映
- [ ] 决定跳槽：先拿书面 offer 再提离职，别裸辞
