# C-08 第一次跳槽 · 清单

> 打印后勾选。依据见 [C-08 正文](../book/03-工作与职业/C-08-第一次跳槽.md)。

## 拿到 offer 之后

- [ ] 拿到书面 offer 才提离职，不裸辞
- [ ] 确认 offer 答复期限和入职时间，给交接和休息留余量
- [ ] 比较总包：工资、奖金、补贴、公积金比例、通勤
- [ ] 背景调查可能联系前公司，提前和领导沟通

## 查合同算时间

- [ ] 查劳动合同期限和离职条款
- [ ] 查竞业限制协议及补偿标准
- [ ] 查服务期协议（培训违约金）和保密协议
- [ ] 算清未休年假天数，应按日工资 300% 折算（含正常工资）
- [ ] 留足 30 日通知期，从书面通知送达之日起算
- [ ] 社保月底离职、次月入职最稳，月中离职先问 HR 扣缴日

## 提离职

- [ ] 先和直属领导当面谈，再发正式离职邮件
- [ ] 邮件写明离职原因、最后工作日、交接安排
- [ ] 写通知不写"请批准"，离职不是申请
- [ ] 保留邮件发送记录和送达凭证

## 交接

- [ ] 列交接清单：文件、账号、客户、在办事项
- [ ] 每项写接收人、时间、状态
- [ ] 交接完成让接收人签字或邮件确认
- [ ] 归还设备、门禁卡、工牌，结清报销和借款
- [ ] 不带走客户名单和技术资料，商业秘密侵权会被追责

## 办手续与入职

- [ ] 离职证明盖公章，写明岗位和在职时间
- [ ] 解除后 15 日内办档案和社保转移，单位没办就催
- [ ] 确认最后工资、未休年假折算、报销款到账，保留工资条
- [ ] 入职新公司带离职证明、身份证、学历证、银行卡
- [ ] 确认新合同试用期和竞业条款
- [ ] 和新公司确认社保增员时间，别断缴

## 出问题找谁

- [ ] 单位不放人：书面通知满 30 日即可解除，保留送达证据
- [ ] 被威胁扣工资：向劳动监察投诉，申请仲裁
- [ ] 不给离职证明：劳动监察投诉，造成损失可主张赔偿
- [ ] 扣着档案：应 15 日内转移，投诉或申请仲裁
- [ ] 竞业被启动：单位按月付补偿、最长 2 年；满 3 个月没付可请求解除
- [ ] 新 offer 被撤回：看缔约过失责任，及时另找
