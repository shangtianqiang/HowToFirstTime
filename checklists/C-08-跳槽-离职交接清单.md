# C-08 第一次跳槽 · 清单

> 打印后勾选。依据见 [C-08 正文](../book/03-工作与职业/C-08-第一次跳槽.md)。

## 离职前

- [ ] 拿到书面 offer
- [ ] 确认新公司入职时间
- [ ] 查劳动合同离职条款
- [ ] 查竞业限制协议
- [ ] 算清未休年假
- [ ] 算好社保衔接日期

## 提离职

- [ ] 当面和领导沟通
- [ ] 发书面离职邮件
- [ ] 写明最后工作日
- [ ] 保留送达记录
- [ ] 不写“请批准”

## 交接

- [ ] 列交接清单
- [ ] 文件、账号、客户、在办事项
- [ ] 接收人签字或邮件确认
- [ ] 归还设备、门禁卡
- [ ] 结清报销和借款

## 办手续

- [ ] 离职证明
- [ ] 社保减员
- [ ] 公积金转移
- [ ] 档案转递
- [ ] 最后工资和年假折算
- [ ] 确认工资条

## 出问题找谁

- [ ] 不放人：满 30 日书面解除，保留证据
- [ ] 不给离职证明：劳动监察投诉
- [ ] 扣档案：投诉或仲裁
- [ ] 竞业纠纷：确认补偿，咨询律师
