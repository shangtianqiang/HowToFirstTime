# C-09 第一次被裁员 · 清单

> 打印后勾选。依据见 [C-09 正文](../book/03-工作与职业/C-09-第一次被裁员.md)。

## 收到通知

- [ ] 要书面解除通知
- [ ] 问清解除理由
- [ ] 记录最后工作日
- [ ] 拍照留存文件
- [ ] 不当场签字

## 核对补偿

- [ ] 算工作年限
- [ ] 算前 12 个月平均工资
- [ ] 算 N
- [ ] 核对代通知金
- [ ] 核对未休年假
- [ ] 核对奖金、报销
- [ ] 核对社保缴到哪个月

## 签字

- [ ] 逐条读协议
- [ ] 金额写清楚
- [ ] 不相信口头承诺
- [ ] 不签“个人原因”辞职
- [ ] 不签空白协议

## 离职后

- [ ] 拿离职证明
- [ ] 办失业登记
- [ ] 申领失业金
- [ ] 社保续缴
- [ ] 更新简历
- [ ] 保留所有证据

## 出问题找谁

- [ ] 拒付补偿：劳动仲裁
- [ ] 公司破产：向破产管理人申报
- [ ] 协议显失公平：咨询律师
- [ ] 心理压力：找家人、心理咨询
