# C-09 第一次被裁员 · 清单

> 打印后勾选。依据见 [C-09 正文](../book/03-工作与职业/C-09-第一次被裁员.md)。

## 收到通知当天

- [ ] 听清解除理由：经济性裁员、协商解除还是违法解除，补偿不同
- [ ] 要书面解除通知，写明解除理由、最后工作日、补偿方案
- [ ] 不让带走文件就拍照留存，事后邮件索要
- [ ] 不当场签字，带回去算清楚

## 收集材料

- [ ] 劳动合同
- [ ] 近 12 个月工资流水，含奖金、补贴
- [ ] 社保缴费记录、考勤、绩效、奖惩记录
- [ ] 裁员通知、会议记录、聊天记录

## 核对补偿

- [ ] 算工作年限：满 1 年算 1 个月，6 个月以上不满 1 年按 1 年，不满 6 个月算半个月
- [ ] 算月工资：解除前 12 个月平均应得工资，不是只算基本工资
- [ ] 月工资超当地社平工资 3 倍的按 3 倍算，年限最高 12 年
- [ ] 未提前 30 日通知的，核对代通知金 1 个月工资
- [ ] 违法解除可主张 2N 赔偿金
- [ ] 未休年假、年终奖、报销另算
- [ ] 问清社保、公积金缴到哪个月

## 签协议

- [ ] 逐条读协议，重点看放弃权利条款
- [ ] 补偿金额、支付时间写进协议，口头承诺不算
- [ ] 写"双方再无争议"前，确认款项已算清
- [ ] 不签空白协议和放弃权利声明
- [ ] 不签"个人原因"辞职书，签了没有补偿也领不了失业金

## 离职之后

- [ ] 拿离职证明、补偿协议、工资结算单
- [ ] 办失业登记：人社部门、街道社保所或线上平台
- [ ] 失业保险缴满 1 年、非本人意愿失业，可申领失业金
- [ ] 领失业金期间医保由失业保险基金缴纳，个人不用缴
- [ ] 社保断缴：以灵活就业身份参保，或尽快入职新单位
- [ ] 更新简历，先稳住生活再找工作
- [ ] 保留所有证据

## 出问题找谁

- [ ] 公司拒付补偿：申请劳动仲裁，不收费，必要时申请财产保全
- [ ] 公司破产：向破产管理人申报工资和补偿债权
- [ ] 协议显失公平：在法定期间内请求撤销，咨询律师
- [ ] 一次性补偿：当地上年职工平均工资 3 倍以内部分免征个税
- [ ] 心理压力大：找家人朋友、心理咨询
