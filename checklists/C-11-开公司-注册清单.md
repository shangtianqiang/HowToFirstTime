# C-11 第一次开公司/个体户 · 清单

> 打印后勾选。依据见 [C-11 正文](../book/03-工作与职业/C-11-第一次开公司个体户.md)。

## 决定前

- [ ] 选主体类型：个体户简单、税负轻；公司有限责任、便于融资招人
- [ ] 特殊行业（食品、医疗、教育等）先办许可证，再办执照或同步办理
- [ ] 收入规模决定小规模纳税人还是一般纳税人
- [ ] 确认是否雇人，涉及社保登记和劳动合同
- [ ] 算清注册和注销成本，别只看注册容易
- [ ] 不轻信"零元注册"，后续记账、地址、注销都可能收费

## 注册

- [ ] 准备 3–5 个名称备选，一网通办平台申报查重
- [ ] 经营范围参考国民经济行业分类，许可项目别乱写
- [ ] 备好经营场所证明：房产证或租赁合同
- [ ] 公司类的备公司章程和股东、法人、监事信息
- [ ] 注册资本认缴也是责任，别虚高
- [ ] 提交设立登记，审核通过后领电子或纸质执照

## 领照后手续

- [ ] 领执照后 30 日内办税务登记，核定税种和票种
- [ ] 刻公章、财务章、法人章、发票章
- [ ] 开对公账户，带执照、印章、法人身份证
- [ ] 签三方协议，用于税款扣缴
- [ ] 有雇员的，30 日内办社保登记
- [ ] 公司依法建账；找代理记账要签合同、留凭证

## 持续合规

- [ ] 按期申报，没收入也零申报，逾期会被处罚
- [ ] 保管发票和凭证
- [ ] 每年 1 月 1 日至 6 月 30 日报年报，不报进经营异常名录
- [ ] 地址变更及时登记，异常名录影响贷款和招投标
- [ ] 不经营及时办注销：税务注销、工商注销、银行销户

## 出问题找谁

- [ ] 名称被驳回：换字号，避开知名商标和禁用词
- [ ] 地址异常：提供真实地址材料申请移出异常名录
- [ ] 税务异常：补申报、补缴税款和罚款，找主管税务机关
- [ ] 年报漏报：尽快补报，申请移出经营异常名录
- [ ] 被冒名登记：向登记机关申请撤销，报警并保留笔迹鉴定材料
