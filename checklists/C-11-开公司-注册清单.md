# C-11 第一次开公司/个体户 · 清单

> 打印后勾选。依据见 [C-11 正文](../book/03-工作与职业/C-11-第一次开公司个体户.md)。

## 决定前

- [ ] 选主体类型
- [ ] 评估风险和税负
- [ ] 确认是否需要行业许可
- [ ] 算清注册和注销成本
- [ ] 准备 3–5 个名称

## 注册

- [ ] 名称申报
- [ ] 经营范围
- [ ] 经营场所证明
- [ ] 注册资本和股东信息
- [ ] 提交设立登记
- [ ] 领执照

## 开业

- [ ] 刻章
- [ ] 开对公账户
- [ ] 签三方扣税协议
- [ ] 税务登记
- [ ] 核定票种
- [ ] 社保登记（有雇员）
- [ ] 建账或找代理记账

## 持续合规

- [ ] 按期申报，没收入也零申报
- [ ] 保管发票和凭证
- [ ] 每年 6 月 30 日前报年报
- [ ] 地址变更及时登记
- [ ] 不经营及时注销

## 出问题找谁

- [ ] 名称驳回：换字号
- [ ] 地址异常：提交真实材料申请移出
- [ ] 税务异常：补申报、补缴
- [ ] 被冒名登记：申请撤销并报警
