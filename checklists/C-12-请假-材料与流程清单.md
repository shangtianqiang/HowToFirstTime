# C-12 第一次请年假/病假/婚假 · 清单

> 打印后勾选。依据见 [C-12 正文](../book/03-工作与职业/C-12-第一次请年假病假婚假.md)。

## 先查清天数

- [ ] 年假按累计工作年限算，不是只算本单位
- [ ] 对照天数：累计满 1 年不满 10 年 5 天，10–20 年 10 天，20 年以上 15 天
- [ ] 新入职当年按剩余日历天数折算
- [ ] 法定节假日和休息日不计入年假
- [ ] 婚假国家 3 天，各省另有奖励假，问 HR 当地天数
- [ ] 丧假直系亲属 1–3 天，外地奔丧路程另算，工资照发
- [ ] 问 HR：年假余额、能否跨年、审批人是谁

## 准备材料

- [ ] 年假提前 3–7 天申请，婚假提前 1–2 周
- [ ] 病假：医院病假条、病历、缴费单，及时通知公司
- [ ] 病假条造假属严重违纪，可能被解除
- [ ] 婚假附结婚证，丧假附死亡证明或亲属关系证明
- [ ] OA 或书面请假单，别只口头说

## 提交与交接

- [ ] 写清假别、起止时间、事由、交接人
- [ ] 附上对应证明材料，保留提交和审批记录
- [ ] 列出请假期间在办事项和接手人
- [ ] 和接手人当面交接：共享文件权限、客户联系方式
- [ ] 设置邮件自动回复，告知紧急联系人

## 休假与返岗

- [ ] 保持紧急联系方式畅通，日常事务不必处理
- [ ] 病假遵医嘱休息，保留复诊记录
- [ ] 返岗当天销假，考勤恢复正常
- [ ] 核对工资条：应休未休年假按日工资 300% 支付（含正常工资）
- [ ] 病假工资不低于当地最低工资标准的 80%
- [ ] 确认年假余额

## 出问题找谁

- [ ] 不批年假：书面申请保留记录，向劳动监察投诉或申请仲裁
- [ ] 病假被拒：提交病假条书面说明，必要时劳动监察投诉
- [ ] 医疗期内被辞退：不得解除，主张补偿
- [ ] 医疗期满被解除：主张经济补偿和医疗补助费
- [ ] 年假被强制清零：保留考勤和申请记录，申请仲裁
- [ ] 婚假被要求上班：保留通知记录，拒绝或要求补休
