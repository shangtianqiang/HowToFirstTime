# C-12 第一次请年假/病假/婚假 · 清单

> 打印后勾选。依据见 [C-12 正文](../book/03-工作与职业/C-12-第一次请年假病假婚假.md)。

## 请假前

- [ ] 查年假余额和累计工龄
- [ ] 确认假别和天数
- [ ] 查公司请假制度
- [ ] 准备证明材料
- [ ] 列交接清单

## 提交

- [ ] OA 或书面申请
- [ ] 写清起止时间和事由
- [ ] 附病假条、结婚证等
- [ ] 指定接手人
- [ ] 保留提交记录

## 休假中

- [ ] 完成交接
- [ ] 设置邮件自动回复
- [ ] 紧急联系方式畅通
- [ ] 病假遵医嘱，保留复诊记录

## 返岗

- [ ] 当天销假
- [ ] 核对考勤
- [ ] 核对工资条
- [ ] 确认年假余额

## 出问题找谁

- [ ] 不批年假：书面申请，劳动监察
- [ ] 病假被拒：提交病假条，投诉
- [ ] 年假清零：保留记录，申请仲裁
- [ ] 医疗期被辞退：主张补偿和医疗补助
