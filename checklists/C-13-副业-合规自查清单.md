# C-13 第一次做副业/接私活 · 清单

> 打印后勾选。依据见 [C-13 正文](../book/03-工作与职业/C-13-第一次做副业与接私活.md)。

## 接活前

- [ ] 重读劳动合同，确认兼职限制、保密、知识产权条款
- [ ] 查员工手册和规章制度里对兼职的规定
- [ ] 签过竞业限制协议的，确认是否在限期内、禁做范围是什么
- [ ] 筛掉与主业同客户、同业务的单子
- [ ] 评估每周可投入时间，不影响本职产出
- [ ] 只用自己的电脑、账号和素材

## 谈单与签约

- [ ] 书面确认工作范围、交付物清单、修改次数
- [ ] 合同写明总价和付款节点（预付款＋验收后付尾款）
- [ ] 写明验收标准和知识产权归属
- [ ] 甲方加的排他条款、违约金条款看清再签
- [ ] 双方签字或确认，各留一份

## 交付与收款

- [ ] 按约定时间交付，保留文件和沟通记录
- [ ] 对照合同验收标准逐条核对
- [ ] 尾款到账再交源文件或授权
- [ ] 转账备注写清项目和款项用途
- [ ] 记录每笔收入：日期、客户、金额、税款

## 报税

- [ ] 确认支付方是否已按劳务报酬预扣预缴
- [ ] 次年 3 月 1 日至 6 月 30 日在个人所得税 App 办理年度汇算
- [ ] 汇算结果留存备查
- [ ] 客户要发票的，先打 12366 问清代开流程

## 出问题找谁

- [ ] 被公司约谈或质疑：对照公司制度，按要求整改，拿不准打 12333
- [ ] 客户拖欠尾款：书面催告留证，按合同争议条款处理，法律援助打 12348
- [ ] 交付被指不合格：拿出书面验收标准逐条对照
- [ ] 收到补税通知：按汇算结果办理，操作疑问打 12366
