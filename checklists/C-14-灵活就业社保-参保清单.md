# C-14 第一次缴灵活就业社保 · 清单

> 打印后勾选。依据见 [C-14 正文](../book/03-工作与职业/C-14-第一次缴灵活就业社保.md)。

## 决定参保方案

- [ ] 想好参保地：优先常住的就业地，落地不了回户籍地
- [ ] 拨 12333 确认就业地是否已放开户籍限制
- [ ] 查当地养老档位表和医保缴费比例（人社、医保局官网）
- [ ] 算月预算：社平工资×档位×20%，加上医保
- [ ] 了解就业困难人员认定条件，判断能否领社保补贴

## 准备材料与账号

- [ ] 身份证原件或电子身份证
- [ ] 银行卡（余额充足，建议一类卡）
- [ ] 掌上 12333 App 已注册实名
- [ ] 电子税务局 App 已注册实名
- [ ] 记下三个号码：12333 人社、12366 税务、12393 医保

## 办理

- [ ] 先办养老参保登记（掌上 12333、国家社保平台或经办窗口）
- [ ] 再办医保参保登记（医保经办机构或政务 App，能联办的一次办完）
- [ ] 登记成功后再去税务渠道缴费
- [ ] 选养老档位和缴费方式（按月、季、半年、年）
- [ ] 电子税务局 App 里选「灵活就业人员正常缴费」，本人或他人代缴
- [ ] 缴款成功后保存回执
- [ ] 需要省事就签银行代扣协议，扣款日留够余额

## 缴费后确认

- [ ] 电子税务局里查缴费记录
- [ ] 掌上 12333 或电子社保卡查权益记录，确认个人账户到账
- [ ] 医保待遇状态显示正常
- [ ] 符合条件的，去街道或人社部门做就业困难认定并申请补贴

## 每年例行

- [ ] 留意当地新公布的缴费基数和档位金额
- [ ] 核对扣款是否成功，余额不足及时补
- [ ] 收入变化时考虑上调或下调档位

## 出问题找谁

- [ ] 登记办不下来：拨 12333 问人社经办
- [ ] 缴费失败、多缴重复缴：拨 12366 问税务
- [ ] 医保待遇、断缴补缴：拨 12393 问医保
- [ ] 断缴超 3 个月：先问清当地等待期月数再补缴
- [ ] 跨省搬家：国家社保平台或掌上 12333 发起养老转移
