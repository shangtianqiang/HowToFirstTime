# C-15 第一次工伤认定与申报 · 清单

> 打印后勾选。依据见 [C-15 正文](../book/03-工作与职业/C-15-第一次工伤认定与申报.md)。

## 出事当天

- [ ] 送医治疗，如实告知是工作中受的伤
- [ ] 取病历、诊断证明、检查报告、缴费票据
- [ ] 拍现场环境、涉事设备、地面、伤情照片
- [ ] 记下在场同事姓名和电话
- [ ] 向班组长/人事报告，留聊天记录或邮件
- [ ] 车祸的：打 122 报警，等事故责任认定书

## 证据袋（认定申请前备齐）

- [ ] 工伤认定申请表
- [ ] 劳动关系证明：合同；没合同的备工资流水、社保记录、工牌、考勤、同事证言
- [ ] 医疗诊断证明；职业病的备职业病诊断证明书
- [ ] 事故责任认定书（交通事故）
- [ ] 全套复印留底，原件自己保管

## 提交与跟进

- [ ] 单位 30 日内不报：自己向人社局工伤认定窗口交
- [ ] 拿《工伤认定申请受理决定书》
- [ ] 被要求补正的，按一次性书面告知单补齐
- [ ] 盯 60 日认定时限；事实清楚的 15 日内出
- [ ] 拿到《认定工伤决定书》或《不予认定工伤决定书》
- [ ] 伤情稳定后仍留残疾的：申请劳动能力鉴定
- [ ] 拿鉴定结论书，核对伤残等级（一级最重，十级最轻）

## 待遇核对

- [ ] 医疗费按工伤保险目录由基金支付
- [ ] 停工留薪期工资按原待遇按月发放
- [ ] 一次性伤残补助金按等级月数核发（7–27 个月本人工资）
- [ ] 离职时申领一次性工伤医疗补助金、一次性伤残就业补助金
- [ ] 单位没参保：待遇由单位按条例标准支付，拒付走仲裁

## 时限红线

- [ ] 个人申请：事故发生之日起 1 年内
- [ ] 对市级鉴定结论不服：收到之日起 15 日内申请再次鉴定
- [ ] 对不予认定不服：申请行政复议或提起行政诉讼
- [ ] 复议或诉讼的期限：问当地人社局或 12333

## 出问题找谁

- [ ] 流程、材料、时限：12333、当地人社局工伤认定窗口
- [ ] 单位拒付待遇：劳动人事争议仲裁委员会
- [ ] 劳动关系被否认：先备凭证再申请；有争议的按当地指引先仲裁确认
- [ ] 超 1 年或 48 小时等边缘情形：带材料去人社局工伤科当面问
