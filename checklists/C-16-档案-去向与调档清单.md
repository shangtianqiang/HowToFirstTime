# C-16 第一次处理毕业生档案 · 清单

> 打印后勾选。依据见 [C-16 正文](../book/03-工作与职业/C-16-第一次处理毕业生档案.md)。

## 毕业离校前

- [ ] 在 dj.ncss.cn 登记毕业去向，核对单位和生源地信息
- [ ] 问学校档案室：转出时间、去向机构、转递单号
- [ ] 未就业的：申请留校两年，或登记转回生源地
- [ ] 党员/团员：另行办理组织关系转接

## 毕业后自查

- [ ] 登录 zwfw.mohrss.gov.cn 查「档案存档情况」
- [ ] 线上查不到的：打生源地人才中心电话，报身份证号查
- [ ] 记下存档机构名称和电话，存进手机

## 用档时（政审/入职/落户）

- [ ] 由接收单位开调档函，看清有效期
- [ ] 调档函交给存档机构，登记转递
- [ ] 2–4 周后向接收单位确认档案到达
- [ ] 政审前查一次档案内材料清单，缺的早补

## 出问题找谁

- [ ] 不知道档案在哪：学校档案室 → 生源地人才中心 → 12333
- [ ] 档案在自己手里：联系户籍地人才机构申请存入
- [ ] 怀疑丢失：沿学校→机要→接收机构转递链逐环节追
