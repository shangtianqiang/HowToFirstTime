# C-16 第一次处理毕业生档案 · 清单

> 打印后勾选。依据见 [C-16 正文](../book/03-工作与职业/C-16-第一次处理毕业生档案.md)。

## 毕业离校前

- [ ] 在 dj.ncss.cn 登记毕业去向，按真实情况填：单位、升学、出国、灵活就业、暂不就业
- [ ] 核对去向信息：单位全称、生源地地址，写错档案就转错
- [ ] 问学校档案室：何时转出、转到哪个机构、有没有转递单号
- [ ] 未就业的：申请留校两年，或转回生源地人才机构
- [ ] 档案由学校机要或邮政特快密封转递，不自己经手、不自带
- [ ] 党员/团员：另行办理组织关系转接，和档案转递是两件事

## 毕业后自查

- [ ] 登录 zwfw.mohrss.gov.cn 查「档案存档情况」，记下存档机构和编号
- [ ] 线上查不到：打生源地人才中心电话，报身份证号查
- [ ] 多数学校毕业后 1–2 个月内完成转递，刚毕业查不到先等等
- [ ] 存档机构名称和电话存进手机
- [ ] 现场办手续带身份证、毕业证或学信网学历在线验证报告

## 用档时（政审/入职/落户）

- [ ] 由接收单位开调档函，看清有效期，别压着过期
- [ ] 调档函交给存档机构，机构之间机要转递，个人不接触档案
- [ ] 2–4 周后向接收单位确认档案到达
- [ ] 政审或入职前查一次档案内材料清单，缺的早补
- [ ] 不随跳槽反复迁移，等有政审、落户、职称需要时再调

## 铁律与红线

- [ ] 档案在自己手里：联系户籍地人才机构申请存入，多数机构拒收自带
- [ ] 个人不拆封，拆封可能被拒收，要回原单位重新审核密封
- [ ] 不找「档案代办」中介：存档、转递、查询全程免费，中介代存不合规
- [ ] 存档费、转递费 2015 年 1 月 1 日起已取消，公共机构收费就打 12333

## 出问题找谁

- [ ] 不知道档案在哪：学校就业指导中心 → 生源地人才中心 → 12333
- [ ] 怀疑丢失：沿学校 → 机要部门 → 接收机构转递链逐环节追
- [ ] 网上查不到不等于丢了：先打电话，线下窗口最准
- [ ] 学校已合并撤销：找合并后院校档案部门或当地教育局
