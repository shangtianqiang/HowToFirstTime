# D-01 学外语 · 90 天清单

> 打印后勾选。依据见 [D-01 正文](../book/04-学习与技能/D-01-第一次学外语入门.md)。

## 开始前

- [ ] 选定一门你真正会用的语言，兴趣、工作、旅行都可以
- [ ] 查 CEFR 等级描述，零基础先冲 A1，定一个 90 天目标
- [ ] 目标写成可检查的动作：自我介绍、问路、点餐、购物，不写"学好""流利"
- [ ] 选一套主教材和一套慢速、有文本的听力材料，不要同时开三套
- [ ] 定每天固定时段，入门阶段每天练 30–60 分钟
- [ ] 准备录音工具，跟读时录音和示范音对比

## 第 1 周

- [ ] 学字母、假名或拼读规则，练 5 个元音
- [ ] 学 10 个常用句，能说 3 句自我介绍
- [ ] 高频词放进句子里学，不背孤立的单词表
- [ ] 不用中文谐音记发音，后面很难改
- [ ] 每天录音一次，和示范音对比

## 第 1 个月

- [ ] 每天完成固定任务量，先保住"每天都碰一下"
- [ ] 旧词按当天、次日、3 天、1 周、2 周、1 月各复习一次
- [ ] 每周留一天复习，不学新内容
- [ ] 每周复盘一次，看哪天断了、为什么断
- [ ] 把学到的句子用出来，哪怕对自己说

## 第 2 个月

- [ ] 加入分级读物或慢速听力，每天听或读一段短材料
- [ ] 圈出生词但不逐个查，能懂大意就算过
- [ ] 材料太难就降一级，先别啃原版小说
- [ ] 每周做一次复述或短写作
- [ ] 找语伴或老师纠正一次发音，模仿语音语调

## 第 3 个月

- [ ] 做一次 CEFR 自评或模考，测听说读写找出最弱项
- [ ] 录一段自我介绍，和第一个月对比
- [ ] 目标能完成 1–2 分钟连续表达，找不到语伴先录音自问自答
- [ ] 下一轮 90 天计划加练最弱项

## 出问题找谁

- [ ] 坚持不下去：任务减半，先保住每天 10 分钟
- [ ] 发音纠正：录音对比，找老师或语伴听一次，不要自己猜
- [ ] 平台期：换材料、加输出、降难度，三选一
- [ ] 资源选择困难：只保留一套主教材、一套听力、一个词汇工具
- [ ] 别信"30 天流利"承诺：A1 约 90–100 小时，按指导学时估算
- [ ] 考试报名：IELTS、JLPT、TOPIK 等，官网查时间和费用
