# D-01 学外语 · 90 天清单

> 打印后勾选。依据见 [D-01 正文](../book/04-学习与技能/D-01-第一次学外语入门.md)。

## 开始前

- [ ] 选定一门语言
- [ ] 查 CEFR 等级描述，定一个 90 天目标
- [ ] 选一套主教材和一套听力材料
- [ ] 定每天固定学习时段和时长
- [ ] 准备录音工具，用于跟读对比

## 第 1 周

- [ ] 学字母或拼读规则
- [ ] 练基础发音
- [ ] 记 20–30 个高频词
- [ ] 学会 10 句日常用语
- [ ] 每天录音一次，和示范音对比

## 第 1 个月

- [ ] 每天完成固定任务量
- [ ] 每周复习一次旧词
- [ ] 开始短句跟读
- [ ] 记录卡住的地方

## 第 2 个月

- [ ] 加入分级读物或慢速听力
- [ ] 每周做一次复述或短写作
- [ ] 找语伴或老师纠正一次

## 第 3 个月

- [ ] 做一次 CEFR 自评或模考
- [ ] 录一段自我介绍，和第一个月对比
- [ ] 按结果调整下一个 90 天计划

## 出问题找谁

- [ ] 坚持不下去：任务减半，先保住每天 10 分钟
- [ ] 发音纠正：录音对比，找老师或语伴
- [ ] 平台期：换材料、加输出、降难度
- [ ] 资源选择困难：只保留一套主教材、一套听力、一个词汇工具
- [ ] 考试报名：查对应考试机构官网
