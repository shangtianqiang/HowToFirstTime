# D-02 学车 · 流程清单

> 打印后勾选。依据见 [D-02 正文](../book/04-学习与技能/D-02-第一次学车.md)。

## 报名前

- [ ] 想清楚 C1 还是 C2：C1 手动挡自动挡都能开，C2 只能开自动挡
- [ ] C2 不考坡道起步，项目少一项，练车通常轻松一些
- [ ] 多看几家驾校的资质、场地、教练、考试通过率
- [ ] 看清合同里的学费、补考费、模拟费、接送费和退费条款
- [ ] 确认身体条件：18 周岁以上，视力 4.9 以上，无红绿色盲
- [ ] 异地申领 C 类驾照凭身份证即可，不需要居住证

## 报名与学时

- [ ] 备好身份证、照片、体检表，在驾校或车管所报名，签培训合同
- [ ] 拿到学习驾驶证明，记住有效期 3 年
- [ ] 确认学时安排，学时不够不能约考
- [ ] 装交管 12123，预约考试、查可预约状态

## 科目一

- [ ] 刷完题库，弄懂错题
- [ ] 预约考试，100 分满分，90 分合格
- [ ] 考完确认成绩已记录
- [ ] 不合格按当地规定重新预约

## 科目二与科目三

- [ ] C1 练倒车入库、坡道定点停车和起步、侧方停车、曲线行驶、直角转弯
- [ ] 科目二 80 分合格，练不会的项目问教练加练
- [ ] 科目三按考试路线练起步、变道、路口、靠边停车，里程不少于 3 公里
- [ ] 科目三 90 分合格
- [ ] 考场模拟费问清是否自愿，别被强制捆绑

## 拿证与实习期

- [ ] 科目四刷完题库，90 分以上合格
- [ ] 领取驾驶证，核对准驾车型和有效期
- [ ] 贴实习标志，实习期 12 个月
- [ ] 实习期上高速，要有 3 年以上驾龄的驾驶人陪同
- [ ] 记分周期 12 个月，满分 12 分
- [ ] 有效期满前 90 日内申请换证；6 年内无满分记录换 10 年证

## 出问题找谁

- [ ] 考试不过：10 日后重新预约；科目二、科目三各最多 5 次
- [ ] 第 5 次仍不合格：已合格的其他科目成绩作废
- [ ] 想换驾校：先看合同退费条款，档案转移问车管所
- [ ] 拿证不敢上路：找正规陪练，先在车少的路段练
- [ ] 驾照丢失或到期：交管 12123 或车管所补办、换证
- [ ] 乱收费或吃拿卡要：补考、模拟费要发票，留证据向交通、市场监管部门投诉
