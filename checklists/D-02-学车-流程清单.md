# D-02 学车 · 流程清单

> 打印后勾选。依据见 [D-02 正文](../book/04-学习与技能/D-02-第一次学车.md)。

## 报名前

- [ ] 确认 C1 还是 C2
- [ ] 比较 2–3 家驾校的资质、场地、教练和费用
- [ ] 看清合同里的学费、补考费、模拟费、退费条款
- [ ] 确认报名条件和体检要求

## 报名

- [ ] 准备身份证、照片、体检表
- [ ] 在驾校或车管所报名
- [ ] 确认学时安排和练车时间
- [ ] 下载交管 12123，完成注册

## 科目一

- [ ] 刷完题库
- [ ] 预约考试
- [ ] 90 分以上合格，确认成绩

## 科目二

- [ ] 完成场地练习学时
- [ ] 熟悉考场和项目
- [ ] 预约考试
- [ ] 80 分以上合格，确认成绩

## 科目三

- [ ] 完成道路练习学时
- [ ] 熟悉考试路线和项目
- [ ] 预约考试
- [ ] 90 分以上合格，确认成绩

## 科目四

- [ ] 刷完题库
- [ ] 预约考试
- [ ] 90 分以上合格，确认成绩

## 拿证后

- [ ] 领取驾驶证
- [ ] 确认实习期 12 个月和实习标志
- [ ] 确认记分周期和换证时间
- [ ] 需要陪练就找正规陪练

## 出问题找谁

- [ ] 考试不过：10 日后重新预约；科目二、科目三各最多 5 次
- [ ] 想换驾校：先看合同退费条款
- [ ] 学时不够：和驾校协商加练
- [ ] 驾照丢失或到期：交管 12123 或车管所
- [ ] 驾校乱收费：保留证据，向当地交通、市场监管部门投诉
