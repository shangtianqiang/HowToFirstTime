# D-03 第一次考职业资格证 · 清单

> 打印后勾选。依据见 [D-03 正文](../book/04-学习与技能/D-03-第一次考职业资格证.md)。

## 选证

- [ ] 查《国家职业资格目录》，确认证书名称和实施部门
- [ ] 分清准入类和水平评价类，目录外多为培训证书
- [ ] 核对报名条件：学历、专业、工作年限、社保，报名时就要符合
- [ ] 确认证书用途：求职、晋升、积分落户、个税扣除
- [ ] 不买山寨证书："国际认证""高级人才证"求职不认
- [ ] 不信"包过"和挂靠：违规可能撤销证书、罚款，出事故担责

## 报名

- [ ] 备齐身份证、学历证书和学信网备案表
- [ ] 工作年限证明要单位盖章，必须真实
- [ ] 电子照片按规格准备，填好报名表
- [ ] 部分考试要社保记录或居住证，提前确认
- [ ] 网上报名后跟进资格审核，不通过按通知补材料
- [ ] 按科目缴费并保留凭证，报名成功不等于缴费成功

## 备考

- [ ] 下载最新考试大纲，按大纲复习
- [ ] 买官方指定教材，不买"内部押题""绝密资料"
- [ ] 按基础、强化、冲刺三阶段制定计划
- [ ] 真题至少刷 3 遍，整理错题
- [ ] 告知承诺制不是空话：条件造假会取消成绩并记入诚信档案

## 考试

- [ ] 考前一周左右打印准考证，核对姓名、考场、时间
- [ ] 带身份证、准考证、文具，提前到场
- [ ] 遵守考场规则，看清禁带物品
- [ ] 突发不适立即告知监考，必要时拨 120

## 考后与领证

- [ ] 在报名系统或主管部门官网查成绩，不信"改分"信息
- [ ] 多数考试滚动管理，2 年或 4 年内通过全部科目
- [ ] 电子证书官网查询下载，与纸质证书同等效力
- [ ] 核对证书信息，纸质证书按通知领取
- [ ] 取得证书当年可按继续教育专项附加扣除申报个税

## 出问题找谁

- [ ] 审核不通过：按通知补材料，截止前提交
- [ ] 错过报名：等下一次，别信"补报名"中介
- [ ] 考试当天证件丢失：找考点考务办，按规则处理
- [ ] 成绩有异议：按公告在规定时限内申请复核
- [ ] 证书遗失：官网申请补办电子证书或按通知补发
- [ ] 代报名：泄露个人信息，条件不够也报不上，别找
