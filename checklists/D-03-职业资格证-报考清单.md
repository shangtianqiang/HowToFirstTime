# D-03 第一次考职业资格证 · 清单

> 打印后勾选。依据见 [D-03 正文](../book/04-学习与技能/D-03-第一次考职业资格证.md)。

## 选证

- [ ] 查国家职业资格目录
- [ ] 分清准入类和水平评价类
- [ ] 核对学历、专业、工作年限
- [ ] 确认证书用途
- [ ] 不买山寨证书

## 报名

- [ ] 身份证
- [ ] 学历证书和备案表
- [ ] 工作年限证明
- [ ] 电子照片
- [ ] 网上报名
- [ ] 资格审核
- [ ] 缴费并保留凭证
- [ ] 打印准考证

## 备考

- [ ] 下载最新考试大纲
- [ ] 买官方教材
- [ ] 制定三阶段计划
- [ ] 真题刷 3 遍
- [ ] 整理错题
- [ ] 模拟计时

## 考试

- [ ] 带身份证和准考证
- [ ] 提前到考点
- [ ] 遵守考场规则
- [ ] 不携带电子设备

## 考后

- [ ] 查成绩
- [ ] 下载电子证书
- [ ] 核对证书信息
- [ ] 申报个税继续教育扣除（如适用）

## 出问题找谁

- [ ] 审核不通过：按通知补材料
- [ ] 证件丢失：找考点考务办
- [ ] 成绩异议：申请复核
- [ ] 改分诈骗：不理，官方渠道查分
