D-04 第一次自学编程 · 清单

开始前打基础（第 1–6 周）做项目（第 7–12 周）进阶出问题找谁

打印后勾选。依据见 D-04 正文。

开始前

  • 选定一个方向：网页前端、数据分析、自动化办公、移动端
  • 按方向选语言：前端 JavaScript，数据分析 Python，企业应用 Java 或 C#
  • 看招聘要求，确认方向有需求
  • 电脑内存 8GB 以上，装好编辑器和运行时
  • 装 Git，注册 GitHub 或 Gitee 账号
  • 定 12 周计划：每天 1–2 小时，坚持 3 个月能看到成果

打基础（第 1–6 周）

  • 第 1–2 周完成环境搭建，跑通 Hello World
  • 学变量、条件、循环、函数，跟着示例代码敲
  • 第 3–6 周学数据结构和文件操作
  • 看一遍、敲一遍、改一遍，不做"只看不练"
  • 每周留一天复习，不追进度

做项目（第 7–12 周）

  • 选一个真实小需求，拆成小任务
  • 第 7–10 周做出核心功能，项目能跑通
  • 初始化仓库，用 Git 提交和推送
  • 初始化仓库，用 Git 提交、推送，写 README
  • 第 11–12 周部署上线，别人能通过链接访问
  • 部署后看访问日志和错误日志

进阶

  • 入门看视频快，进阶读官方文档
  • 学看报错、日志和开发者工具，提问附上代码、报错和环境
  • 求职笔试再补算法，先能做项目
  • 作品比证书重要：GitHub 项目、可访问的作品、技术博客

出问题找谁

  • 环境装不上：查官方安装文档，或用在线环境
  • 卡在同一问题：换搜索关键词，去官方论坛或社区问，别自己硬扛
  • 高价"包就业"课：承诺不写进合同就是坑，先试学 2 周
  • 被诈骗课程：保留付款记录，向平台投诉或拨 12315
  • 电脑配置低：用在线编辑器或轻量工具
  • 眼睛、颈椎不适：控制时长，定时休息
