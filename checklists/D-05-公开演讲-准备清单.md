# D-05 第一次公开演讲 · 清单

> 打印后勾选。依据见 [D-05 正文](../book/04-学习与技能/D-05-第一次公开演讲.md)。

## 准备

- [ ] 确认听众和时长
- [ ] 定一个核心观点
- [ ] 列三个要点和例子
- [ ] 写开场和结尾
- [ ] 做 PPT，每页一个观点
- [ ] 准备关键词卡

## 排练

- [ ] 完整讲 3 遍
- [ ] 录音回听
- [ ] 计时
- [ ] 标记可删部分
- [ ] 练问答

## 到场

- [ ] 提前 30 分钟
- [ ] 试投影、麦克风、翻页器
- [ ] 准备 PDF 备份
- [ ] 熟悉上台动线
- [ ] 喝水、深呼吸

## 演讲

- [ ] 30 秒内抓住注意
- [ ] 三个要点讲清
- [ ] 不照读 PPT
- [ ] 看时间
- [ ] 结尾回扣观点

## 出问题找谁

- [ ] 投影坏了：用打印稿
- [ ] 忘词：看关键词卡
- [ ] 被问住：记下，承诺回复
- [ ] 超时：跳到结尾
