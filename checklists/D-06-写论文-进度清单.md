# D-06 第一次写论文 · 清单

> 打印后勾选。依据见 [D-06 正文](../book/04-学习与技能/D-06-第一次写论文.md)。

## 选题与开题

- [ ] 从课程、实习、导师课题里找问题，和导师确认选题
- [ ] 题目要小：一个变量、一个案例、一个时间段
- [ ] 确认有数据和文献支撑再定题
- [ ] 和导师确认范围、方法和时间表
- [ ] 提交开题报告，开题通过再动笔

## 文献

- [ ] 用学校图书馆、知网、万方检索，先读综述
- [ ] 再读近 5 年核心文献，先读 20–30 篇
- [ ] 记录作者、年份、方法、结论和可引用观点
- [ ] 用文献管理工具整理，避免找不到出处
- [ ] 边读边写文献综述，不必全部精读

## 数据与写作

- [ ] 实验、问卷、访谈按伦理要求做，要知情同意
- [ ] 数据备份两份，原始记录留存
- [ ] 不编造数据，数据不够就补做实验或缩小范围
- [ ] 先写提纲，再填内容
- [ ] 先写方法和结果，再写讨论和引言
- [ ] 每天固定字数，别等到最后
- [ ] 每引用一个观点立刻标出处，转述也要注明
- [ ] 参考文献按学校模板和 GB/T 7714 格式

## 查重与定稿

- [ ] 用学校指定系统查重，提前 1–2 个月
- [ ] 查重率参考：本科 20%–30%，硕士 10%–15%，以学校规定为准
- [ ] 查重没过逐句改写保留原意，不用"降重软件"
- [ ] 按导师意见逐条修改，保留修改记录
- [ ] 自查逻辑错别字，请同学互读，核对学校模板：封面、目录、页码、致谢

## 答辩

- [ ] 做 10–15 页 PPT，讲研究问题、方法、结果、结论
- [ ] 排练 2–3 遍，控制在规定时间
- [ ] 准备可能被问的 10 个问题
- [ ] 打印装订按学校要求

## 出问题找谁

- [ ] 查重过高：逐段改写，规范引用
- [ ] 数据丢失：从备份恢复，必要时重做
- [ ] 导师失联：约见面，发简明进度邮件
- [ ] 答辩未过：按意见修改，申请二次答辩
- [ ] 数据造假或抄袭：学术不端可能撤销学位；被误判按学校程序申诉，提供原始数据
