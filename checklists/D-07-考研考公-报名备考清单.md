# D-07 第一次考研/考公 · 清单

> 打印后勾选。依据见 [D-07 正文](../book/04-学习与技能/D-07-第一次考研考公.md)。

## 确定目标

- [ ] 选考试类型：考研看研招网，国考看国家公务员局，省考看各省人事考试网
- [ ] 看近 3 年公告和分数线，判断难度
- [ ] 核对条件：学历、专业、政治面貌、基层经历
- [ ] 考公年龄一般 18 周岁以上、35 周岁以下，应届硕士博士可放宽
- [ ] 确认考试科目和参考书目
- [ ] 主攻一个，另一个当备选，时间会冲突

## 报名

- [ ] 记住时间线：考研 9 月预报名、10 月正式报名、12 月下旬初试、次年 3–4 月复试；国考 10 月报名、11–12 月笔试
- [ ] 备齐身份证、学历学位证书、学信网备案表、电子照片
- [ ] 报名信息一次填对，专业、报考点、学习方式逐项核对
- [ ] 截止前可修改，截止后一般不能改；别在最后一天报
- [ ] 核对报名号，缴费成功才算报名完成
- [ ] 按报考点要求完成网上确认

## 备考

- [ ] 下载官方大纲，买真题，不迷信押题
- [ ] 考研政治、英语、专业课按 3–6–9 个月分阶段
- [ ] 考公行测、申论按模块刷题，每周一次全真模拟
- [ ] 真题至少刷 2–3 遍，错题归类
- [ ] 申论要动笔写，只看考场写不出

## 考试

- [ ] 考前规定时间打印准考证，核对考点和座位
- [ ] 提前看考点，带身份证、准考证、文具
- [ ] 不带电子设备，遵守考场规则
- [ ] 作弊取消成绩并记入诚信档案，若干年内不得报考

## 后续

- [ ] 查成绩，关注复试线和调剂系统开放时间
- [ ] 复试准备自我介绍、专业问题、岗位认知
- [ ] 考公走面试、体检、考察（政审）
- [ ] 如实填病史，按通知到指定医院体检
- [ ] 提前确认档案位置和内容，政审要档案和无犯罪记录

## 出问题找谁

- [ ] 报名系统卡顿：错峰登录，换浏览器
- [ ] 准考证或证件丢失：重新下载打印，找考点考务办
- [ ] 初试失利：准备调剂、二战或就业，别错过春招
- [ ] 体检不合格：按通知申请复检
- [ ] "内部指标"承诺：都是骗局，招录公开透明
