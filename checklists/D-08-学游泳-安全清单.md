# D-08 第一次学游泳 · 清单

> 打印后勾选。依据见 [D-08 正文](../book/04-学习与技能/D-08-第一次学游泳.md)。

## 选场地和教练

- [ ] 看卫生许可证和水质检测公示，水应清澈、无刺鼻氯味
- [ ] 确认救生员在岗、穿明显标识
- [ ] 教练要有救生员证和游泳社会体育指导员证
- [ ] 水深标识清楚，浅水区水深不超过胸口
- [ ] 按预算选班型：一对一、小班、大班
- [ ] 试听一节课，看教练是否耐心、是否讲安全

## 装备

- [ ] 泳衣或泳裤、泳镜、泳帽
- [ ] 初学者备浮板或背漂，耳塞可选
- [ ] 拖鞋、浴巾、防水袋
- [ ] 不戴隐形眼镜，近视配带度数的泳镜

## 下水前

- [ ] 饭后 1 小时再下水，不空腹、不酒后
- [ ] 有心脏病、癫痫、皮肤病先问医生；感冒发烧腹泻不去
- [ ] 热身 5–10 分钟
- [ ] 淋浴、过浸脚池，戴泳帽入场
- [ ] 认清水深标识、救生员位置和紧急出口

## 学习

- [ ] 先在浅水区熟悉水性，练水中呼气
- [ ] 扶池边漂浮，再放手漂浮，能漂 5–10 秒
- [ ] 先学蹬腿，再学划手，最后配合呼吸
- [ ] 每次课练一个重点，浮板辅助逐步去掉
- [ ] 多数人 10–20 节课学会一种泳姿，不和别人比进度
- [ ] 能连续游 10–15 米算入门

## 安全红线

- [ ] 不跳水、不憋气比赛、不在深水区逞强
- [ ] 不去野泳：水库河道没有救生员
- [ ] 充气游泳圈不是救生设备
- [ ] 儿童全程一臂距离看护，不交给大孩子
- [ ] 雷电暴雨立即离池，进入室内

## 出问题找谁

- [ ] 抽筋：呼救、抓池边、拉伸，上岸休息
- [ ] 呛水：咳嗽排出，扶池边休息，不要慌
- [ ] 溺水：呼救、拨 120、用竿绳浮物施救，不盲目下水
- [ ] 上岸后检查呼吸，必要时心肺复苏
- [ ] 耳鼻进水：侧头单脚跳，不用棉签深挖
- [ ] 皮肤过敏、红眼：上岸冲洗，必要时就医
