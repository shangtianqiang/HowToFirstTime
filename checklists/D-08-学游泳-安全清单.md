# D-08 第一次学游泳 · 清单

> 打印后勾选。依据见 [D-08 正文](../book/04-学习与技能/D-08-第一次学游泳.md)。

## 选场地

- [ ] 有卫生许可证
- [ ] 水质检测公示
- [ ] 救生员在岗
- [ ] 水深标识清楚
- [ ] 教练有资质
- [ ] 试听一节课

## 装备

- [ ] 泳衣泳裤
- [ ] 泳镜
- [ ] 泳帽
- [ ] 浮板或背漂
- [ ] 拖鞋、浴巾
- [ ] 防水袋

## 下水前

- [ ] 饭后 1 小时
- [ ] 不空腹、不酒后
- [ ] 热身 5–10 分钟
- [ ] 淋浴、过浸脚池
- [ ] 确认救生员位置

## 学习

- [ ] 浅水区熟悉水性
- [ ] 水中呼气
- [ ] 扶池边漂浮
- [ ] 放手漂浮
- [ ] 蹬腿
- [ ] 划手
- [ ] 配合呼吸
- [ ] 连续游 10–15 米

## 安全

- [ ] 不跳水
- [ ] 不憋气比赛
- [ ] 不在深水区逞强
- [ ] 儿童一臂距离看护
- [ ] 不用充气游泳圈当救生设备

## 出问题找谁

- [ ] 抽筋：呼救、抓池边、拉伸
- [ ] 呛水：咳嗽、扶池边休息
- [ ] 溺水：呼救、拨 120、心肺复苏
- [ ] 耳鼻进水：侧头单脚跳，不深挖
