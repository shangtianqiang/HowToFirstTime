# D-09 第一次自己做饭 · 清单

> 打印后勾选。依据见 [D-09 正文](../book/04-学习与技能/D-09-第一次自己做饭.md)。

## 备好

- [ ] 炒锅、汤锅
- [ ] 生熟两套刀和砧板
- [ ] 碗盘、保鲜盒
- [ ] 基础调料
- [ ] 灭火毯或厨房灭火器
- [ ] 食品温度计（可选）

## 做饭前

- [ ] 洗手
- [ ] 洗菜切菜，生熟分开
- [ ] 肉解冻彻底
- [ ] 备齐调料
- [ ] 开抽油烟机

## 烹饪

- [ ] 肉炒到熟透
- [ ] 豆角、豆浆煮透
- [ ] 尝味再调盐
- [ ] 不反复用煎炸油
- [ ] 注意油温，不冒大量烟

## 收尾

- [ ] 关火、关灶前阀
- [ ] 剩菜 2 小时内冷藏
- [ ] 清洗锅具
- [ ] 擦台面、倒垃圾
- [ ] 检查燃气阀门

## 出问题找谁

- [ ] 油锅起火：关火、盖锅盖
- [ ] 燃气泄漏：关阀、开窗、室外打电话
- [ ] 食物中毒：停食、留样本、拨 120
- [ ] 烫伤：冷水冲 15–20 分钟
