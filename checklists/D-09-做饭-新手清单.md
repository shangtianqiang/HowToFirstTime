# D-09 第一次自己做饭 · 清单

> 打印后勾选。依据见 [D-09 正文](../book/04-学习与技能/D-09-第一次自己做饭.md)。

## 备好

- [ ] 炒锅、汤锅、锅铲、汤勺
- [ ] 生熟各一套菜刀和砧板
- [ ] 碗盘筷子、保鲜盒保鲜膜
- [ ] 基础调料买小包装：油盐、生抽老抽、醋、糖、料酒、淀粉
- [ ] 灭火毯或厨房灭火器，食品温度计可选

## 第一次做什么

- [ ] 先学 5 道菜：番茄炒蛋、青椒肉丝、清炒时蔬、蛋炒饭、煮面
- [ ] 每餐一荤一素一主食
- [ ] 按周计划买菜，小份购买，根茎类耐放叶菜先吃
- [ ] 周末备菜洗切分装，冷藏 2 天内吃完

## 做饭前

- [ ] 洗手，接触生肉后再洗
- [ ] 洗菜切菜腌肉，生熟分开，生肉不挨熟食
- [ ] 备齐调料再开火
- [ ] 先开抽油烟机，再点火，调中小火

## 烹饪

- [ ] 肉炒到变色熟透，中心温度 70℃ 以上
- [ ] 豆角、豆浆、四季豆必须彻底煮透
- [ ] 尝味再调盐，少量多次
- [ ] 刀要锋利，砧板垫湿布防滑，手指蜷成爪形慢慢切
- [ ] 刀口朝里放，不丢在水池里

## 收尾与储存

- [ ] 关火、关灶前阀，再关抽油烟机
- [ ] 剩菜 2 小时内装盒冷藏
- [ ] 冷藏 4℃ 以下、冷冻 -18℃ 以下，冰箱不塞太满
- [ ] 剩菜冷藏 1–2 天内吃完，再吃彻底加热
- [ ] 清洗锅具、擦台面、倒垃圾
- [ ] 睡前、出门前检查燃气阀门

## 出问题找谁

- [ ] 油锅起火：关火、盖锅盖或灭火毯，绝不用水浇
- [ ] 燃气泄漏：关阀、开窗、不开灯不开火，到室外拨燃气抢修电话或 119
- [ ] 食物中毒：停止进食、保留食物样本，严重时拨 120
- [ ] 烫伤：冷水冲 15–20 分钟，不涂牙膏酱油，起泡就医
- [ ] 切伤：清水冲洗、压迫止血，深伤口就医
- [ ] 停电停水：备好饮用水和速食，冰箱少开门
