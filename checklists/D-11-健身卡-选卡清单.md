# D-11 第一次办健身卡 · 清单

> 打印后勾选。依据见 [D-11 正文](../book/04-学习与技能/D-11-第一次办健身卡.md)。

## 选馆（办卡前 1 到 2 周）

- [ ] 想清楚目标：减脂、增肌、减压还是游泳
- [ ] 场馆在单位或家 1.5 公里内，通勤顺路
- [ ] 按你要练的时段去看过一次人流
- [ ] 核对证照：营业执照、教练资格是否公示
- [ ] 查过口碑、经营年限、有无关店纠纷
- [ ] 用单次票或体验课试练过

## 签合同（当场逐项核对）

- [ ] 退款条件、扣费标准、到账时间写进合同
- [ ] 转卡费、停卡费问清并写进合同
- [ ] 有效期起算日和到期处理写进合同
- [ ] 搬迁、关闭怎么退写进合同
- [ ] 没有「概不退款」「不补办」「解释权归商家」字样
- [ ] 口头承诺全部落到书面
- [ ] 合同盖公章，拿到发票，合同拍照备份
- [ ] 银行卡或移动支付付款，留了付款记录
- [ ] 预算超上限的，不买

## 第一次进馆

- [ ] 带运动鞋、毛巾、水壶、更衣柜锁
- [ ] 体测数据只作参考，不当场买课
- [ ] 有伤病提前告知教练
- [ ] 从固定器械学起，重量循序渐进
- [ ] 用完器械归位、擦汗
- [ ] 贵重物品锁进更衣柜

## 日常

- [ ] 定期核对次卡、储值卡余额和消费记录
- [ ] 长期出差或受伤按合同办停卡
- [ ] 合同、发票、付款记录放在一起保存
- [ ] 出现换教练、低价清卡等迹象时，先不加购

## 出问题找谁

- [ ] 退款被拒：用文字书面提出并留记录，拨 12315 或找当地消协
- [ ] 门店关店跑路：保全合同和付款凭证，12315 投诉，涉嫌诈骗报警
- [ ] 受伤：停练找工作人员，必要时拨 120，保留病历和缴费凭证
- [ ] 器械故障：停用拍照，告知前台并要求登记
- [ ] 卡丢失：凭身份证和付款凭证到前台挂失
