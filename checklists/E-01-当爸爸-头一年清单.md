# E-01 当爸爸 · 头一年清单

> 打印后勾选。依据见 [E-01 正文](../book/05-家庭与育儿/E-01-第一次当爸爸.md)。各地政策差异大，以当地官方页面为准。

## 确认怀孕后

- [ ] 去医院确认怀孕
- [ ] 孕 13 周前建档，建《母子健康手册》
- [ ] 了解产检节奏，安排陪诊时间
- [ ] 查当地生育登记怎么办
- [ ] 查生育保险和生育津贴政策
- [ ] 查陪产假天数和工资规定

## 孕中期

- [ ] 按医生安排完成产检
- [ ] 准备待产包
- [ ] 确认入院证件和押金
- [ ] 确认陪产条件和入院路线
- [ ] 安排月子照护

## 入院与出生

- [ ] 带齐证件和待产包
- [ ] 办理入院手续
- [ ] 陪产（如医院允许）
- [ ] 办理出生医学证明
- [ ] 确认孩子姓名和证件信息

## 出生后 1 个月内

- [ ] 上户口：出生后 1 个月内
- [ ] 办新生儿医保：出生后 90 天内
- [ ] 申领生育津贴
- [ ] 预约疫苗接种
- [ ] 确认安全睡眠：同房不同床、仰卧、床面硬实、无软物
- [ ] 观察产后情绪和睡眠

## 出生后 1 年内

- [ ] 按时间表接种疫苗
- [ ] 定期儿保
- [ ] 6 个月起添加辅食，继续母乳到 2 岁及以上
- [ ] 复盘家庭分工，调整夜间照护

## 出问题找谁

- [ ] 早产或急产：走急诊产科，路上拨 120
- [ ] 产后抑郁：妇幼保健机构或精神卫生机构，可拨 12356
- [ ] 新生儿黄疸：按医生安排监测
- [ ] 喂养困难：找产科、儿科或哺乳门诊
- [ ] 证件丢失：问医院、派出所或当地卫健委
