# E-01 当爸爸 · 头一年清单

> 打印后勾选。依据见 [E-01 正文](../book/05-家庭与育儿/E-01-第一次当爸爸.md)。各地政策差异大，以当地官方页面为准。

## 确认怀孕后

- [ ] 去医院确认怀孕
- [ ] 孕 13 周前建档，建《母子健康手册》，名额紧的确认怀孕后尽早问
- [ ] 了解产检节奏，安排陪诊时间；产检套餐看清必查和可选，别被推销
- [ ] 查生育登记、生育保险和生育津贴政策，怀孕前确认连续缴费月数
- [ ] 查陪产假天数和工资规定

## 孕中期

- [ ] 按医生安排完成产检
- [ ] 准备待产包
- [ ] 确认入院证件和押金
- [ ] 确认陪产条件和入院路线
- [ ] 安排月子照护；月嫂和月子中心看清服务内容、退款和更换条款
- [ ] 夜间照护分工提前商量，别等孩子出生再吵

## 入院与出生

- [ ] 带齐证件和待产包
- [ ] 办理入院手续，交押金、签知情同意书
- [ ] 陪产要什么条件、能不能陪，按医院规定
- [ ] 办理出生医学证明，非母亲领证带母亲签字的委托书
- [ ] 核对证明上的姓名、性别、出生日期和父母信息

## 出生后 1 个月内

- [ ] 出生后 1 个月内上户口
- [ ] 出生 90 天内办新生儿医保
- [ ] 申领生育津贴，各地时限不同，生完尽早问 HR 或医保局
- [ ] 预约疫苗接种
- [ ] 确认安全睡眠：同房不同床、仰卧、床面硬实、无软物
- [ ] 观察产后情绪和睡眠

## 出生后 1 年内

- [ ] 按时间表接种疫苗，只去正规接种单位，核对接种证和批号
- [ ] 定期儿保
- [ ] 6 个月起添加辅食，继续母乳到 2 岁及以上
- [ ] 复盘家庭分工，调整夜间照护

## 出问题找谁

- [ ] 早产或急产：走急诊产科，路上拨 120
- [ ] 产后抑郁：妇幼保健机构或精神卫生机构，可拨 12356
- [ ] 新生儿黄疸：按医生安排监测
- [ ] 喂养困难：找产科、儿科或哺乳门诊
- [ ] 证件丢失：问医院、派出所或当地卫健委
