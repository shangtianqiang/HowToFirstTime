## 孕前

- [ ] 夫妻双方孕前检查

- [ ] 戒烟戒酒
- [ ] 控制体重
- [ ] 查口腔
- [ ] 慢性病用药咨询医生

- [ ] 血 HCG 和 B 超
- [ ] 确认宫内孕
- [ ] 问清预产期
- [ ] 预约建档

## 建档

- [ ] 身份证

## 产检

- [ ] 按时间表预约

- [ ] 大排畸
- [ ] 糖耐
- [ ] 孕晚期胎心监护
- [ ] 每次带母子手册

## 临产

- [ ] 待产包

- [ ] 入院流程
- [ ] 急诊电话

## 出问题找谁

- [ ] 出血腹痛：立即就医
- [ ] 破水：平躺，立即去医院
- [ ] 胎动减少：左侧卧数胎动，异常就医
- [ ] 严重呕吐：查尿酮体
