# E-02 第一次备孕与产检 · 清单

> 打印后勾选。依据见 [E-02 正文](../book/05-家庭与育儿/E-02-第一次备孕与产检.md)。

## 孕前 3 个月

- [ ] 夫妻双方做孕前检查：血常规、传染病、甲状腺、妇科、精液分析
- [ ] 社区或妇幼保健院申请免费孕前优生健康检查
- [ ] 女方孕前 3 个月开始补叶酸，每天 0.4 毫克，至少吃到孕早期 3 个月
- [ ] 戒烟戒酒，规律作息，控制体重
- [ ] 查口腔，处理智齿和牙周问题
- [ ] 慢性病患者先调整用药，咨询医生

## 确认怀孕与建档

- [ ] 月经推迟先用早孕试纸，再到医院查血 HCG 和 B 超，确认宫内孕、排除宫外孕
- [ ] 问清预产期和建档时间
- [ ] 孕 6–12 周内尽快建档，名额紧张的提前预约
- [ ] 备齐身份证、结婚证、医保卡、居住证（非户籍）和既往检查报告，领母子健康手册

## 产检时间表

- [ ] 按医生安排全程产检，通常 7–11 次，不因麻烦跳过
- [ ] 孕早期做 NT 检查（约 11–13 周+6）
- [ ] 孕中期做唐筛或无创 DNA（约 15–20 周）
- [ ] 孕 20–24 周做大排畸，孕 24–28 周做糖耐
- [ ] 孕晚期每 2–4 周一次，36 周后每周一次并做胎心监护
- [ ] 35 岁以上属高龄，按医嘱加做无创 DNA 或羊水穿刺
- [ ] 每次带母子手册，记录体重、血压、宫高、腹围，产检记录别乱丢

## 临产准备

- [ ] 孕 36 周前备好待产包和证件，了解医院入院流程和急诊电话
- [ ] 和医生确认分娩方式和麻醉选择
- [ ] 上班产检时间计入劳动时间，不得扣工资
- [ ] 产检和分娩费用按当地医保规定报销，提前问清

## 日常避坑

- [ ] 先建档再产检，不建卡部分医院不接诊
- [ ] 孕期任何药都先问医生，包括中成药和保健品
- [ ] 不信偏方保胎，不轻信"包生男孩"
- [ ] 多数孕妇可散步、做孕妇瑜伽，孕期控制体重，避免剧烈运动，有流产史或前置胎盘遵医嘱

## 出问题找谁

- [ ] 出血、剧烈腹痛：立即就医，拨 120 或家人送医
- [ ] 破水：平躺，垫高臀部，不要洗澡，立即去医院
- [ ] 胎动明显减少：左侧卧，数胎动，异常立即就医
- [ ] 严重呕吐不能进食：查尿酮体，必要时补液
- [ ] 高热：物理降温，及时就诊，不自行吃退烧药
- [ ] 头痛、眼花、水肿加重：警惕妊娠期高血压，及时就诊
- [ ] 摔倒、车祸：即使无不适也要去医院检查
