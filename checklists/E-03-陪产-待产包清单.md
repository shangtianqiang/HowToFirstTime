# E-03 第一次陪产 · 清单

> 打印后勾选。依据见 [E-03 正文](../book/05-家庭与育儿/E-03-第一次陪产.md)。

## 待产包

- [ ] 身份证、结婚证、医保卡
- [ ] 产检本、母子健康手册
- [ ] 产褥垫、卫生巾
- [ ] 哺乳内衣、拖鞋、毛巾
- [ ] 水杯、吸管
- [ ] 宝宝纸尿裤、湿巾、包被
- [ ] 手机、充电器、充电宝
- [ ] 巧克力、水

## 入院

- [ ] 认准规律宫缩、破水、见红
- [ ] 破水平躺，立即去医院
- [ ] 带齐证件和待产包
- [ ] 办住院、交押金
- [ ] 熟悉产房位置

## 陪产

- [ ] 问清是否允许陪产
- [ ] 穿隔离衣、鞋套
- [ ] 站指定位置
- [ ] 听助产士指挥
- [ ] 不随意拍照

## 产后

- [ ] 观察出血量
- [ ] 观察血压和精神状态
- [ ] 协助早接触、早吸吮
- [ ] 记录宝宝排尿排便
- [ ] 办出生医学证明
- [ ] 核对姓名和出生日期
- [ ] 拿出院小结和发票

## 出问题找谁

- [ ] 产后大出血：按呼叫铃，叫护士
- [ ] 胎儿窘迫：听医生建议
- [ ] 宝宝发热：立即就医
- [ ] 情绪持续低落：看心理科
