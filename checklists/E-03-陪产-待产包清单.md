# E-03 第一次陪产 · 清单

> 打印后勾选。依据见 [E-03 正文](../book/05-家庭与育儿/E-03-第一次陪产.md)。

## 备待产包

- [ ] 证件：身份证、结婚证、医保卡、产检本、母子健康手册
- [ ] 妈妈用品：产褥垫、卫生巾、哺乳内衣、拖鞋、毛巾、牙刷、水杯、吸管
- [ ] 宝宝用品：纸尿裤、湿巾、包被、和尚服、帽子、奶瓶（如需）
- [ ] 其他：手机、充电器、充电宝、现金、巧克力、红牛
- [ ] 提前问医院提供什么，避免重复买
- [ ] 提前问医院是否允许陪产、几人、是否需要培训，熟悉入院流程、电梯和产房位置
- [ ] 备好隔离衣、鞋套，按医院要求
- [ ] 和妻子确认分娩方式、无痛分娩意愿

## 入院时机

- [ ] 规律宫缩：初产妇 5–10 分钟一次就去医院，经产妇更密
- [ ] 破水：平躺，垫高臀部，不要洗澡，立即去医院
- [ ] 见红：少量可观察，量大立即就医
- [ ] 胎动明显减少或剧烈增多：立即就医

## 入院与待产

- [ ] 到急诊或产科：挂号、办住院、交押金、做检查，保留住院证和押金单
- [ ] 记录宫缩间隔和持续时间
- [ ] 帮妻子翻身、按摩腰背、补充水分
- [ ] 听胎心，配合护士

## 分娩与签字

- [ ] 剖宫产、无痛分娩、输血等知情同意书，听医生说明风险再签
- [ ] 不盲目坚持顺产或剖宫产，由医生评估母婴情况
- [ ] 按医院要求穿隔离衣、鞋套，站妻子侧方指定位置
- [ ] 听助产士指挥，鼓励妻子按呼吸法用力；不随意走动、不随意拍照（除非允许）

## 产后与出院

- [ ] 产后 2 小时观察出血量、血压、面色和精神状态，别只盯宝宝
- [ ] 协助早接触、早吸吮，注意保暖，记录宝宝第一次排尿、排便
- [ ] 配合足跟血筛查，接种乙肝疫苗和卡介苗
- [ ] 办出生医学证明：带父母身份证，核对姓名、性别、出生日期，一经打印难改
- [ ] 结算费用打印发票和清单，拿好出院小结和疫苗接种记录
- [ ] 陪产假各地 7–30 天，工资照发

## 出问题找谁

- [ ] 产后大出血：恶露突然增多、颜色鲜红、头晕心慌、面色苍白，按呼叫铃叫护士
- [ ] 胎儿窘迫：听医生建议，可能需要紧急剖宫产
- [ ] 新生儿窒息：儿科医生复苏，家属在外等待
- [ ] 宝宝发热：立即就医，不自行退烧
- [ ] 产妇情绪崩溃：陪伴倾听，持续两周以上看心理科
- [ ] 停水停电等突发：听院方安排，不要慌乱
