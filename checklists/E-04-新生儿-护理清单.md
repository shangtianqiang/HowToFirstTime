# E-04 第一次照顾新生儿 · 清单

> 打印后勾选。依据见 [E-04 正文](../book/05-家庭与育儿/E-04-第一次照顾新生儿.md)。

## 环境

- [ ] 室温 22–26℃
- [ ] 湿度 50%–60%
- [ ] 婴儿床在父母床边
- [ ] 硬床垫、睡袋
- [ ] 床上无软物
- [ ] 家里无烟

## 喂养

- [ ] 早接触、早吸吮
- [ ] 按需喂，每天 8–12 次
- [ ] 正确含接
- [ ] 喂后拍嗝
- [ ] 配方奶按说明冲调
- [ ] 记录大小便

## 护理

- [ ] 仰卧睡
- [ ] 尿布从前向后擦
- [ ] 脐带保持干燥
- [ ] 按医嘱消毒
- [ ] 每天测体温
- [ ] 补维生素 D

## 疫苗与筛查

- [ ] 乙肝疫苗第一针
- [ ] 卡介苗
- [ ] 足跟血筛查
- [ ] 听力筛查
- [ ] 办预防接种证

## 危险信号

- [ ] 3 个月内发热 ≥38℃
- [ ] 呼吸超过 60 次/分
- [ ] 拒奶、嗜睡
- [ ] 抽搐
- [ ] 皮肤发紫
- [ ] 黄疸加重

## 出问题找谁

- [ ] 发热：立即就医
- [ ] 呛奶：侧卧拍背，拨 120
- [ ] 脐部红肿：就医
- [ ] 黄疸加重：立即就医
