## 出生证明

- [ ] 想好宝宝名字
- [ ] 父母身份证
- [ ] 医院填表
- [ ] 核对姓名、性别、出生时间
- [ ] 保管原件

## 落户

- [ ] 出生医学证明
- [ ] 父母户口簿
- [ ] 父母身份证
- [ ] 结婚证
- [ ] 出生登记申请表
- [ ] 到父或母户籍地派出所
- [ ] 核对户口簿信息

## 医保

- [ ] 户口簿
- [ ] 出生证明
- [ ] 父母身份证
- [ ] 参保登记
- [ ] 缴费
- [ ] 保留缴费凭证
- [ ] 确认待遇生效时间

## 社保卡

- [ ] 提交照片
- [ ] 选择邮寄或自取
- [ ] 激活医保功能
- [ ] 绑定家庭共济（如适用）

## 出问题找谁

- [ ] 出生证明错误：联系医院更正
- [ ] 超期落户：尽快办，说明原因
- [ ] 医保未生效：问医保经办机构
- [ ] 报销被拒：补材料或申请复核
