# E-05 第一次给孩子上户口/办医保 · 清单

> 打印后勾选。依据见 [E-05 正文](../book/05-家庭与育儿/E-05-第一次给孩子上户口办医保.md)。

## 出生医学证明

- [ ] 出院前在分娩医院办理，带父母双方身份证
- [ ] 办之前想好宝宝姓名，签发后改名要走变更流程
- [ ] 核对姓名、性别、出生日期、身份证号和父母信息
- [ ] 保管好原件：落户、医保、入学都要用，丢了补办很麻烦

## 落户

- [ ] 出生后一个月内，到父亲或母亲户籍地派出所申报出生登记
- [ ] 材料备齐：出生医学证明、父母双方户口簿、身份证、结婚证
- [ ] 填写出生登记申请表
- [ ] 非婚生育按当地规定提供非婚生育说明或亲子鉴定，具体问派出所
- [ ] 父母户籍不一致：选一方落户，问清当地要求
- [ ] 拿到户口簿核对宝宝姓名、性别、出生日期和身份证号

## 医保参保

- [ ] 记住顺序：出生医学证明 → 户口登记 → 医保参保 → 社保卡
- [ ] 出生 90 天内参保，多数地区可自出生之日起享受待遇，住院费用通常可追溯报销
- [ ] 带户口簿、出生证明、父母身份证和银行卡，办参保登记
- [ ] 城乡居民医保按年度缴费，通常几百元，政府有补助
- [ ] 到税务部门、指定银行或线上渠道缴费，保留凭证
- [ ] 确认参保年度和待遇生效时间

## 社保卡

- [ ] 在社保卡服务网点或线上申请，提交照片和身份信息，首次申领免费
- [ ] 选择邮寄或自取，邮寄更快
- [ ] 拿到卡后激活医保功能，不激活用不了
- [ ] 材料提前复印好，窗口要复印件，现场排队耽误时间

## 避坑

- [ ] 别轻信"代办落户"，收费代办多为骗局，自己办很简单
- [ ] 医保错过参保期，当年可能无法享受待遇，只能等下一年度
- [ ] 只落户不参保，宝宝生病全自费
- [ ] 境外出生需出生证明认证和翻译；收养子女凭收养登记证办理

## 出问题找谁

- [ ] 出生证明信息错误：立即联系医院更正，不自行涂改
- [ ] 超期未落户：尽快办，向派出所说明原因
- [ ] 户口簿信息错误：带出生证明和医院证明到派出所申请更正
- [ ] 医保报销被拒：问清原因，补材料或申请复核
