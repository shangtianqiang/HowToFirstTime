# E-06 第一次选幼儿园 · 清单

> 打印后勾选。依据见 [E-06 正文](../book/05-家庭与育儿/E-06-第一次选幼儿园.md)。

## 摸政策

- [ ] 提前 6–12 个月查区县教育局招生公告：报名时间、材料、录取方式
- [ ] 分清公办、普惠性民办、普通民办，公办和普惠收费低、就近
- [ ] 看报名条件：户籍、房产、居住证、社保年限要求不同，没有房产关注居住证
- [ ] 问清收费项目：保教费、伙食费、校服、兴趣班
- [ ] 幼儿园不应提前教拼音、算术等小学内容，游戏和习惯更重要

## 实地看园

- [ ] 办学许可证挂在显眼位置，无证园随时可能被关停
- [ ] 收费公示牌、食品经营许可证
- [ ] 消防通道畅通
- [ ] 门禁和接送制度，防陌生人接走
- [ ] 教室采光通风，卫生间和洗手设施，户外活动场地
- [ ] 乘校车看校车标牌和许可，司机有资质、不超员

## 问清这几点

- [ ] 一个班几个孩子、几个老师，教师是否持证、流动率高不高
- [ ] 每日作息和户外活动时间
- [ ] 伙食：看每周食谱公示、留样记录，问食材来源
- [ ] 孩子生病、受伤怎么处理；是否有监控，家长能否查看
- [ ] 收费退费规则，按月或按天算，报名前问清
- [ ] 不轻信"名校直升"承诺，写进合同才算数

## 报名与缴费

- [ ] 在区县教育局平台或幼儿园报名：填信息，上传户口簿、房产证、居住证、接种证，备好原件和复印件
- [ ] 关注录取顺序和摇号规则
- [ ] 确认录取后按时缴费注册，看清收费明细
- [ ] 不一次性交多年费用，跑路风险高
- [ ] 收费、退费、责任要有书面合同约定

## 入园准备

- [ ] 到妇幼保健院做入园体检，合格后交幼儿园
- [ ] 调整作息，练习自己吃饭、上厕所、穿脱鞋
- [ ] 准备姓名贴、换洗衣物、水杯
- [ ] 提前带孩子熟悉环境；前几天短时入园、带安抚物，多数孩子 1–2 周适应

## 出问题找谁

- [ ] 幼儿园关停：关注教育局公告，及时转园，要求退费
- [ ] 孩子受伤：要求园方说明并查看监控，必要时就医报警
- [ ] 疑似虐童：立即报警，向教育局投诉，保留证据
- [ ] 食物中毒：就医，保留餐食样本，拨 12315 和疾控部门
- [ ] 传染病停课：按园方和疾控要求隔离，复课要证明
- [ ] 收费纠纷：向教育局、市场监管部门投诉
