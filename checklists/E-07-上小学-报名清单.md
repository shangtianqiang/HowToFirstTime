# E-07 第一次送孩子上小学 · 清单

> 打印后勾选。依据见 [E-07 正文](../book/05-家庭与育儿/E-07-第一次送孩子上小学.md)。

## 摸政策

- [ ] 孩子年满 6 周岁入学，条件不具备的地区可推迟到 7 周岁
- [ ] 提前 1 年查区县教育局当年招生方案：划片范围、报名时间、录取顺序
- [ ] 义务教育免试就近入学，公办学校不得组织入学考试
- [ ] 分清"人户一致""人户分离""随迁子女"的不同要求
- [ ] 民办公民同招，报名人数超计划则摇号，看是否跨区招生
- [ ] 报名窗口通常只有几天，一年一次，错过只能等统筹或下一年

## 备材料

- [ ] 户口簿
- [ ] 房产证或购房合同；没有房产按居住证、社保条件申请，可能统筹安排
- [ ] 居住证和社保缴费记录（随迁子女），按当地要求备务工证明
- [ ] 预防接种证和查验证明，未完成接种的按通知补种
- [ ] 出生医学证明、儿童体检报告
- [ ] 材料必须真实，查出造假取消录取资格

## 网上报名

- [ ] 在区县教育局入学平台注册，填户籍、房产、居住信息
- [ ] 上传材料，报名成功生成报名号
- [ ] 按通知提交原件核验，信息要一致
- [ ] 材料被退回：按通知在截止前补交
- [ ] 查看录取结果，按时到校确认，记下报到时间和需带材料

## 报到开学

- [ ] 到录取学校交材料，领校服、课本
- [ ] 参加新生家长会，看清分班、作息时间和接送安排
- [ ] 加入班级群，记下班主任电话
- [ ] 入学后学校统一建学籍，全国联网，转学要办手续

## 入学准备

- [ ] 调整作息，早睡早起
- [ ] 练自己穿衣、吃饭、整理书包
- [ ] 练表达：能说出姓名、家长电话、住址
- [ ] 练安全：不跟陌生人走，记住 110、120
- [ ] 每天亲子阅读 20 分钟，练坐姿和倾听
- [ ] 不提前学小学课程，习惯更重要；提前熟悉校园，缓解入学焦虑

## 出问题找谁

- [ ] 未被录取：按区县统筹安排，及时联系教育局
- [ ] 孩子不适应：和班主任沟通，逐步调整作息
- [ ] 遭遇校园欺凌：保留证据，联系班主任和学校，严重时报警
- [ ] 学校违规收费（如"择校费"）：义务教育不得收取，向教育局、市场监管部门投诉
- [ ] 转学：按转入地政策办理，学籍网上转接
