# E-07 第一次送孩子上小学 · 清单

## 政策

- [ ] 查区县招生方案
- [ ] 确认划片范围
- [ ] 确认报名时间
- [ ] 分清人户一致和随迁子女
- [ ] 看民办摇号规则

## 材料

- [ ] 户口簿
- [ ] 房产证或购房合同
- [ ] 居住证
- [ ] 社保记录
- [ ] 预防接种证
- [ ] 接种查验证明
- [ ] 出生证明
- [ ] 体检报告

## 报名

- [ ] 网上报名
- [ ] 上传材料
- [ ] 材料审核
- [ ] 查看录取
- [ ] 到校确认

## 入学准备

- [ ] 调整作息
- [ ] 自己穿衣吃饭
- [ ] 整理书包
- [ ] 记住家长电话和住址
- [ ] 记住 110、120
- [ ] 每天亲子阅读
- [ ] 参加新生家长会

## 出问题找谁

- [ ] 未录取：联系教育局统筹
- [ ] 材料退回：按通知补交
- [ ] 校园欺凌：班主任、学校、报警
- [ ] 违规收费：教育局、市场监管
