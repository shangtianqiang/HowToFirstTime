# E-08 第一次照顾生病的孩子 · 清单

> 打印后勾选。依据见 [E-08 正文](../book/05-家庭与育儿/E-08-第一次照顾生病的孩子.md)。

## 药箱

- [ ] 电子体温计
- [ ] 对乙酰氨基酚
- [ ] 布洛芬
- [ ] 口服补液盐
- [ ] 生理盐水滴鼻
- [ ] 喂药器
- [ ] 创可贴、碘伏

## 观察

- [ ] 量体温并记录
- [ ] 看精神状态
- [ ] 看呼吸
- [ ] 看尿量
- [ ] 看皮疹
- [ ] 记录用药时间和剂量

## 护理

- [ ] 按体重用退烧药
- [ ] 不叠加两种退烧药
- [ ] 少量多次补液
- [ ] 清淡饮食
- [ ] 不捂汗
- [ ] 不用酒精擦浴
- [ ] 不用成人药

## 就医

- [ ] 3 个月以下发热
- [ ] 精神差、嗜睡
- [ ] 呼吸急促
- [ ] 抽搐
- [ ] 皮疹按压不褪色
- [ ] 频繁呕吐、尿少

## 复课

- [ ] 隔离期满
- [ ] 开复课证明
- [ ] 报告学校
- [ ] 补作业和课程

## 出问题找谁

- [ ] 高热惊厥：侧卧，拨 120
- [ ] 呼吸困难：拨 120
- [ ] 误服药物：带药瓶就医
- [ ] 传染病：报告学校、疾控
