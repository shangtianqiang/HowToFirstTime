# E-08 第一次照顾生病的孩子 · 清单

> 打印后勾选。依据见 [E-08 正文](../book/05-家庭与育儿/E-08-第一次照顾生病的孩子.md)。

## 家庭药箱

- [ ] 电子体温计
- [ ] 对乙酰氨基酚（3 个月以上可用）
- [ ] 布洛芬（6 个月以上可用）
- [ ] 口服补液盐
- [ ] 生理盐水滴鼻
- [ ] 创可贴、碘伏、喂药器

## 观察记录

- [ ] 腋温 ≥37.3℃ 为发热；每 4 小时测一次体温，记录时间和用药剂量
- [ ] 看精神状态：精神好、能玩能吃可先观察，精神差比高烧更危险
- [ ] 看呼吸、肤色和尿量
- [ ] 记录吃奶吃饭量、大便次数和性状，咳嗽、流涕、皮疹等症状变化
- [ ] 就诊时把记录和正在吃的药带给医生

## 退烧与补液

- [ ] 通常腋温 ≥38.5℃ 或孩子明显不适时用退烧药，不只看数字
- [ ] 对乙酰氨基酚每次 10–15 毫克/千克，间隔 4–6 小时
- [ ] 布洛芬每次 5–10 毫克/千克，间隔 6–8 小时
- [ ] 按体重算剂量，不按年龄估；24 小时内不超过 4 次，不两种退烧药叠加
- [ ] 少量多次喂水或口服补液盐，观察尿量和颜色
- [ ] 清淡易消化饮食，不强迫进食，腹泻不禁食，母乳继续喂

## 用药避坑

- [ ] 不捂汗，不用酒精擦浴，可温水擦拭或减少衣物
- [ ] 不用成人药和阿司匹林，儿童可能中毒
- [ ] 不自行用抗生素；儿童止咳药谨慎，尤其 6 岁以下先就医
- [ ] 按医嘱完成疗程，不自行停药，症状稍好就停易复发

## 就医与复课

- [ ] 就医准备：医保卡、病历本、既往检查报告、正在吃的药、口罩和水
- [ ] 症状加重或持续 3 天以上，按医嘱复诊
- [ ] 发热、传染病期间不去幼儿园和学校
- [ ] 传染病居家隔离，报告学校，隔离期满凭疾控或医院证明
- [ ] 按学校要求开复课证明

## 出问题找谁

- [ ] 3 个月以下发热：立即就医，不自行退烧
- [ ] 高热惊厥：侧卧，移开硬物，不塞东西到嘴里，记录时间，超过 5 分钟拨 120
- [ ] 呼吸困难：看鼻翼扇动、胸凹，立即拨 120
- [ ] 皮疹按压不褪色：立即就医，警惕严重感染
- [ ] 误服药物：带药瓶立即就医，拨 120
- [ ] 脱水（尿少、口干、哭无泪）：口服补液盐，严重时就医；精神差、频繁呕吐、尿少立即就医
