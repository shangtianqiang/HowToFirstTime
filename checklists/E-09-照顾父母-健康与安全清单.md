# E-09 第一次照顾年迈父母 · 清单

> 打印后勾选。依据见 [E-09 正文](../book/05-家庭与育儿/E-09-第一次照顾年迈父母.md)。

## 建健康档案

- [ ] 备好身份证、医保卡、既往病历和检查报告
- [ ] 列用药清单：药名、剂量、频次
- [ ] 记下过敏史、紧急联系人和常去的医院、医生
- [ ] 存好 120、社区医生和子女电话，准备应急卡（姓名、病史、用药、联系人），教会父母用手机拨号和一键呼叫

## 居家防跌倒

- [ ] 浴室装扶手和防滑垫，卧室到卫生间装夜灯
- [ ] 清除地面电线和杂物，保持地面干燥
- [ ] 常用物品放在伸手可及处
- [ ] 备拐杖或助行器，穿防滑鞋、练平衡
- [ ] 煤气、电器定期检查

## 体检与慢病管理

- [ ] 每年一次体检，重点查血压、血糖、血脂、肝肾功能、心电图、骨密度
- [ ] 定期测血压血糖并记录，高血压一般控制在低于 140/90 毫米汞柱，糖尿病按医生目标
- [ ] 用药清单定期让医生复核，避免重复用药和相互作用
- [ ] 不自行停药换药，血压血糖会反弹
- [ ] 保健品替代不了药物，看清药品说明书，防重复用药和过量

## 陪诊与日常照护

- [ ] 提前挂号，带病历、药盒、医保卡陪同就诊
- [ ] 记下医生嘱咐和下次复诊时间，拿药并核对
- [ ] 饮食清淡，控制盐糖；适度活动、保持社交，防孤独
- [ ] 观察情绪和认知变化：记忆减退、重复提问、迷路、性格变化，尽早到神经内科或记忆门诊
- [ ] 情绪低落持续两周以上，看心理科或老年科，老年抑郁常被当成"脾气不好"

## 资源与法律

- [ ] 了解当地长护险试点政策：向医保经办机构申请，做失能评估
- [ ] 了解社区居家养老服务、助餐点和家庭医生签约
- [ ] 不轻信“养老返利”，非法集资血本无归
- [ ] 养老机构实地看资质和护理员配比，按老人意愿和经济条件选
- [ ] 了解医保门诊慢特病待遇
- [ ] 提前沟通意定监护和遗嘱，按民法典办理，形式合法、必要时公证

## 出问题找谁

- [ ] 跌倒：不急于扶起，先问哪里疼，怀疑骨折拨 120
- [ ] 胸痛、胸闷：立即拨 120，不自行开车送医
- [ ] 中风征兆（口角歪斜、说话不清、肢体无力）：立即拨 120
- [ ] 走失：报警，提供照片和衣着，查监控
- [ ] 误服药物：带药瓶就医，拨 120
- [ ] 情绪危机：陪伴，移除危险物品，看心理科
- [ ] 不把照护全部压在一个子女身上，照护者也会垮
