# E-10 第一次面对亲人离世 · 清单

> 打印后勾选。依据见 [E-10 正文](../book/05-家庭与育儿/E-10-第一次面对亲人离世.md)。

## 第一时间

- [ ] 确认死亡，联系医生或社区卫生服务中心开死亡医学证明
- [ ] 核对死亡医学证明：姓名、身份证号、死亡时间、死因
- [ ] 家中死亡：联系社区卫生服务中心或拨 120，必要时报警
- [ ] 通知直系亲属，商量后事安排
- [ ] 分工：一人联系殡仪馆和医院，一人通知亲友接待，一人整理证件财务，一人管费用记账

## 备齐证件

- [ ] 死者身份证、户口簿，经办人身份证
- [ ] 死亡医学证明、火化证明多复印几份，处处要用，丢了补办麻烦
- [ ] 社保卡、医保卡
- [ ] 银行卡、存折、房产证、车辆登记证、遗嘱（如有）

## 殡仪与火化

- [ ] 凭死亡证明联系当地殡仪馆，不找无资质中介，殡葬中介价格虚高
- [ ] 预约遗体接运、冷藏、告别厅和火化
- [ ] 先问殡仪馆官方收费项目和标准，看是否有惠民殡葬减免
- [ ] 按约火化，领取骨灰和火化证明

## 注销与待遇

- [ ] 凭死亡证明、户口簿、身份证到户籍地派出所注销户口，身份证收回
- [ ] 注销时限：城市在葬前，农村在一个月内
- [ ] 到社保经办机构办养老保险注销，个人账户余额可依法继承；及时通知停发养老金，多领的要退回
- [ ] 参加企业职工基本养老保险的，遗属申领丧葬补助金和抚恤金，标准按当地规定
- [ ] 注销医保个人账户
- [ ] 注销银行卡、手机号和网络账号，处理保险理赔，退租、过户水电燃气

## 遗产处理

- [ ] 先清点财产和债务：存款、房产、车辆、股权，继承后办过户
- [ ] 先以遗产清偿债务，剩余部分再继承；放弃继承可不承担债务
- [ ] 有遗嘱按遗嘱办理，必要时公证；自书、代书、打印遗嘱都有形式要求
- [ ] 无遗嘱按法定继承，第一顺序是配偶、子女、父母，一般均分，照顾困难一方
- [ ] 继承人协商分割，口头分遗产容易反悔，写书面协议
- [ ] 银行卡密码不知道：凭死亡证明、亲属关系证明到银行办理查询和继承，可能需公证
- [ ] 不轻信"遗产代办"，收费高可能卷款

## 出问题找谁

- [ ] 非正常死亡：保护现场，不移动遗体，立即报警
- [ ] 遗产纠纷：先协商，找调解委员会，必要时诉讼
- [ ] 遗嘱争议：做笔迹鉴定，按民法典规定处理
- [ ] 境外资产：联系使领馆，按当地法律办理
- [ ] 悲伤走不出来：持续失眠、无法工作、出现自伤念头，及时看心理科
- [ ] 照顾好自己：正常吃饭睡觉，接受亲友帮助，心理危机拨心理援助热线
