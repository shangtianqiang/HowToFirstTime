# E-10 第一次面对亲人离世 · 清单

> 打印后勾选。依据见 [E-10 正文](../book/05-家庭与育儿/E-10-第一次面对亲人离世.md)。

## 第一时间

- [ ] 确认死亡
- [ ] 医院开死亡证明
- [ ] 家中死亡联系社区或报警
- [ ] 通知直系亲属
- [ ] 分工

## 证件

- [ ] 死者身份证、户口簿
- [ ] 经办人身份证
- [ ] 死亡医学证明，多复印
- [ ] 火化证明
- [ ] 社保卡、医保卡
- [ ] 银行卡、房产证

## 后事

- [ ] 联系殡仪馆
- [ ] 确认收费项目
- [ ] 遗体接运
- [ ] 告别厅
- [ ] 火化
- [ ] 领取骨灰和火化证明

## 注销与待遇

- [ ] 户口注销
- [ ] 养老保险注销
- [ ] 丧葬补助金
- [ ] 抚恤金
- [ ] 医保个人账户注销
- [ ] 银行卡注销

## 遗产

- [ ] 清点财产
- [ ] 清点债务
- [ ] 查找遗嘱
- [ ] 继承人协商
- [ ] 书面协议或公证
- [ ] 办理过户

## 照顾自己

- [ ] 正常吃饭睡觉
- [ ] 接受亲友帮助
- [ ] 允许自己悲伤
- [ ] 持续失眠或无法生活，看心理科

## 出问题找谁

- [ ] 非正常死亡：保护现场，报警
- [ ] 遗产纠纷：调解或诉讼
- [ ] 遗嘱争议：笔迹鉴定
- [ ] 心理危机：心理咨询、援助热线
