# E-11 第一次给孩子报兴趣班 · 清单

> 打印后勾选。依据见 [E-11 正文](../book/05-家庭与育儿/E-11-第一次给孩子报兴趣班.md)。

## 定类型

- [ ] 想清楚学什么：体育、艺术、科技（编程、机器人）或学科类，结合孩子兴趣、身体条件和接送半径
- [ ] 学科类不再新审批，收费实行政府指导价，节假日、休息日和寒暑假不能排课，线下结束不晚于 20:30
- [ ] 学龄前孩子的学前班、幼小衔接班等学科类培训被明令禁止
- [ ] 游泳、攀岩属高危险性体育项目，看许可要求，高危项目每班次不超 20 人、须配持急救证书的救护人员
- [ ] 问孩子想试什么，先试听再报，优先选离家近的

## 查资质

- [ ] 办学许可证、营业执照或民办非企业单位登记证书两证齐全，核对名称地址和门店一致
- [ ] 收费公示牌：项目、标准、时长
- [ ] 教师或教练资质公示：姓名、照片、证书编号
- [ ] 全国平台「校外培训家长端」App 查得到该机构，查黑白名单
- [ ] 消防和疏散通道合规，监控覆盖教室和活动场地
- [ ] 体育类看急救设备和持急救证书的人员，问"孩子受伤了你们怎么处理"
- [ ] 宣传"在职名师"的直接排除：机构不得聘用中小学在职教师

## 试听

- [ ] 同类机构试听 1–2 家对比，先问清试听是否收费、是正式课还是展示课
- [ ] 看班额和配比：体育类每班原则上不超 35 人，超 10 名学员应至少配 2 名执教人员
- [ ] 体育类先确认孩子身体状况，有基础健康问题的先咨询医生
- [ ] 问课程体系、每期课时、任教教练和教练变动怎么处理
- [ ] 下课后问孩子"还想来吗"，再问自己价格值不值

## 签约缴费

- [ ] 用《中小学生校外培训服务合同（示范文本）》（2021 年修订版），口头承诺逐条写进合同
- [ ] 退费规则、停课处理和违约责任写进合同
- [ ] 一次缴费不超 3 个月或 60 课时，且不超 5000 元，超上限的报价直接拒绝
- [ ] 钱进机构收费专用账户，或走家长端 App，纳入资金监管
- [ ] 不办培训贷，不转私人微信或支付宝
- [ ] 拿到盖章合同和正规票据，App 里确认订单记录，未消课程费用支持原路退还

## 开课期间

- [ ] 固定接送人，先走一遍路线，和教练确认交接方式，低龄孩子送进教室再离开
- [ ] 每次课后核对 App 消课记录，发现异常尽早处理
- [ ] 告知教练孩子过敏史和健康状况；告诉孩子不舒服或被打骂推搡，第一时间告诉家长
- [ ] 教练更换或门店搬迁：看合同变更条款，要求书面确认新安排，不接受按退费条款协商

## 出问题找谁

- [ ] 不想学了：先看合同退费条款，向机构书面提出；App 缴费的在 App 申请退费
- [ ] 协商不成：拨 12315、12345，或通过全国平台投诉
- [ ] 机构关门跑路：保留合同、票据、消课记录，联合其他家长统一登记诉求，金额大的报警
- [ ] 孩子受伤：现场处置送医、保留病历单据，要求看监控（体育类视频应保存不少于 90 日），问清场所责任险和意外险
- [ ] 教练体罚或言行不当：带孩子离开现场，向机构投诉，严重的报警并向主管部门反映
