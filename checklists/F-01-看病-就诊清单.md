# F-01 第一次自己挂号看病 · 清单

> 打印后勾选。依据见 [F-01 正文](../book/06-健康与医疗/F-01-第一次自己挂号看病.md)。

## 出发前

- [ ] 带身份证、社保卡或医保码
- [ ] 带既往病历、检查报告和影像片子
- [ ] 带正在吃的药或用药清单
- [ ] 确认是否需要空腹、憋尿
- [ ] 确认医院地址和就诊时段

## 挂号

- [ ] 选医院公众号、App、电话、自助机或窗口
- [ ] 不确定科室问导诊台
- [ ] 非急诊实名挂号
- [ ] 按预约时段到院

## 就诊

- [ ] 签到或刷卡，等叫号
- [ ] 向医生如实说症状、持续时间和用药
- [ ] 说明过敏史、孕哺情况
- [ ] 问清检查和用药注意事项

## 检查取药

- [ ] 缴费后按指引检查
- [ ] 按回执时间取报告
- [ ] 药房取药，问清用法用量
- [ ] 保存发票、清单和报告

## 出问题找谁

- [ ] 过号：问护士台能不能补叫
- [ ] 报告异常：按医生安排复诊
- [ ] 药物过敏：停药并去急诊
- [ ] 急危重症：拨 120 或直接去急诊
