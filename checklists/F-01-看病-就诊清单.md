# F-01 第一次自己挂号看病 · 清单

> 打印后勾选。依据见 [F-01 正文](../book/06-健康与医疗/F-01-第一次自己挂号看病.md)。

## 出发前

- [ ] 带本人有效身份证件：身份证、户口本、社保卡、驾驶证、护照都可以
- [ ] 带社保卡或医保码，没带卡可在医保服务平台或支付宝、微信激活医保码
- [ ] 带既往病历、检查报告和影像片子，忘带可能重复检查多花钱
- [ ] 带正在吃的药，或拍照、列清单
- [ ] 空腹、憋尿等检查要求提前问清
- [ ] 确认医院地址和就诊时段，老人和行动不便的有人陪同

## 挂号

- [ ] 选医院公众号或 App、电话、自助机或窗口挂号，二级以上医院有分时段预约，保留现场号源和人工窗口
- [ ] 发热去发热门诊，腹泻去肠道门诊，其他按症状所属系统选科
- [ ] 不确定挂哪个科：问导诊台或挂全科医学科，别来回换号
- [ ] 非急诊实名挂号，不买"专家号"黄牛号
- [ ] 常见病、慢病开药可去社区或基层医疗机构
- [ ] 帮老人小孩看病可用医保亲情账户，人码相符，不冒名就医

## 候诊与就诊

- [ ] 按预约时段到院，签到或刷卡等叫号
- [ ] 预约了去不了：出诊单元结束前取消，不取消可能计爽约
- [ ] 号满了问有没有现场号或加号
- [ ] 向医生如实说症状、持续时间、用过什么药，别夸大也别隐瞒
- [ ] 说明过敏史、孕哺情况、既往病史
- [ ] 听不懂医嘱当场问，或请医生写下来

## 检查与取药

- [ ] 缴费后按指引到检验科、影像科检查
- [ ] 按回执时间取报告
- [ ] 药房取药，看清用药说明
- [ ] 药快吃完提前问能不能开长期处方，一般 4 周内，病情稳定最长 12 周
- [ ] 复诊一般还要挂号，看医院规定

## 保存资料

- [ ] 病历、检查报告、影像片子
- [ ] 发票、费用清单、处方底方、医保结算单
- [ ] 按时间整理，复诊和报销都要用，至少留到报销完成
- [ ] 异地跨省就医先备案，备案后直接结算

## 出问题找谁

- [ ] 急危重症、外伤、突发剧痛：拨 120 或直接去急诊，危重患者先救治后补费
- [ ] 过号：问护士台能不能补叫
- [ ] 报告异常：按医生安排复诊，不要自己上网查
- [ ] 药物过敏：立即停药去急诊，带上药盒
- [ ] 异地急诊视同已备案，报销比例按参保地政策
