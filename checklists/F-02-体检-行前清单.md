# F-02 第一次体检 · 清单

> 打印后勾选。依据见 [F-02 正文](../book/06-健康与医疗/F-02-第一次体检.md)。

## 选套餐

- [ ] 看医疗机构执业许可证，选公立医院体检中心或正规连锁
- [ ] 基础项目做全：一般检查、内外科、血尿常规、肝肾功能、血脂血糖、心电图、胸片、腹部 B 超
- [ ] 按年龄和性别加项：30 岁以上加血脂、血糖、甲状腺，40 岁以上加胃肠镜、颈动脉超声，女性加乳腺、宫颈筛查
- [ ] 有家族史按医生建议做专项，不选"全身扫描""一滴血查癌"等过度宣传项目
- [ ] 确认是否需要预约、是否要带照片，问清空腹要求

## 前 3 天

- [ ] 清淡饮食，不喝酒（至少提前 3 天），不熬夜，不剧烈运动
- [ ] 停用维生素、保健品（遵医嘱的除外）
- [ ] 女性避开月经期，最好约在月经结束 3–7 天后
- [ ] 怀孕或备孕提前告知，不做胸片、CT 等辐射检查

## 当天带齐

- [ ] 身份证、医保卡或体检卡、预约短信
- [ ] 既往报告和常用药清单
- [ ] 抽血和腹部 B 超要空腹 8–12 小时，前一天晚上 8 点后不进食，可少量喝水
- [ ] 带糖块和水杯，抽血后可喝水

## 现场体检

- [ ] 出示身份证领指引单，看清项目清单、楼层分布和空腹项目
- [ ] 先做空腹项目：抽血、腹部 B 超
- [ ] 抽血后按压 3–5 分钟，不揉
- [ ] 按指引单顺序做其他项目，先做排队少的
- [ ] 不告知病史，医生无法判断结果
- [ ] 交回指引单确认无漏项，再吃早餐补水

## 取报告

- [ ] 按通知时间取纸质报告或线上下载
- [ ] 看异常项和医生建议，按建议挂对应科室复查，不自己上网对号入座
- [ ] 发现结节、息肉按医生建议复查或处理，不恐慌
- [ ] 历年报告长期保存，方便对比趋势

## 出问题找谁

- [ ] 晕针：提前告知，平卧抽血，抽完坐一会儿再走
- [ ] 低血糖：吃糖块，立即吃早餐
- [ ] 报告危重异常：体检中心会电话通知，尽快就诊
- [ ] 被劝"体检代检"：拒绝，代检违法
- [ ] 体检纠纷：保留报告和缴费凭证，向卫健部门投诉
