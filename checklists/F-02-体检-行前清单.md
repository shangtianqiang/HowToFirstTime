# F-02 第一次体检 · 清单

> 打印后勾选。依据见 [F-02 正文](../book/06-健康与医疗/F-02-第一次体检.md)。

## 预约前

- [ ] 选正规体检机构
- [ ] 看执业许可证
- [ ] 选基础和加项
- [ ] 确认预约时间
- [ ] 问清空腹要求

## 前 3 天

- [ ] 清淡饮食
- [ ] 不喝酒
- [ ] 不熬夜
- [ ] 不剧烈运动
- [ ] 停保健品（遵医嘱除外）
- [ ] 女性避开经期

## 当天

- [ ] 身份证
- [ ] 医保卡或体检卡
- [ ] 预约短信
- [ ] 既往报告
- [ ] 空腹 8–12 小时
- [ ] 带糖块和水

## 体检

- [ ] 先抽血和腹部 B 超
- [ ] 抽血后按压 3–5 分钟
- [ ] 按指引单完成项目
- [ ] 交表确认无漏项
- [ ] 吃早餐

## 取报告

- [ ] 按时间取报告
- [ ] 看异常项
- [ ] 按建议复查
- [ ] 保存历年报告

## 出问题找谁

- [ ] 晕针：提前告知，平卧
- [ ] 低血糖：吃糖，吃早餐
- [ ] 危重异常：尽快就诊
- [ ] 体检纠纷：卫健部门投诉
