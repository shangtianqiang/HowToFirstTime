# F-03 第一次住院/手术 · 清单

> 打印后勾选。依据见 [F-03 正文](../book/06-健康与医疗/F-03-第一次住院手术.md)。

## 入院

- [ ] 住院证
- [ ] 身份证
- [ ] 医保卡
- [ ] 押金
- [ ] 既往病历
- [ ] 用药清单
- [ ] 办医保登记
- [ ] 异地就医备案

## 生活用品

- [ ] 换洗衣物
- [ ] 拖鞋、毛巾、牙刷
- [ ] 水杯、吸管
- [ ] 纸巾、湿巾
- [ ] 手机、充电器
- [ ] 陪护用品

## 术前

- [ ] 按医嘱停药
- [ ] 备皮
- [ ] 禁食禁水
- [ ] 取下假牙、首饰
- [ ] 签手术同意书
- [ ] 签麻醉同意书
- [ ] 问清风险和费用

## 术后

- [ ] 监测生命体征
- [ ] 观察伤口和引流
- [ ] 按医嘱用药
- [ ] 早期下床
- [ ] 疼痛及时说

## 出院

- [ ] 结算费用
- [ ] 发票和清单
- [ ] 出院小结
- [ ] 诊断证明
- [ ] 复印病历
- [ ] 预约复查

## 出问题找谁

- [ ] 术后出血：按呼叫铃
- [ ] 发热红肿：报告医生
- [ ] 胸痛呼吸困难：立即呼叫
- [ ] 费用争议：医保办、卫健部门
