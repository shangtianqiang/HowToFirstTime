# F-03 第一次住院/手术 · 清单

> 打印后勾选。依据见 [F-03 正文](../book/06-健康与医疗/F-03-第一次住院手术.md)。

## 办入院

- [ ] 带住院证、身份证、医保卡和押金（银行卡或现金，通常几千到几万元）
- [ ] 带既往病历、检查报告、用药清单，记牢过敏史
- [ ] 交材料办手续，拿住院手环，记下床位、科室、住院号
- [ ] 入院后按医院要求时限办医保登记，问清报销比例、起付线和自费项目
- [ ] 异地就医先备案：国家医保服务平台 App 或参保地医保经办机构办理
- [ ] 办陪护证，遵守探视时间

## 生活用品

- [ ] 换洗衣物、拖鞋、毛巾、牙刷
- [ ] 水杯、吸管、纸巾、湿巾，便盆或尿壶按需
- [ ] 手机、充电器、充电宝
- [ ] 陪护人的折叠床或到医院租用
- [ ] 请护工选医院认可的正规机构并签合同，费用约 200–400 元/天

## 术前

- [ ] 按医嘱停药：抗凝药、降糖药、降压药不自行停也不自行续
- [ ] 备皮、清洁按护士要求
- [ ] 禁食 6–8 小时、禁水 2–4 小时，按麻醉科要求执行，不自行缩短
- [ ] 术前检查和麻醉评估如实告知病史和用药
- [ ] 取下假牙、首饰、隐形眼镜，换病号服
- [ ] 签手术同意书和麻醉同意书，签字前问清风险、替代方案和费用

## 术后

- [ ] 监测生命体征，观察伤口和引流
- [ ] 疼痛及时告诉护士，按医嘱用镇痛药，不硬扛
- [ ] 按医嘱活动、饮食、用药
- [ ] 早期下床，预防血栓
- [ ] 输液反应：关输液阀，叫护士

## 出院

- [ ] 拿到出院医嘱再结算费用，打印发票和费用清单
- [ ] 核对费用清单，自费项目多，出院才发现
- [ ] 拿出院小结和诊断证明，复查、报销都要用
- [ ] 需要报销或转诊就到病案室复印病历，带身份证和委托书
- [ ] 按出院小结时间预约复查：一般术后 1–2 周、1 个月、3 个月

## 出问题找谁

- [ ] 术后出血：立即按呼叫铃叫护士
- [ ] 发热、伤口红肿：报告医生，可能感染
- [ ] 呼吸困难、胸痛：立即呼叫，警惕肺栓塞
- [ ] 费用争议：核对清单，向医保办或卫健部门投诉
- [ ] 医疗纠纷：封存病历，保留证据，走调解或法律途径
