# F-04 第一次看牙 · 清单

> 打印后勾选。依据见 [F-04 正文](../book/06-健康与医疗/F-04-第一次看牙.md)。

## 就诊前

- [ ] 选有医疗机构执业许可证的机构，看医生执业资质
- [ ] 看器械是否独立包装拆封、是否一次性，不合规范的换一家
- [ ] 不轻信"免费检查、低价种植"广告，先问清总费用
- [ ] 带身份证、医保卡和既往牙片
- [ ] 带正在吃的药清单，特别是抗凝药，说明过敏史
- [ ] 高血压、糖尿病、心脏病患者先控制病情再拔牙
- [ ] 吃饱饭再去，拔牙后 2 小时内不能进食；女性拔牙避开经期

## 就诊

- [ ] 说明症状，配合检查和拍牙片，不拍片就治疗容易漏诊
- [ ] 问清诊断和治疗方案：步骤、次数（根管治疗通常 2–4 次）和每次费用
- [ ] 问清哪些医保可报、哪些自费：补牙、拔牙、根管等治疗类可报，种植、正畸、美白多为自费
- [ ] 对比材料价格，不盲目选最贵
- [ ] 治疗中不舒服举手示意，不要突然闭嘴
- [ ] 确认方案签字后治疗，缴费保留发票和病历

## 治疗后

- [ ] 预约下次复诊时间
- [ ] 拔牙后咬棉球 30–40 分钟再吐
- [ ] 拔牙 24 小时内不漱口、不刷牙、不吸吮、不吃热食
- [ ] 补牙 24 小时内不用患侧咬硬物
- [ ] 洗牙后牙齿短期敏感，几天内避免过冷过热

## 日常预防

- [ ] 每天刷牙 2 次，用牙线
- [ ] 每年洗牙 1–2 次
- [ ] 每半年做一次口腔检查，小洞早补别拖成大洞
- [ ] 儿童第一颗牙萌出后 6 个月内看牙，及时做窝沟封闭
- [ ] 儿童乳牙不治，影响恒牙发育

## 出问题找谁

- [ ] 拔牙后出血不止：继续咬紧棉球，冷敷，及时复诊
- [ ] 术后发热、肿胀加重：可能感染，及时就医
- [ ] 麻药过敏：立即告知医生
- [ ] 器械破损：立即告知并保留证据
- [ ] 医疗纠纷：封存病历，向卫健部门投诉；牙痛夜间加重看急诊口腔或次早就诊
