# F-04 第一次看牙 · 清单

> 打印后勾选。依据见 [F-04 正文](../book/06-健康与医疗/F-04-第一次看牙.md)。

## 就诊前

- [ ] 选有执业许可证的机构
- [ ] 吃饱饭
- [ ] 带身份证、医保卡
- [ ] 带既往牙片
- [ ] 告知用药和过敏史
- [ ] 女性避开经期（拔牙）

## 就诊

- [ ] 说明症状
- [ ] 拍牙片
- [ ] 问清诊断
- [ ] 问清治疗方案和次数
- [ ] 问清医保和自费项目
- [ ] 确认总费用

## 治疗后

- [ ] 保留发票和病历
- [ ] 预约复诊
- [ ] 拔牙咬棉球 30–40 分钟
- [ ] 24 小时内不漱口不刷牙
- [ ] 不吃热食、不吸吮
- [ ] 补牙 24 小时内不用患侧咬硬物

## 预防

- [ ] 每天刷牙 2 次
- [ ] 用牙线
- [ ] 每年洗牙 1–2 次
- [ ] 每半年检查一次
- [ ] 儿童做窝沟封闭

## 出问题找谁

- [ ] 出血不止：咬棉球、冷敷、复诊
- [ ] 发热肿胀：及时就医
- [ ] 麻药过敏：立即告知医生
- [ ] 医疗纠纷：封存病历、卫健部门
