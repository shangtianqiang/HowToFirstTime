# F-05 第一次配眼镜 · 清单

> 打印后勾选。依据见 [F-05 正文](../book/06-健康与医疗/F-05-第一次配眼镜.md)。

## 验光前

- [ ] 选医院眼科或正规眼镜店
- [ ] 带旧眼镜
- [ ] 带既往验光单
- [ ] 隐形眼镜停戴
- [ ] 儿童准备散瞳，带帽子

## 验光

- [ ] 电脑验光
- [ ] 综合验光仪
- [ ] 试镜架
- [ ] 测瞳距
- [ ] 测散光轴位
- [ ] 拿验光处方

## 选镜

- [ ] 按度数选折射率
- [ ] 镜框不夹脸
- [ ] 瞳孔对准镜片中心
- [ ] 鼻托可调
- [ ] 问清售后

## 取镜

- [ ] 核对度数
- [ ] 核对散光轴位
- [ ] 核对瞳距
- [ ] 试戴 20–30 分钟
- [ ] 不适及时调整

## 日常

- [ ] 每天户外 2 小时
- [ ] 20-20-20 法则
- [ ] 儿童每半年复查
- [ ] 成人每年复查
- [ ] 镜架变形及时调整

## 出问题找谁

- [ ] 头晕恶心：复查度数、轴位、瞳距
- [ ] 视力骤降：及时就医
- [ ] 镜片破碎：联系店家
- [ ] 角膜感染：停戴隐形，立即就医
