# F-05 第一次配眼镜 · 清单

> 打印后勾选。依据见 [F-05 正文](../book/06-健康与医疗/F-05-第一次配眼镜.md)。

## 验光前

- [ ] 儿童青少年首次验光先去医院眼科散瞳，成人可到有持证验光师的正规眼镜店
- [ ] 不在地摊、无资质网店直接配镜
- [ ] 问清验光是否收费、是否含复查
- [ ] 带旧眼镜和既往验光单
- [ ] 验光前 1–2 天不长时间近距离用眼；戴隐形眼镜的软镜停戴 1–2 天、硬镜停戴 1–2 周
- [ ] 儿童散瞳后 4–6 小时怕光、看近模糊，带帽子和遮阳

## 验光

- [ ] 电脑验光只作参考，必须再做综合验光仪和试镜架
- [ ] 配合红绿测试、散光盘、双眼平衡
- [ ] 处方四项要齐全：球镜度数、柱镜度数（散光）、轴位、瞳距
- [ ] 瞳距两眼分别测，对照旧镜度数
- [ ] 拿到验光处方再配镜

## 选镜片镜框

- [ ] 折射率按度数选：300 度以下选 1.56 或 1.60，300–600 度选 1.60 或 1.67，600 度以上选 1.67 或 1.74
- [ ] 折射率不是越高越好，低度数配高折射率多花钱，色散可能更明显
- [ ] 防蓝光镜片对缓解眼疲劳作用有限，按需选
- [ ] 镜框轻、稳、不夹脸，瞳孔对准镜片中心，鼻托可调、镜腿不压耳
- [ ] 选定镜框后测瞳距和瞳高
- [ ] 问清售后：镜架调整、保修

## 取镜试戴

- [ ] 核对镜片度数、散光轴位、瞳距
- [ ] 试戴 20–30 分钟，走路、看远、看近
- [ ] 头晕、眼胀明显，让店里调整或重新验配
- [ ] 新镜一般 3–7 天适应

## 日常用眼

- [ ] 每天户外活动 2 小时，控制近距离用眼，记住 20-20-20 法则
- [ ] 儿童每半年到一年复查，成人每年复查、1–2 年换镜
- [ ] 镜架变形及时调整
- [ ] 隐形眼镜要验配、测基弧，注意卫生，不戴着睡觉
- [ ] 别信"降度数"训练，真性近视不可逆

## 出问题找谁

- [ ] 戴镜后头痛、恶心：复查度数、散光轴位和瞳距，调整或重配
- [ ] 儿童视力突然下降：及时就医，排除眼病
- [ ] 镜片破碎：保留碎片，联系店家检查是否质量问题
- [ ] 角膜感染：停戴隐形眼镜，立即就医
- [ ] 化学物品入眼：立即用清水冲洗 15 分钟再就医
- [ ] 验光纠纷：保留验光单和发票，向市场监管部门投诉
