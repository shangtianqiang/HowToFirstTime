# F-06 第一次看心理医生 · 清单

> 打印后勾选。依据见 [F-06 正文](../book/06-健康与医疗/F-06-第一次看心理医生.md)。

## 就诊前

- [ ] 分清精神科和心理咨询
- [ ] 选正规医院或机构
- [ ] 带身份证、医保卡
- [ ] 带既往病历和药物
- [ ] 记录症状和持续时间
- [ ] 记录睡眠、食欲变化

## 初诊

- [ ] 如实说症状
- [ ] 说生活事件和压力
- [ ] 说家族史
- [ ] 配合量表
- [ ] 问清诊断
- [ ] 问清治疗方案

## 治疗

- [ ] 按医嘱用药
- [ ] 记录副作用
- [ ] 按时复诊
- [ ] 不自行停药
- [ ] 咨询按预约进行

## 危机

- [ ] 告诉家人或朋友
- [ ] 拨 12356 或 120
- [ ] 去精神专科急诊
- [ ] 移除危险物品
- [ ] 不独处

## 出问题找谁

- [ ] 药物过敏：停药就医
- [ ] 症状加重：提前复诊
- [ ] 遭遇歧视：医院投诉、卫健部门
- [ ] 未成年人：监护人陪同
