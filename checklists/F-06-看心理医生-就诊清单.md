# F-06 第一次看心理医生 · 清单

> 打印后勾选。依据见 [F-06 正文](../book/06-健康与医疗/F-06-第一次看心理医生.md)。

## 就诊前

- [ ] 情绪低落、焦虑、失眠持续 2 周以上、影响工作学习，就去就诊，越早干预越好
- [ ] 分清机构：医院精神科/心理科能诊断开药，心理咨询机构只做谈话治疗、不能开药
- [ ] 选正规医院或有资质的咨询师，看资质和受训背景
- [ ] 带身份证、医保卡、既往病历和检查报告
- [ ] 带正在吃的药
- [ ] 记录症状：什么时候开始、什么情况下加重，睡眠、食欲、体重变化
- [ ] 记住家族史；看心理医生不是"有精神病"，是处理情绪和压力

## 初诊

- [ ] 如实说症状、持续时间、影响、用药史和生活事件，不隐瞒
- [ ] 说清家族史
- [ ] 配合心理量表和化验，量表只是筛查，不能替代诊断
- [ ] 问清诊断和治疗方案
- [ ] 问清保密范围：咨询内容保密，涉及自伤、伤人、法律要求除外
- [ ] 咨询通常需要多次，不期待一次解决；不合适可以换医生

## 治疗期间

- [ ] 按医嘱用药，抗抑郁药通常 2–4 周起效，不要几天没效就停
- [ ] 记录副作用，复诊时反馈药物效果
- [ ] 不自行加减停药，减量要医生指导
- [ ] 心理治疗每周或每两周一次、每次 50 分钟，按预约进行
- [ ] 精神科门诊和住院按医保规定报销，心理咨询多为自费
- [ ] 不靠喝酒缓解情绪，不网络自诊

## 危机

- [ ] 有自伤、自杀念头：立即告诉家人或朋友，不要独处
- [ ] 拨 12356 心理援助热线或 120
- [ ] 去精神专科急诊
- [ ] 移除家中危险物品
- [ ] 惊恐发作：坐下，缓慢呼吸，告诉身边人，必要时就医

## 出问题找谁

- [ ] 药物过敏（皮疹、呼吸困难）：立即停药并就医
- [ ] 症状加重或严重失眠：提前复诊，不自行加安眠药
- [ ] 家人不理解：带家人一起就诊，让医生解释
- [ ] 遭遇歧视：保留证据，向医院投诉或向卫健部门反映
- [ ] 未成年人：监护人陪同，学校心理老师可协助转介；医疗记录受隐私保护
