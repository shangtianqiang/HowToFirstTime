# F-07 第一次拨 120/急救 · 清单

> 打印后勾选。依据见 [F-07 正文](../book/06-健康与医疗/F-07-第一次拨120急救.md)。

## 平时准备

- [ ] 存好 120、110、119，记住家庭详细地址和门牌号
- [ ] 了解附近 AED 位置：地铁站、商场、体育馆
- [ ] 学一次心肺复苏，参加红十字会等急救培训；家里备急救包
- [ ] 这些情况立即拨 120：意识丧失、呼吸停止、胸痛超过 15 分钟、口角歪斜/说话不清/肢体无力、大出血、呼吸困难嘴唇发紫、抽搐、误服药物、溺水、触电

## 现场判断

- [ ] 拍肩大声呼叫，看有没有反应
- [ ] 看胸廓是否起伏，判断有没有正常呼吸
- [ ] 看出血、肤色
- [ ] 记下发病时间；中风识别记住脸歪、手臂无力、说话不清，任何一项立即拨 120

## 拨 120

- [ ] 说清地址：区、路、门牌、楼栋、楼层
- [ ] 说人数、主要伤情和联系电话，按调度员提问回答
- [ ] 保持通话，调度员会指导操作，不先挂电话
- [ ] 派人到路口接急救车

## 心肺复苏与 AED

- [ ] 无呼吸立即按压：仰卧硬平面，双手交叠，掌根放两乳头连线中点
- [ ] 频率 100–120 次/分，深度 5–6 厘米，每次让胸廓完全回弹
- [ ] 30 次按压加 2 次人工呼吸；不会人工呼吸可以只按压
- [ ] 持续按压直到急救人员接手或患者恢复呼吸
- [ ] 尽快取 AED，开机按语音提示贴电极片
- [ ] 分析心律时不要接触患者
- [ ] 提示电击时按下按钮，电击后立即继续按压
- [ ] 窒息（噎住）：成人海姆立克腹部冲击；婴儿拍背 5 次加胸部按压 5 次，意识丧失立即心肺复苏

## 交接与特殊场景

- [ ] 向急救人员说明发病时间、做过什么处理、用药情况
- [ ] 带上身份证、医保卡、病历
- [ ] 大出血：直接压迫止血，抬高患肢
- [ ] 车祸：先确保自身安全，拨 120、122，不随意搬动伤者
- [ ] 溺水：先救上岸，检查呼吸，立即心肺复苏；触电：先断电，不直接拉人
- [ ] 一氧化碳中毒：开窗通风，转移患者；过敏休克：拨 120，平卧

## 不做什么

- [ ] 不先拍照发群，不耽误抢救
- [ ] 不随意搬动伤者，怀疑脊柱损伤除非有危险不搬
- [ ] 不掐人中，不给意识不清者喂水喂药
- [ ] 抽搐：移开硬物，侧卧，不塞东西到嘴里，记录时间，超过 5 分钟拨 120
- [ ] 胸痛不自行吃阿司匹林，等急救人员指导；不做只人工呼吸不按压
