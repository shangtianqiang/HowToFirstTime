# F-07 第一次拨 120/急救 · 清单

> 打印后勾选。依据见 [F-07 正文](../book/06-健康与医疗/F-07-第一次拨120急救.md)。

## 平时

- [ ] 存 120、110、119
- [ ] 记住家庭详细地址
- [ ] 了解附近 AED
- [ ] 参加急救培训
- [ ] 家里备急救包

## 判断

- [ ] 拍肩呼叫
- [ ] 看胸廓起伏
- [ ] 看出血和肤色
- [ ] 记录发病时间

## 拨 120

- [ ] 说准确地址
- [ ] 说人数和伤情
- [ ] 说联系电话
- [ ] 派人到路口接车
- [ ] 不先挂电话

## 急救

- [ ] 无呼吸立即按压
- [ ] 100–120 次/分
- [ ] 深度 5–6 厘米
- [ ] 让胸廓回弹
- [ ] 取 AED
- [ ] 按语音贴片电击
- [ ] 窒息用海姆立克

## 交接

- [ ] 说明发病时间
- [ ] 说明做过什么
- [ ] 带身份证、医保卡、病历
- [ ] 告知用药情况

## 不做什么

- [ ] 不先拍照发群
- [ ] 不随意搬动伤者
- [ ] 不掐人中
- [ ] 不给意识不清者喂水
- [ ] 不往抽搐者嘴里塞东西
