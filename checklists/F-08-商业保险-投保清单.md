# F-08 第一次买商业保险 · 清单

> 打印后勾选。依据见 [F-08 正文](../book/06-健康与医疗/F-08-第一次买商业保险.md)。

## 投保前

- [ ] 确认已有医保
- [ ] 先保家庭经济支柱
- [ ] 预算控制在年收入 5%–10%
- [ ] 对比保障责任
- [ ] 看清免赔额和等待期
- [ ] 看免责条款

## 健康告知

- [ ] 逐条阅读
- [ ] 问到的如实答
- [ ] 不确定的查病历
- [ ] 智能核保不通过试人工
- [ ] 保留告知记录

## 投保

- [ ] 核对姓名、身份证号
- [ ] 核对受益人
- [ ] 确认保费和缴费期
- [ ] 本人签名
- [ ] 收到电子保单
- [ ] 官网查验保单

## 犹豫期

- [ ] 核对保障内容
- [ ] 确认是否需要调整
- [ ] 15 天内可全额退保

## 理赔

- [ ] 及时报案
- [ ] 诊断证明
- [ ] 病历
- [ ] 发票和费用清单
- [ ] 银行卡
- [ ] 跟进核定进度

## 出问题找谁

- [ ] 拒赔：要书面理由，申诉
- [ ] 销售误导：保留证据，12378
- [ ] 保单丢失：App 或客服补发
- [ ] 忘记缴费：宽限期内补缴
