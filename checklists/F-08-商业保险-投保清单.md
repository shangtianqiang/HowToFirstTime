# F-08 第一次买商业保险 · 清单

> 打印后勾选。依据见 [F-08 正文](../book/06-健康与医疗/F-08-第一次买商业保险.md)。

## 投保前

- [ ] 先配医保，再买意外险、医疗险，预算够再加重疾险、寿险
- [ ] 先保家庭经济支柱，先大人后小孩
- [ ] 预算控制在年收入 5%–10%，不把保险当理财
- [ ] 对比保障责任、保额和保费，保额优先于返还
- [ ] 看清等待期：医疗险常见 30 天，重疾险 90–180 天，等待期内出险不赔
- [ ] 看清免赔额：百万医疗通常 1 万元，超过部分才报
- [ ] 看免责条款：酒驾、斗殴、既往症可能不赔；分清条款写的是"保证续保"还是"可续保"

## 健康告知

- [ ] 逐条阅读，问什么答什么，如实告知
- [ ] 不确定的查病历或问客服，不留空白；隐瞒既往症理赔可能被拒
- [ ] 智能核保不通过，可尝试人工核保
- [ ] 备好体检报告、病历（如问及）、社保参保信息和受益人信息
- [ ] 保留健康告知记录

## 投保

- [ ] 从保险公司官网、官方 App 或持牌经纪平台投保
- [ ] 核对姓名、身份证号和受益人信息
- [ ] 确认保费、缴费期限和保障期限
- [ ] 本人签名，代签名合同可能无效
- [ ] 收到电子保单后在官网或监管平台查验
- [ ] 保留电子保单和告知记录

## 犹豫期

- [ ] 收到保单后核对保障内容和保费
- [ ] 确认保留或退保
- [ ] 长期人身险 15 天内不满意可全额退保
- [ ] 过了犹豫期退保只退现金价值，可能亏损

## 理赔

- [ ] 出险后及时打客服电话或在 App 报案
- [ ] 备齐诊断证明、病历、发票和费用清单、银行卡
- [ ] 等待期内出险按条款处理，保留就诊记录
- [ ] 材料齐全后保险公司 30 日内核定，达成协议 10 日内赔付，跟进进度

## 出问题找谁

- [ ] 拒赔：书面要求说明理由，向保险公司申诉
- [ ] 申诉不成或销售误导：保留聊天、录音，拨 12378，必要时诉讼
- [ ] 既往症被拒赔：调取投保时的健康告知，申诉或投诉
- [ ] 保单丢失：在保险公司 App 或找客服补发
- [ ] 忘记缴费：宽限期内补缴，超过可能失效
- [ ] 被"返还型""低保费"吸引：回头再核对保障责任，别只看保费
