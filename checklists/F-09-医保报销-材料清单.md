# F-09 第一次医保报销 · 清单

> 打印后勾选。依据见 [F-09 正文](../book/06-健康与医疗/F-09-第一次医保报销.md)。

## 就医前

- [ ] 确认医保参保状态正常
- [ ] 带社保卡或医保码
- [ ] 异地就医先备案
- [ ] 查药品和项目是否在医保目录

## 门诊结算

- [ ] 挂号、就诊时出示医保凭证
- [ ] 结算时看费用清单
- [ ] 确认医保支付和个人自付
- [ ] 保存发票和清单

## 住院结算

- [ ] 入院时登记医保
- [ ] 出院时直接结算
- [ ] 核对住院费用总清单
- [ ] 保存发票、清单和出院记录

## 手工报销

- [ ] 医保电子凭证或身份证或社保卡
- [ ] 医院收费票据
- [ ] 门急诊费用清单
- [ ] 处方底方
- [ ] 材料齐全后不超过 30 个工作日

## 出问题找谁

- [ ] 不能直接结算：先自费，回参保地报销
- [ ] 报销被拒：问清原因并申请复核
- [ ] 医保断缴：及时续保
- [ ] 大病费用：基本医保后自动进入大病保险
