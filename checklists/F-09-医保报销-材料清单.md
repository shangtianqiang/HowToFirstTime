# F-09 第一次医保报销 · 清单

> 打印后勾选。依据见 [F-09 正文](../book/06-健康与医疗/F-09-第一次医保报销.md)。

## 就医前

- [ ] 确认医保参保状态正常；居民医保一年一缴，断缴影响待遇
- [ ] 激活医保码：国家医保服务平台 App、支付宝或微信，就医出示；或带社保卡
- [ ] 查药品和项目在不在三大目录：药品、诊疗项目、医用耗材，目录外全自费
- [ ] 分清甲类乙类：甲类全额纳入后按比例报，乙类先自付一部分再报
- [ ] 记住三条线：起付线以下自付，起付线以上到封顶线按比例报，具体数值查参保地医保局

## 异地就医

- [ ] 长期异地居住或临时外出就医，先办备案
- [ ] 备案渠道：参保地经办窗口、国家医保服务平台 App、国家异地就医备案小程序、国务院客户端
- [ ] 线上备案原则上 2 个工作日办结
- [ ] 急诊抢救视同已备案，报销比例按参保地政策
- [ ] 备案后直接结算，按"就医地目录、参保地政策"

## 门诊与住院结算

- [ ] 挂号、就诊、结算全程出示医保凭证
- [ ] 结算时看费用清单上的医保支付和个人自付
- [ ] 用自费药或目录外项目，医生应提前告知
- [ ] 入院登记医保，出院直接结算
- [ ] 出院前逐笔核对住院费用总清单
- [ ] 系统故障不能结算：先自费，保留票据回参保地手工报销
- [ ] 保存发票、清单和出院记录，手工报销要原件

## 手工报销

- [ ] 没直接结算的，回参保地经办机构或线上平台申请
- [ ] 备齐医保电子凭证或身份证或社保卡
- [ ] 备齐医院收费票据、门急诊费用清单、处方底方
- [ ] 材料齐全后一般不超过 30 个工作日
- [ ] 材料不齐，当场问清能不能后补

## 大病保险与不报范围

- [ ] 居民参保人大病保险自动享受，不用另外缴费
- [ ] 大病保险支付比例不低于 60%，医疗费用越高比例越高
- [ ] 工伤、第三方责任、公共卫生、境外就医，医保不报
- [ ] 体检、养生保健、美容、非功能性整容，也不报
- [ ] 职工普通门诊已纳入统筹，支付比例从 50% 起步

## 出问题找谁

- [ ] 报销金额有疑问：先查费用清单和目录，再向经办机构申请复核
- [ ] 医保卡不借给别人用，不参与"医保套现"
- [ ] 报销被拒：问清原因，查目录和政策
- [ ] 查进度：国家医保服务平台 App，或拨 12393、12345
