# F-10 第一次献血 · 清单

> 打印后勾选。依据见 [F-10 正文](../book/06-健康与医疗/F-10-第一次献血.md)。

## 献血前

- [ ] 确认年龄 18–55 周岁
- [ ] 确认体重达标
- [ ] 没有感冒发热
- [ ] 近期无手术、纹身、拔牙
- [ ] 前一晚睡足
- [ ] 不喝酒
- [ ] 吃清淡食物，不空腹
- [ ] 带身份证

## 献血中

- [ ] 如实填写健康征询表
- [ ] 量血压、脉搏
- [ ] 血红蛋白初筛
- [ ] 握拳松拳配合
- [ ] 观察一次性耗材

## 献血后

- [ ] 按压针眼 10 分钟
- [ ] 休息 15–30 分钟
- [ ] 喝糖水
- [ ] 24 小时不剧烈运动
- [ ] 不喝酒
- [ ] 针眼保持干燥
- [ ] 领取献血证

## 用血

- [ ] 保存献血证
- [ ] 了解本人用血减免
- [ ] 了解亲属用血规定
- [ ] 需要时联系血站

## 出问题找谁

- [ ] 头晕心慌：坐下平卧，叫工作人员
- [ ] 针眼出血：重新按压
- [ ] 化验异常：按通知复查
- [ ] 献血纠纷：卫健部门投诉
