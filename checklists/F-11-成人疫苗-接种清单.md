# F-11 第一次打成人疫苗 · 清单

> 打印后勾选。依据见 [F-11 正文](../book/06-健康与医疗/F-11-第一次打成人疫苗.md)。

## 打疫苗前

- [ ] 定好疫苗名称，对照适用年龄和针次
- [ ] 查当地有无免费或惠民接种政策
- [ ] 用疾控公众号、政务 App 或电话预约，确认到苗
- [ ] 记下门诊名称、地址、开放时间
- [ ] 估算费用，准备好支付方式

## 出门前

- [ ] 带身份证
- [ ] 带既往接种记录或纸质接种证（换过城市接种的尤其要带）
- [ ] 想清楚过敏史、慢病、怀孕备孕情况，登记时如实说
- [ ] 穿方便露出上臂的衣服

## 在门诊

- [ ] 取号建档，出示预约码或身份证
- [ ] 回答健康询问，读懂知情同意书后再签字
- [ ] 核对疫苗名称、有效期、剂次
- [ ] 接种后在留观区待满 30 分钟
- [ ] 确认接种凭证或电子记录已更新
- [ ] 约好下一针时间，或记下预约方式

## 打完后

- [ ] 接种部位保持清洁，一般反应多 1～2 天自行缓解
- [ ] 高热不退、严重皮疹、呼吸不畅：及时就医并告知接种史
- [ ] 查记录：在本地政务 App 或疾控小程序领电子预防接种证
- [ ] 多剂次疫苗把下一针时间记进日历

## 出问题找谁

- [ ] 留观时心慌、呼吸困难、皮疹加重：呼叫留观区医护
- [ ] 回家后严重不适：就医，同时联系接种门诊
- [ ] 预约不上：换疾控公众号、门诊电话登记、跨区预约
- [ ] 跨城市续种：带全部记录到现居住地门诊建档
- [ ] 情况复杂（孕期、免疫低下、慢病）：以接种门诊医生评估为准
