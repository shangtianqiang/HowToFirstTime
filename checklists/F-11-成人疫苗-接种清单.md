# F-11 第一次打成人疫苗 · 清单

> 打印后勾选。依据见 [F-11 正文](../book/06-健康与医疗/F-11-第一次打成人疫苗.md)。

## 打疫苗前

- [ ] 定好疫苗名称，对照适用年龄和针次；HPV 获批上限 45 岁，别信"超龄可操作"广告
- [ ] 查当地免费或惠民接种政策：13 岁女孩双价 HPV 已免费接种
- [ ] 用疾控公众号、政务 App 或电话预约，确认到苗；不找"黄牛"，不用非官方小程序
- [ ] 记下门诊名称、地址、开放时间
- [ ] 成人疫苗多为自费，先问清疫苗费和服务费

## 出门前

- [ ] 提前 24 小时电话确认到苗和针次安排，避免白跑
- [ ] 正在发热或有急性疾病，先电话问门诊能否按时接种
- [ ] 带身份证和手机（预约码、支付、电子接种证）
- [ ] 带既往接种记录或纸质接种证（换过城市尤其要带）
- [ ] 想清楚过敏史、慢病、怀孕备孕情况；穿方便露出上臂的衣服

## 在门诊

- [ ] 取号建档，出示预约码或身份证
- [ ] 回答健康询问，如实说怀孕备孕、正在服药；读懂知情同意书再签字
- [ ] 核对疫苗名称、有效期、剂次，可主动看疫苗盒
- [ ] 留观区待满 30 分钟，别提前走——严重过敏多发生在这半小时内
- [ ] 确认接种凭证或电子记录已更新
- [ ] 多剂次疫苗当场约下一针，或记下预约方式
- [ ] 缴费时核对收费明细

## 常用疫苗对照

- [ ] 流感疫苗：9 岁以上每流行季 1 剂，最好流行季前完成
- [ ] 乙肝疫苗：按 0、1、6 月各 1 剂，全程共 3 剂
- [ ] 带状疱疹：重组苗 50 岁及以上 2 剂、间隔 2～6 个月；减毒活苗 40 岁及以上 1 剂
- [ ] HPV 疫苗：女性常规 3 剂，9～14 岁可选 2 剂；进口四价和九价也获批用于男性
- [ ] "破伤风针"多是被动免疫制剂，不是疫苗，要不要打由医生判断

## 打完后

- [ ] 接种部位保持清洁，一般反应多 1～2 天自行缓解
- [ ] 高热不退、严重皮疹、呼吸不畅：及时就医，告知接种时间和疫苗名称
- [ ] 在本地政务 App 或疾控小程序领电子预防接种证，换城市前先领好
- [ ] 下一针时间记进日历；超期了一般不用从头再来，带记录去门诊评估

## 出问题找谁

- [ ] 留观时心慌、呼吸困难、皮疹加重：立刻呼叫留观区医护
- [ ] 回家后严重不适：就医，同时联系接种门诊
- [ ] 预约不上：换疾控公众号、门诊电话登记、跨区跨市预约，热门疫苗排队几周属正常
- [ ] 跨城市续种：带全部接种记录到现居住地门诊建档
- [ ] 孕期、哺乳、免疫低下、慢病：登记时告知医生，以接种门诊评估为准
