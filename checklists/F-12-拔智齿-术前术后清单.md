# F-12 第一次拔智齿 · 清单

> 打印后勾选。依据见 [F-12 正文](../book/06-健康与医疗/F-12-第一次拔智齿.md)。

## 术前 1–2 周（评估）

- [ ] 挂口腔颌面外科或口腔外科号
- [ ] 带身份证、医保卡
- [ ] 带既往牙片、体检报告、正在吃的药清单
- [ ] 高血压、糖尿病、心脏病、抗凝药等病史，主动告知
- [ ] 智齿正在发炎：先消炎，炎症控制后再约手术
- [ ] 女性避开月经期
- [ ] 要不要拔、一次拔几颗，等医生评估后定

## 术前 24 小时

- [ ] 确认预约时间和地点
- [ ] 不熬夜、不喝酒
- [ ] 备好温凉软食：粥、面条、鸡蛋羹、布丁
- [ ] 复杂拔牙安排陪同人
- [ ] 准备冰袋

## 出门前

- [ ] 术前 1–2 小时吃清淡食物，不空腹、不过饱
- [ ] 穿宽松、领口不紧的衣服
- [ ] 带身份证、医保卡、病历和牙片
- [ ] 手机有电，支付方式可用

## 手术当天（术后 24 小时内）

- [ ] 咬棉球 30–40 分钟再吐出，复杂拔牙可到 1 小时
- [ ] 2 小时后吃温凉软食，用对侧咀嚼
- [ ] 当天不刷牙、不漱口
- [ ] 不舔、不吸创口，不用吸管，不频繁吐口水
- [ ] 24 小时内冰敷，每次 15 分钟左右，每小时一次，不热敷
- [ ] 按医嘱吃止痛药
- [ ] 麻药没退不咬嘴唇、不嚼东西
- [ ] 当天不开车，不剧烈运动

## 术后 72 小时

- [ ] 口水少量血丝属正常，咽下去，观察即可
- [ ] 3 天内不烟酒、不吃辛辣烫硬食物
- [ ] 72 小时内避免剧烈运动和体力劳动
- [ ] 肿痛一般 3 天后减轻
- [ ] 有缝线：7–10 天复诊拆线

## 出问题找谁

- [ ] 出血不止：换干净棉球再咬 30–60 分钟，无效回医院
- [ ] 疼痛加重、口腔有臭味：回口腔外科，让医生查干槽症
- [ ] 发热、肿胀加重、张口困难：当天回医院，必要时急诊
- [ ] 麻药超过 4 小时不退：联系手术医院
- [ ] 缝线脱落、伤口裂开：复诊，不自己处理
- [ ] 皮疹、心慌、呼吸困难：立刻回医院或拨 120
