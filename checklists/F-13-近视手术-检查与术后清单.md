# F-13 第一次做近视手术 · 清单

> 打印后勾选。依据见 [F-13 正文](../book/06-健康与医疗/F-13-第一次做近视手术.md)。是否手术以医生评估为准。

## 检查前

- [ ] 确认年满 18 周岁、近两年度数稳定
- [ ] 停戴隐形眼镜：软镜 1 周 / 散光软镜、RGP 3 周 / OK 镜 3 个月
- [ ] 检查当天带太阳镜（可能散瞳），不自己开车
- [ ] 备好问题清单：术式差别、完整报价、主刀经验、术后预案
- [ ] 核验机构执业资质和手术资质

## 确定方案

- [ ] 对比医生建议与预算，确认术式
- [ ] 逐条读完知情同意书再签字
- [ ] 确认费用含检查/手术/复查/药费，防加项

## 手术当天

- [ ] 按约到院，再验光核对
- [ ] 术后按医嘱滴药、戴防护眼罩
- [ ] 拿到用药清单和复查时间表再离开

## 术后

- [ ] 复查节点：1 天 / 1 周 / 1 个月 / 3 个月 / 6 个月 / 12 个月
- [ ] 3 天脏水不入眼，1 周少看屏幕，1 月不揉眼不游泳
- [ ] 眼红、疼痛、视力骤降：立即联系机构急诊复查
- [ ] 征兵考警校的：确认术后满 6 个月再体检
