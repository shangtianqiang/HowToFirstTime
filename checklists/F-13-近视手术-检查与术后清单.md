# F-13 第一次做近视手术 · 清单

> 打印后勾选。依据见 [F-13 正文](../book/06-健康与医疗/F-13-第一次做近视手术.md)。是否手术以医生评估为准。

## 检查前自查

- [ ] 确认年满 18 周岁、近两年度数稳定；孕期哺乳期一般暂缓
- [ ] 有活动性眼病、未控制圆锥角膜、严重干眼等禁忌情形，以检查为准
- [ ] 有征兵、考公、考警校计划：先查当年体检标准，倒排手术日期（激光类一般要求术后满 6 个月，ICL 通常不符合）
- [ ] 停戴隐形眼镜：普通软镜 1 周 / 散光软镜、RGP 3 周 / OK 镜 3 个月
- [ ] 检查前规律作息，别熬夜刷手机

## 选机构与预算

- [ ] 首选公立三甲眼科或大型眼科专科医院，核验「医疗机构执业许可」和手术资质
- [ ] 主刀医生的资质和手术量，直接开口问
- [ ] 要完整报价：含术前检查、手术、术后复查和药费，防低价引流高价成交
- [ ] 对齐预算：半飞秒约 8000–20000 元、全飞秒约 13000–19000 元、ICL 约 28000–35000 元（双眼）

## 检查当天

- [ ] 带身份证实名预约；检查可能散瞳，带太阳镜，别自己开车
- [ ] 术前检查 20 多项、约 2 小时，角膜厚度和形态是关键
- [ ] 听结论：可做/不可做、适合哪种术式；不适合的会明确告知原因
- [ ] 术式由检查结果定：角膜厚选激光类，角膜薄或超高度数评估 ICL
- [ ] 别当天连做：正规流程是检查→方案沟通→另约手术日

## 手术前确认

- [ ] 备好问题清单：术式差别、费用构成、主刀经验、术后预案
- [ ] 逐条读完知情同意书再签，重点看并发症和处理预案
- [ ] 警惕「摘镜保证」承诺；不写保证数字的机构才可信
- [ ] 手术费属自费，医保不报销（部分地区检查和药品可按规定结算）

## 手术当天与术后

- [ ] 按约到院，术前再验光核对
- [ ] 术后短暂畏光流泪属常见反应，按医嘱滴药、戴防护眼罩
- [ ] 拿到用药清单和复查时间表再离开；用药按医嘱逐渐减停，别自行停药
- [ ] 复查节点：1 天 / 1 周 / 1 个月 / 3 个月 / 6 个月 / 12 个月
- [ ] 3 天脏水不入眼，1 周少看屏幕，1 个月不揉眼、不剧烈运动、不游泳
- [ ] 眼红、疼痛、视力骤降：立即联系机构急诊复查
- [ ] 激光类多数人次日可正常用眼；术后仍要定期查眼底
