# F-14 第一次做牙齿矫正 · 清单

> 打印后勾选。依据见 [F-14 正文](../book/06-健康与医疗/F-14-第一次做牙齿矫正.md)。方案与拔牙决策以正畸医生评估为准。

## 初诊准备

- [ ] 写下想解决的问题清单（拥挤/前突/咬合/缝隙）
- [ ] 定预算区间和时间账（1.5–3 年，每 4–8 周复诊）
- [ ] 带既往牙片和病历
- [ ] 要问：方案与替代选项、拔牙与支抗钉、完整费用构成、医生资质

## 检查与定方案

- [ ] 拍全景片 + 头颅侧位片（必要时 CBCT）
- [ ] 有蛀牙、牙结石、牙周问题的先治疗
- [ ] 比较方案后签知情同意，确认总费用含复诊和保持器

## 矫治期护理

- [ ] 每次进食后清洁：正畸刷 + 牙线穿引器
- [ ] 加力后 2–3 天吃软食
- [ ] 托槽脱落 / 弓丝扎嘴：保护蜡应急，48 小时内联系机构
- [ ] 隐形牙套每天戴足 20–22 小时
- [ ] 复诊按节奏，不随意改期

## 保持期

- [ ] 拆除后按医嘱戴保持器（第一年最关键）
- [ ] 保持器丢失尽快重做，别裸奔
- [ ] 定期复查到医生确认稳定
