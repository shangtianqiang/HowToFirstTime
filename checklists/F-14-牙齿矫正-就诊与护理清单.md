# F-14 第一次做牙齿矫正 · 清单

> 打印后勾选。依据见 [F-14 正文](../book/06-健康与医疗/F-14-第一次做牙齿矫正.md)。方案与拔牙决策以正畸医生评估为准。

## 初诊准备

- [ ] 写下想解决的问题（拥挤/前突/咬合/缝隙），初诊时逐条问
- [ ] 定预算上限：金属约 6000–15000 元、陶瓷约 12000–20000 元、隐形约 20000–50000 元、舌侧约 40000–80000 元
- [ ] 算时间账：矫正期 1.5–3 年，每 4–8 周复诊，想好工作日请假方不方便
- [ ] 成年人有预期：骨骼已定型，重度骨性问题可能要正畸-正颌联合方案
- [ ] 带既往牙片和病历（有拔牙、补牙史的）

## 初诊要问

- [ ] 问：我的问题属于哪种类型？方案是什么？要不要拔牙、打支抗钉？
- [ ] 问：总费用含不含复诊、保持器、中途换配件？分期怎么收？
- [ ] 问：主诊医生的正畸培训和病例量，中途换医生怎么办？
- [ ] 问：方案有什么替代选项，各自利弊？
- [ ] 警惕低价引流后分阶段加价，签约前拿到含应急处理的完整报价

## 检查与定方案

- [ ] 拍全景片 + 头颅侧位片（必要时 CBCT），没拍片就出方案的直接换一家
- [ ] 取牙模或口内扫描
- [ ] 蛀牙、牙结石先治疗洁治；牙周炎先控制稳定再上牙套
- [ ] 比较方案后签知情同意，确认总费用含复诊和保持器
- [ ] 模拟效果只是预期，不是承诺
- [ ] 不用网红「牙齿矫正器」自助矫治，无监控自行加力可能牙根吸收

## 矫治期护理

- [ ] 每次进食后清洁：正畸刷或间隙刷 + 牙线穿引器，冲牙器辅助不能替代
- [ ] 加力后 2–3 天牙齿酸胀，吃软食过渡
- [ ] 金属/陶瓷每 4–8 周复诊加力，隐形每 6–10 周复诊，不随意改期
- [ ] 隐形牙套每天戴足 20–22 小时，戴不够效果打折

## 出问题找谁

- [ ] 托槽脱落、弓丝扎嘴：保护蜡覆盖，48 小时内联系机构，别自己剪弓丝
- [ ] 矫到一半换城市：带走完整病历和牙模资料，结清费用再转诊
- [ ] 关节弹响疼痛：告知主诊医生，可能调整方案或会诊
- [ ] 怀孕：告知医生，非急诊的 X 光片避开
- [ ] 发现牙根吸收：与医生评估程度，轻则调整重则终止

## 保持期

- [ ] 拆除后按医嘱戴保持器：第一年最关键，别凭感觉停
- [ ] 保持器至少戴 1–2 年，之后夜间维持，越久越稳
- [ ] 保持器丢失、折断：尽快重做，间隔越久移位越多
- [ ] 轻度复发重新戴保持器；明显复发找医生查原因（智齿、不良习惯、依从性）
