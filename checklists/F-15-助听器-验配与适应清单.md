# F-15 第一次配助听器 · 清单

> 打印后勾选。依据见 [F-15 正文](../book/06-健康与医疗/F-15-第一次配助听器.md)。方案以验配师评估为准。

## 就诊前

- [ ] 记下「什么场合听不清」清单（陪同代述更准）
- [ ] 带身份证、既往病历、用药记录
- [ ] 突发骤降/耳痛流液：先看病，不是配机器

## 检查与选配

- [ ] 医院耳鼻喉科：排除疾病，出听力报告
- [ ] 验配中心：按听力图选型（耳背/受话器外置/耳内定制）
- [ ] 安静+嘈杂环境都试听
- [ ] 问清：保修年限、免费调试次数、退换规则
- [ ] 验配报告留底

## 取机与适应（2–8 周）

- [ ] 学会开关机、换电池、清洁、干燥盒
- [ ] 第 1 周每天 1–2 小时安静环境
- [ ] 逐步延长到全天、嘈杂场合
- [ ] 不舒服、听不清随时回店免费复调
- [ ] 洗澡睡觉不戴，防潮防震

## 补贴申请（可选）

- [ ] 听力残疾评定 → 办残疾人证
- [ ] 向户籍地县级残联申请辅具适配补贴
- [ ] 问清当地目录、限额、儿童专项

## 每年

- [ ] 复查听力，机器复调
- [ ] 到店保养（多数免费）
