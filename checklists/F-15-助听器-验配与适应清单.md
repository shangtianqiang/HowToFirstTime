# F-15 第一次配助听器 · 清单

> 打印后勾选。依据见 [F-15 正文](../book/06-健康与医疗/F-15-第一次配助听器.md)。方案以验配师评估为准。

## 先判断该不该配

- [ ] 对照信号：电视越开越大声、人多嘈杂就听不清、常要求别人重复
- [ ] 先去医院查听力：可能是耵聍堵塞、中耳炎等可逆原因
- [ ] 突发一侧听力骤降：72 小时内挂耳鼻喉科急诊，不是配机器的事
- [ ] 耳痛流液：先治中耳炎等疾病，炎症控制后再评估选配

## 就诊前准备

- [ ] 把「什么场合听不清」写成清单，陪同代述更准
- [ ] 带身份证、既往病历、用药记录（部分药物影响听力）
- [ ] 糖尿病、高血压控制好病情再测，结果更准
- [ ] 想好预算：单只还是双耳；入门约 1000–3000 元、进阶 3000–6000 元、高端数万元（单只）

## 检查与选配

- [ ] 第一步医院耳鼻喉科：排除疾病，出听力报告
- [ ] 第二步验配中心：认准有资质验配师和售后网点，按听力图选型（耳背/受话器外置/耳内定制）
- [ ] 安静和嘈杂环境都试听；双耳都有听损的一般建议双耳配
- [ ] 问清：保修年限、免费调试次数、电池或充电方案、退换规则
- [ ] 同一品牌多店比价：机器同价，调试服务和保修年限可谈
- [ ] 定制式需取耳模，等待数天到两周；验配报告留底

## 取机与适应

- [ ] 学会开关机、换电池、清洁、干燥盒
- [ ] 第 1 周每天 1–2 小时，安静环境一对一交流
- [ ] 第 2–3 周延长到半天，再过渡到全天和嘈杂场合
- [ ] 听不清、吵得难受随时回店免费复调，一般 1 个月内要调多次
- [ ] 洗澡睡觉不戴，摘下就放干燥盒，防潮防震

## 补贴申请（可选）

- [ ] 先做听力残疾评定，办残疾人证
- [ ] 向户籍地县级残联申请辅具适配补贴
- [ ] 问清当地目录、限额和儿童专项，儿童补贴力度普遍更大
- [ ] 带上户口本和残疾人证去问最准

## 长期使用

- [ ] 每年复查听力，机器参数同步复调
- [ ] 定期到店保养，多数免费；助听器寿命一般 5–8 年
- [ ] 机器进水或摔了：断电取出电池，自然晾干后送修，别用吹风机猛吹
- [ ] 戴上就啸叫不止：检查是否戴到位、耳模是否密合，回店调整
