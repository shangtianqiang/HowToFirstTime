# G-01 第一次办银行卡 · 清单

> 打印后勾选。依据见 [G-01 正文](../book/07-钱与消费/G-01-第一次办银行卡.md)。

## 出发前

- [ ] 选好银行和网点：看距离、App 好不好用、手续费；工资卡按单位要求
- [ ] 带身份证原件和本人实名手机
- [ ] 部分网点要工作或居住证明，先电话确认
- [ ] 准备少量现金存入激活
- [ ] 学生可办学生卡，问清优惠；不轻信「代办高额度卡」的中介

## 了解账户

- [ ] 一类户全功能，同一银行只能开一个一类户
- [ ] 二类、三类户有交易限额，适合日常小额
- [ ] 年费 10 元/年、小额账户管理费 3 元/季度，都可申请减免，每行限一个账户
- [ ] 存款保险：同一家银行的本息 50 万元以内全额保障

## 开户

- [ ] 取号，填开户申请书
- [ ] 刷身份证、人脸识别，如实回答开户用途（反洗钱和反诈要求）
- [ ] 设 6 位密码，不告诉任何人
- [ ] 按需开通短信提醒，不开不必要的免密支付
- [ ] 存入少量现金激活账户
- [ ] 下载银行 App 登录查看余额，不点陌生链接下载
- [ ] 记下卡号、开户行和客服电话

## 开户后

- [ ] 卡和身份证分开放
- [ ] 不出租、出借、出售银行卡，可能构成帮信罪
- [ ] 长期不用的睡眠卡：销户或保留少量余额，清理前确认没绑定业务
- [ ] 被要求说明资金来源：如实说明，配合反洗钱调查

## 出问题找谁

- [ ] 卡丢失：先打客服电话挂失，再到网点补办
- [ ] 被盗刷：挂失、报警、保留交易记录，向银行申诉
- [ ] 账户冻结：问清冻结机关，联系银行和办案单位
- [ ] 被冒名开户：向银行申请撤销，报警
- [ ] 遭遇电信诈骗：拨 110 或 96110，申请止付
