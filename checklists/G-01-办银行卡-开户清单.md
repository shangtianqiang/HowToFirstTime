# G-01 第一次办银行卡 · 清单

> 打印后勾选。依据见 [G-01 正文](../book/07-钱与消费/G-01-第一次办银行卡.md)。

## 出发前

- [ ] 选好银行和网点
- [ ] 带身份证原件
- [ ] 带本人实名手机
- [ ] 准备少量现金
- [ ] 确认是否需要工作或居住证明

## 开户

- [ ] 取号填表
- [ ] 身份核验
- [ ] 说明开户用途
- [ ] 设置 6 位密码
- [ ] 开通短信提醒
- [ ] 存入少量现金激活
- [ ] 下载银行 App

## 开户后

- [ ] 记下卡号和客服电话
- [ ] 卡和身份证分开放
- [ ] 关闭不必要的免密支付
- [ ] 不把卡借给他人
- [ ] 不出租出售银行卡

## 出问题找谁

- [ ] 卡丢失：电话挂失，网点补办
- [ ] 被盗刷：挂失、报警、申诉
- [ ] 账户冻结：问清冻结机关
- [ ] 被冒名开户：申请撤销并报警
