# G-02 第一次租房 · 清单

> 打印后勾选。依据见 [G-02 正文](../book/07-钱与消费/G-02-第一次租房.md)。

## 找房

- [ ] 查中介或租赁企业是否备案
- [ ] 核验房东身份证和不动产权证
- [ ] 转租要看原出租人书面同意
- [ ] 看房拍照，检查漏水、霉斑、门锁、水电燃气
- [ ] 问清物业、取暖、网费谁承担

## 签约

- [ ] 合同写清双方身份、房屋地址和设施
- [ ] 写清租金、押金、支付周期和返还时间
- [ ] 写清押金扣减情形
- [ ] 写清维修责任和费用承担
- [ ] 写清违约、解除和争议解决

## 交接

- [ ] 抄水电燃气表读数并拍照
- [ ] 列家具家电清单，注明损坏情况
- [ ] 拍房屋现状视频
- [ ] 拿钥匙、门禁卡、燃气卡、电卡

## 入住后

- [ ] 督促出租人 30 日内备案，备案免费
- [ ] 保存合同、押金收据、转账记录
- [ ] 报修用书面或聊天记录
- [ ] 续租或退租提前按合同通知

## 出问题找谁

- [ ] 押金不退：12345/住建投诉，或调解、仲裁、诉讼
- [ ] 暴力驱赶：拨 110
- [ ] 甲醛超标：委托有资质机构检测并投诉
- [ ] 中介乱收费：拨 12315
