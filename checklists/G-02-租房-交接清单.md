# G-02 第一次租房 · 清单

> 打印后勾选。依据见 [G-02 正文](../book/07-钱与消费/G-02-第一次租房.md)。

## 找房与核验

- [ ] 优先选已备案的经纪机构、住房租赁企业或官方租赁平台，门店看备案信息、收费标准、实名工作牌
- [ ] 网络平台找房，先核验发布者身份和房源真实性
- [ ] 核验出租人身份证和不动产权证；房东本人不到场，要有授权委托书
- [ ] 核对合同签约人和产权人一致；转租要看原出租人书面同意
- [ ] 房东不肯出示产权证明，直接放弃
- [ ] 群租隔断房不租：厨房、卫生间、阳台、过道、地下储藏室、车库不得单独住人
- [ ] 不先交「看房费」「意向金」再看房

## 看房

- [ ] 白天去看，最好有人陪同
- [ ] 看采光、通风、漏水、霉斑、隔音、门锁、水电燃气
- [ ] 房产证地址和房源地址一致，问清合租人数和公共区域
- [ ] 问清物业、取暖、网费谁承担；问能不能做饭、养宠物、转租
- [ ] 设施清单拍照留存

## 签约

- [ ] 逐条读合同，填好空白处，不同意的条款当场改
- [ ] 写清双方身份、房屋地址面积和设施清单
- [ ] 写清租金、押金、支付周期、返还时间和扣减情形
- [ ] 写清维修责任、费用承担、违约、解除和争议解决
- [ ] 口头承诺全部写进合同
- [ ] 双方签字后拿一份合同原件；不给原件就拍照留存，谨慎签

## 押金与付款

- [ ] 没有统一押金上限，也没有「押一付三」的法律规定，按合同约定
- [ ] 部分城市对租赁企业有监管：押金一般不超过 1 个月、单次收租不超过 3 个月
- [ ] 租金走银行转账备注「房租」，不转给个人中介或平台代收
- [ ] 没有合同约定的情形，出租人无正当理由不得扣押金

## 交接与入住

- [ ] 抄水电燃气表读数并拍照
- [ ] 清点家具家电列清单，注明损坏情况；拍房屋现状视频，重点拍墙面、地板、门窗、厨卫
- [ ] 拿钥匙、门禁卡、燃气卡、电卡，确认物业、宽带、供暖过户或新开
- [ ] 督促出租人 30 日内办租赁备案，备案免费；出租人不办，承租人可以自己办
- [ ] 保存合同、押金收据、转账记录、交接清单；报修用书面或聊天记录

## 出问题找谁

- [ ] 押金不退：先协商，再向 12345 或住建部门投诉，或调解、仲裁、诉讼
- [ ] 暴力驱赶、断水断电赶人：拨 110，保留证据，向住建部门投诉
- [ ] 甲醛超标：委托有资质机构检测留报告，要求整改或解约并投诉
- [ ] 中介乱收费：拨 12315，保留收据和聊天记录
- [ ] 房东不维修：书面催告，可自行维修，费用由出租人承担
