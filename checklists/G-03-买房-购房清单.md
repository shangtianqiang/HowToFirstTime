# G-03 第一次买房/办房贷 · 清单

> 打印后勾选。依据见 [G-03 正文](../book/07-钱与消费/G-03-第一次买房办房贷.md)。

## 资格与预算

- [ ] 查当地限购政策
- [ ] 确认首付比例
- [ ] 查贷款利率
- [ ] 算契税、维修基金
- [ ] 留 12 个月月供备用

## 看房

- [ ] 五证公示
- [ ] 预售许可证对应楼栋
- [ ] 开发商资质
- [ ] 交付时间
- [ ] 物业费和车位
- [ ] 周边不利因素

## 签约

- [ ] 看清认购书定金条款
- [ ] 商品房买卖合同
- [ ] 面积、单价、总价
- [ ] 交付标准
- [ ] 违约条款
- [ ] 网签备案

## 付款与贷款

- [ ] 首付进监管账户
- [ ] 保留首付发票
- [ ] 收入证明
- [ ] 银行流水
- [ ] 征信报告
- [ ] 面签
- [ ] 贷款合同留存

## 交房

- [ ] 两书一表
- [ ] 面积实测报告
- [ ] 验房
- [ ] 记录质量问题
- [ ] 签字收房
- [ ] 缴契税和维修基金
- [ ] 办不动产权证

## 出问题找谁

- [ ] 停工：住建部门、保交楼
- [ ] 贷款被拒：换银行或增加首付
- [ ] 延期交房：书面催告、违约金
- [ ] 质量问题：住建部门投诉
