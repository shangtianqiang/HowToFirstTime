# G-03 第一次买房/办房贷 · 清单

> 打印后勾选。依据见 [G-03 正文](../book/07-钱与消费/G-03-第一次买房办房贷.md)。

## 资格与预算

- [ ] 查当地限购、限贷政策：户籍、社保、个税年限、家庭套数
- [ ] 查首付比例和贷款利率：首套通常 20%–30%，二套更高，各城市不同
- [ ] 算总成本：首付、契税（1%–3%）、维修基金、装修、月供、物业费
- [ ] 月供不超过家庭月收入 50%，保守一点 30%–40%
- [ ] 留 12 个月月供备用，不把全部积蓄付首付
- [ ] 不用首付贷、经营贷买房——违规，银行可提前收贷

## 查楼盘

- [ ] 五证公示：土地、用地规划、工程规划、施工许可、预售许可，五证不全不买
- [ ] 预售许可证对应你要买的楼栋
- [ ] 开发商资质和过往项目
- [ ] 交付时间、物业费和车位
- [ ] 周边规划和不利因素；「学区房」以教育局公布为准

## 认购与签约

- [ ] 认购书看清「定金」还是「订金」：定金通常不退，订金可退
- [ ] 看认购书的签约期限和违约条款
- [ ] 商品房买卖合同逐条看：面积、单价、总价、交付日期、违约条款
- [ ] 合同附件也要看：装修标准、交付条件写清楚
- [ ] 网签备案完成，认购书和定金收据留好

## 付款与贷款

- [ ] 首付打进预售资金监管账户，不是开发商个人账户
- [ ] 保留首付发票
- [ ] 备齐贷款材料：身份证户口簿、婚姻证明、收入证明、6–12 个月银行流水、征信报告、首付款凭证
- [ ] 公积金贷款问清缴存基数、账户余额和当地上限
- [ ] 按时面签，看清贷款额度、利率、期限、还款方式
- [ ] 贷款合同留存

## 交房与办证

- [ ] 两书一表齐全再收房：先验房，后签字
- [ ] 核对面积实测报告；面积误差超过 3% 可按合同要求退房
- [ ] 验房查墙面、地面、水电、门窗、防水，质量问题拍照记录、要求整改、向住建部门投诉
- [ ] 缴契税和维修基金，办不动产权证
- [ ] 票据全留存：首付发票、贷款合同、契税票、维修基金票据

## 出问题找谁

- [ ] 楼盘停工：联合业主向住建部门反映，关注保交楼政策
- [ ] 贷款被拒：问清原因，换银行或增加首付，注意认购书违约条款
- [ ] 延期交房：书面催告，按合同主张违约金
- [ ] 断供风险：提前和银行沟通，避免征信受损
