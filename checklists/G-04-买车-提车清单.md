# G-04 第一次买车 · 清单

> 打印后勾选。依据见 [G-04 正文](../book/07-钱与消费/G-04-第一次买车.md)。

## 买车前算总账

- [ ] 算落地价：裸车价 + 购置税 + 保险 + 上牌费 + 装饰，不只看裸车价
- [ ] 保险首年通常 4000–8000 元，上牌几百元
- [ ] 燃油车购置税按不含税价 10% 估算，大约裸车价除以 11.3；新能源按现行减免政策
- [ ] 贷款算清利息和手续费的总成本，不只看月供
- [ ] 确认充电条件：没有固定车位充电，纯电要谨慎
- [ ] 对比保值率、保养成本、保险费用，试驾并坐满家人试空间

## 签约

- [ ] 合同写清车型、配置、颜色、车架号，防止减配
- [ ] 写明交车日期，不接受无限期等待
- [ ] 赠品、保险、上牌服务费逐项写进合同
- [ ] 分清定金和订金：定金通常不退，订金可退
- [ ] 低配加装冒充高配：逐项核对配置表
- [ ] 保留付款凭证，付款后拿到发票

## 提车验车

- [ ] 核对车架号、发动机号和合同一致
- [ ] 看生产日期，避免库存车当新车
- [ ] 看里程，通常 50 公里内
- [ ] 检查漆面、轮胎、玻璃、内饰
- [ ] 清点随车工具
- [ ] 手续收齐四样：合格证、发票、三包凭证、保养手册
- [ ] 验车无误再签交车单

## 保险与上牌

- [ ] 交强险必买
- [ ] 三者险建议 200 万元以上
- [ ] 按用车环境加车损险、座位险、医保外用药责任险
- [ ] 缴车辆购置税，保留完税证明
- [ ] 备齐身份证、购车发票、合格证、交强险保单、购置税完税证明，部分城市要居住证
- [ ] 到车管所验车、选号、上牌，拿行驶证和号牌

## 出问题找谁

- [ ] 提车发现质量问题：拒绝签字，要求换车或书面承诺修复
- [ ] 合格证被抵押：要求经销商限期赎回，向厂家和市场监管投诉
- [ ] 车辆故障：按三包规定维修、换车或退车
- [ ] 被强制消费：保留证据，拨 12315 投诉
- [ ] 上牌被拒：核对材料，问清原因，补办
