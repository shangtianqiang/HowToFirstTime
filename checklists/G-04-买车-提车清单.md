## 签约

- [ ] 车型、配置、颜色
- [ ] 车架号

- [ ] 赠品清单
- [ ] 违约条款

## 提车

- [ ] 核对车架号、发动机号
- [ ] 看生产日期
- [ ] 看里程
- [ ] 检查漆面
- [ ] 检查轮胎和玻璃
- [ ] 随车工具
- [ ] 合格证

- [ ] 三包凭证
- [ ] 保养手册

## 保险与上牌

- [ ] 交强险
- [ ] 三者险 200 万元以上
- [ ] 车损险
- [ ] 座位险
- [ ] 缴购置税
- [ ] 验车选号
- [ ] 行驶证和号牌

## 出问题找谁

- [ ] 质量问题：拒绝签字，要求换车
- [ ] 合格证被抵押：厂家、市场监管
- [ ] 三包故障：按三包规定
- [ ] 强制消费：12315
