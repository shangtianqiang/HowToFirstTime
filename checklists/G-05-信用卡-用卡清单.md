# G-05 第一次用信用卡 · 清单

> 打印后勾选。依据见 [G-05 正文](../book/07-钱与消费/G-05-第一次用信用卡.md)。

## 申请办卡

- [ ] 年满 18 周岁、有稳定收入、征信良好再申请
- [ ] 备好身份证、收入证明、社保或公积金记录
- [ ] 选卡看年费、权益、返现、积分，不只看额度，问清刷满几次免年费
- [ ] 不通过中介办卡，不交"包装费"
- [ ] 不频繁申请多张卡，查询记录过多影响征信

## 拿到卡后

- [ ] 激活并设置密码，绑定官方 App
- [ ] 开通交易提醒
- [ ] 记下账单日和还款日，还款日通常在账单日后 20 天左右
- [ ] 设置自动还款，防止忘记还款
- [ ] 通读领用合约再开卡
- [ ] 弄懂免息期：最长约 50–56 天，账单日次日消费最长

## 日常用卡

- [ ] 不把卡和密码交给他人，盗刷和法律责任都算自己的
- [ ] 不套现，违反领用合约，可能封卡
- [ ] 不点陌生提额链接，是钓鱼诈骗
- [ ] 每月账单日出账后核对消费明细，有疑问联系银行申请调单
- [ ] 到期还款日前全额还款，免利息
- [ ] 不长期最低还款：未还部分按日息约万分之五计息，按月计复利

## 分期与销卡

- [ ] 分期手续费折算年化可能超过 10%，办前算清
- [ ] 分期看清提前还款规则，提前还可能仍收手续费
- [ ] 取现没有免息期，从当天计息还有手续费，不建议
- [ ] 销卡先还清欠款、处理积分，销卡后剪断磁条和芯片

## 出问题找谁

- [ ] 盗刷：立即挂失冻结、报警，保留交易记录，向银行申请拒付
- [ ] 还款失败：确认到账，必要时手动还款并保留凭证
- [ ] 年费争议：核对免年费条件，向银行申诉
- [ ] 催收骚扰：保留录音，拨 12378 向金融监管投诉
- [ ] 征信错误：向银行和征信中心提出异议；逾期污点保留 5 年
