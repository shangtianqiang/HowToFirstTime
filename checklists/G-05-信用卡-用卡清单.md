# G-05 第一次用信用卡 · 清单

> 打印后勾选。依据见 [G-05 正文](../book/07-钱与消费/G-05-第一次用信用卡.md)。

## 申请

- [ ] 确认收入和征信
- [ ] 选年费可免的卡
- [ ] 看权益和返现
- [ ] 不通过中介办卡
- [ ] 不交包装费

## 激活

- [ ] 设置密码
- [ ] 绑定官方 App
- [ ] 开通交易提醒
- [ ] 记下账单日和还款日
- [ ] 设置自动还款
- [ ] 读领用合约

## 用卡

- [ ] 不借卡给他人
- [ ] 不套现
- [ ] 不点陌生提额链接
- [ ] 每月核对账单
- [ ] 全额还款
- [ ] 不长期最低还款

## 安全

- [ ] 遮挡密码
- [ ] 不在公共 Wi-Fi 操作
- [ ] 保留交易记录
- [ ] 查征信每年一次

## 出问题找谁

- [ ] 盗刷：挂失、报警、拒付
- [ ] 还款失败：手动还款，留凭证
- [ ] 年费争议：银行申诉
- [ ] 催收骚扰：12378 投诉
