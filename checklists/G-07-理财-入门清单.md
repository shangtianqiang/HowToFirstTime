# G-07 第一次理财 · 清单

> 打印后勾选。依据见 [G-07 正文](../book/07-钱与消费/G-07-第一次理财.md)。

## 开始前

- [ ] 列清收入、支出、负债、保险
- [ ] 留够 3–6 个月生活费作应急金，放活期或货币基金
- [ ] 先还清信用卡、消费贷等高息负债
- [ ] 定投资目标和期限：1 年、3 年还是 5 年以上
- [ ] 在银行或基金平台做风险测评，如实填写

## 选渠道

- [ ] 只用银行 App、持牌基金销售平台、证券公司、国债承销银行
- [ ] 确认平台有金融牌照再开户
- [ ] 不用来路不明的 App、微信群、直播间链接
- [ ] 不把钱转到个人账户，一定是骗局

## 选产品

- [ ] 存款打底，受存款保险保障：同一银行 50 万元以内全额保障
- [ ] 国债由国家信用兜底，风险低
- [ ] 货币基金放应急金，流动性好、收益波动小
- [ ] 债券基金、股票基金按风险承受力配，第一次选 R1–R2
- [ ] 看清起购金额、期限、赎回规则、费用，不买看不懂的产品
- [ ] 银行理财不保本，看风险等级和投资范围

## 持有与复盘

- [ ] 每季度看一次，不天天盯盘
- [ ] 不追涨杀跌，不频繁交易，手续费会吃掉收益
- [ ] 定期再平衡，不把全部资金投一个产品、一个平台
- [ ] 不借钱投资，不用消费贷、信用卡套现进场
- [ ] 急用钱优先赎回流动性好的产品，避免高息借贷

## 出问题找谁

- [ ] 平台跑路：报警，保留转账和聊天记录，向金融监管投诉
- [ ] 被误导销售：保留宣传材料和合同，拨 12378 投诉
- [ ] 账户被盗：冻结账户、改密码、报警
- [ ] 遭遇诈骗：拨 110 或 96110，申请止付
- [ ] 记住保本高息、内部渠道、老师带单都是骗局
