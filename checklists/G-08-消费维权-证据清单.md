# G-08 第一次消费维权 · 清单

> 打印后勾选。依据见 [G-08 正文](../book/07-钱与消费/G-08-第一次消费维权.md)。

## 先留证据

- [ ] 订单截图，含商品页和订单号
- [ ] 支付记录、发票或收据
- [ ] 商品问题拍照拍视频，保留商品和包装
- [ ] 聊天记录、快递单号和物流记录
- [ ] 通话录音合法取得
- [ ] 没有发票也能维权：订单、支付记录、聊天记录都算证据

## 对齐规则和诉求

- [ ] 看平台退换货规则、商家质保承诺和保修卡、三包凭证
- [ ] 确认商品是否属于定制、生鲜、数字化商品等无理由退货例外
- [ ] 网购自收到商品之日起七日内、商品完好，可无理由退货
- [ ] 想清楚诉求：退货、换货、修理、退款还是赔偿
- [ ] 不接受口头承诺，要书面或平台记录

## 协商与投诉

- [ ] 先联系商家：说明问题、提出诉求、发送证据
- [ ] 记录沟通时间和对方的方案或拒绝理由
- [ ] 商家不解决，走平台投诉入口，提交订单、证据、诉求
- [ ] 再上全国 12315 平台（网站、App、小程序或电话），记下受理编号，跟进进度
- [ ] 申请当地消协调解
- [ ] 不轻信"私了"转账，对方可能反悔

## 赔偿与诉讼

- [ ] 构成欺诈的退一赔三，赔偿不足 500 元的按 500 元
- [ ] 不符合食品安全标准的，可要求十倍价款赔偿，最低 1000 元
- [ ] 超过七天无理由退货失效，质量问题不受此限
- [ ] 金额大协商不成：整理证据、写起诉状向法院起诉，有仲裁协议的申请仲裁
- [ ] 疑似假货：保留商品和包装，申请鉴定再投诉

## 出问题找谁

- [ ] 商家失联：平台投诉、12315、报警
- [ ] 预付卡跑路：报警、12315、市场监管投诉，联合其他消费者维权
- [ ] 人身伤害：先就医保留病历和发票，再报警
- [ ] 被威胁：报警，保留录音和聊天记录
- [ ] 群体投诉：联合其他消费者，统一证据和诉求
