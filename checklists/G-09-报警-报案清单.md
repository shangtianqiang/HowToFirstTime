# G-09 第一次报警/报案 · 清单

> 打印后勾选。依据见 [G-09 正文](../book/07-钱与消费/G-09-第一次报警报案.md)。

## 报警前

- [ ] 先判断类型：刑事、治安案件找公安；债务、合同、消费纠纷走 12315、仲裁或法院
- [ ] 正在发生的危险，先离开现场再报警，不独自与嫌疑人对抗
- [ ] 记住对方体貌、车牌、逃跑方向
- [ ] 备好身份证、聊天转账记录、照片视频、证人联系方式和损失清单
- [ ] 走失立即报警，不需要等 24 小时

## 拨 110

- [ ] 说准确地址和事件经过
- [ ] 说清有几人、是否有人受伤
- [ ] 报姓名和电话，保持通话，听接警员提问
- [ ] 非紧急事项到派出所报案，或拨 12345 咨询
- [ ] 电信诈骗立即拨 110 或 96110，提供对方账号和转账记录，申请止付

## 派出所报案

- [ ] 到案发地或居住地派出所，说明情况，提交证据原件或复印件
- [ ] 民警制作询问笔录，逐字核对后签字
- [ ] 索取受案回执，后续查询和维权都要用
- [ ] 记下办案民警姓名和联系方式
- [ ] 如实陈述，不夸大不隐瞒，虚假报警违法
- [ ] 不删聊天记录，保留原始载体

## 跟进与救济

- [ ] 按回执上的查询方式跟进，关注立案或不立案通知
- [ ] 不立案可申请复议，不服再向上一级公安机关申请复核
- [ ] 或向检察院申请立案监督，拿到书面答复
- [ ] 配合调查中提供新证据，给原件或复印件

## 出问题找谁

- [ ] 对受理不满：拨 12389 投诉
- [ ] 人被带走超 24 小时没消息：到办案单位询问，索要拘留通知书
- [ ] 遭遇家暴：报警并要求出具告诫书，就医验伤
- [ ] 车辆被拖：拨 122 或查车管所，不要盲目找
