# G-11 第一次请律师 · 清单

> 打印后勾选。依据见 [G-11 正文](../book/07-钱与消费/G-11-第一次请律师.md)。

## 请之前

- [ ] 拨过 12348 免费咨询，判断要不要请律师
- [ ] 符合条件的先问了法律援助
- [ ] 写好案情时间线
- [ ] 想清楚预算上限和目标

## 材料准备

- [ ] 身份证
- [ ] 合同、协议、借条等原件和复印件
- [ ] 转账记录、发票、收据
- [ ] 聊天记录、录音等原始载体
- [ ] 问题清单，按重要程度排序

## 找律师

- [ ] 从律所官网、当地律协或 12348 找
- [ ] 律师执业证号在公示平台 credit.acla.org.cn 查得到
- [ ] 律所名称在公示平台查得到
- [ ] 约面谈时问清是否收费、带什么材料

## 面谈

- [ ] 按时间线讲案情，出示原件
- [ ] 听懂初步方案、可选路径和大致费用
- [ ] 问清收费方式：计件、按标的比例、计时，还是风险代理
- [ ] 风险代理先确认案件不在禁止范围内
- [ ] 风险代理比例不超过分档上限（100 万元以下部分不超过 18%）
- [ ] 问清另收费项目：诉讼费、保全费、鉴定费、公证费、查档费等

## 签合同

- [ ] 合同抬头和盖章都是律师事务所
- [ ] 委托事项和阶段写明（一审、二审、执行）
- [ ] 委托权限写明，特别授权逐项列出
- [ ] 收费项目、标准、方式、数额、付款结算、争议解决齐全
- [ ] 风险代理单独签专门合同，风险责任写明
- [ ] 拿到盖章合同原件

## 付款与留痕

- [ ] 对公转账给律所，备注案件名和费用性质
- [ ] 索取正规发票
- [ ] 原件移交列清单，双方签字，自留复印件
- [ ] 异地差旅费先看费用概算再签字
- [ ] 结算时索取代付费用清单和有效凭证
- [ ] 重要沟通用文字确认一遍

## 出问题找谁

- [ ] 收费争议：先与律所书面协商，再提请当地律协调解
- [ ] 违规执业：向当地司法行政机关或律协投诉
- [ ] 疑似假冒律师：向律协、司法局反映，涉嫌诈骗报警
- [ ] 交不起诉讼费：向法院申请缓交、减交、免交的司法救助
- [ ] 经济困难：拨 12348 申请法律援助
