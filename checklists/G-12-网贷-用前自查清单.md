# G-12 第一次用网贷/分期 · 清单

> 打印后勾选。依据见 [G-12 正文](../book/07-钱与消费/G-12-第一次用网贷与分期.md)。

## 借钱前

- [ ] 问过自己三个问题：非借不可吗？拿什么还？还不上怎么办？
- [ ] 先试过不借钱的路：缓一缓、动存款、找家人商量
- [ ] 列出每月收入、支出，确认扣掉还款还有结余
- [ ] 确认放贷机构是持牌机构，牌照在金监总局官网查得到
- [ ] 在校学生：确认放贷方不是小额贷款公司
- [ ] 只从官方应用商店下载 App，不点短信、弹窗里的借款链接
- [ ] 看到「无门槛」「秒批」「黑户可贷」，直接关掉

## 下单前

- [ ] 找到并截图「年化利率」，日息、月费率换算成年化再比较
- [ ] 分期手续费折算成年化利率，看清真实成本
- [ ] 看清每期还款额、总还款额、扣款日
- [ ] 看清提前还款有没有违约金
- [ ] 逐项取消默认勾选的会员、保障、权益包
- [ ] 核对合同里的放贷机构全称，与牌照信息一致
- [ ] 确认征信查询授权是自己勾选的
- [ ] 保存电子合同

## 还款中

- [ ] 设还款提醒，提前一天确认扣款卡里有余额
- [ ] 每期核对扣款是否成功
- [ ] 不借新还旧，不以贷养贷
- [ ] 结清后索要结清证明并留档

## 出问题找谁

- [ ] 还不上：第一时间联系放贷机构客服，问延期或分期安排
- [ ] 催收违规（深夜来电、骚扰家人）：录音截图留证据
- [ ] 持牌机构违规：拨 12378 投诉
- [ ] 网贷平台违规：到中国互联网金融举报信息平台举报
- [ ] 威胁恐吓、上门滋扰：报警 110
- [ ] 被冒名贷款：联系机构声明、报警、向征信中心提出异议
- [ ] 「注销校园贷」来电：是诈骗，挂断，不给验证码
