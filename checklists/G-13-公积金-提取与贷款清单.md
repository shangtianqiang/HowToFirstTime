# G-13 第一次提取公积金与办公积金贷款 · 清单

> 打印后勾选。依据见 [G-13 正文](../book/07-钱与消费/G-13-第一次提取公积金与办公积金贷款.md)。

## 先查账户

- [ ] 当地公积金 App/小程序查余额、月缴存额、缴存状态
- [ ] 确认连续缴存月数（贷款一般要满 6 个月）
- [ ] 计划贷款的：先做额度试算，别急着提取

## 租房提取

- [ ] 租赁合同（部分城市要备案或发票）
- [ ] App 选「租房提取」，看本年度剩余额度
- [ ] 提交后确认到账银行卡

## 购房提取（注意 1 年时限）

- [ ] 购房合同或不动产权证书
- [ ] 购房发票、契税凭证
- [ ] 在合同生效/拿证后 1 年内办理

## 公积金贷款

- [ ] 额度试算：余额 × 当地倍数，对比最高限额
- [ ] 材料：身份证、户口簿、购房合同、首付凭证、征信授权
- [ ] 额度不够：问组合贷，先和卖家确认接受
- [ ] 放款后保存还款计划表

## 换城市 / 离职

- [ ] 跨城：全国住房公积金小程序办转移接续
- [ ] 离职：确认封存期限和销户条件再动手
- [ ] 疑问拨 12329
