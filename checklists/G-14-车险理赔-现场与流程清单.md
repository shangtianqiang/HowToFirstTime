# G-14 第一次车险理赔 · 清单

> 打印后勾选。依据见 [G-14 正文](../book/07-钱与消费/G-14-第一次车险理赔.md)。

## 平时备好

- [ ] 保险单拍照存手机：报案电话、保单号、起止日期
- [ ] 行驶证、驾驶证放车内固定位置
- [ ] 交管 12123 登录过一次，确认「事故快处」可用
- [ ] 车内放《交通事故自行协商协议书》和三角警示牌

## 事故现场

- [ ] 有人伤：先打 120，再打 122，保护现场
- [ ] 车能动、人未伤：拍照（全景/碰撞部位/双方车牌/刹车痕）
- [ ] 责任无争议：挪车，走 12123 快处或当地快处快赔
- [ ] 责任有争议或对方酒驾：原地等交警
- [ ] 记下对方车牌、电话、保险公司

## 报案与定损

- [ ] 48 小时内打保险报案电话，记下报案号
- [ ] 配合查勘定损，确认定损单项目和金额
- [ ] 定损确认后再修车，先修后报容易拒赔

## 修车与赔付

- [ ] 修完拿发票、维修清单，旧件拍照留存
- [ ] 直赔或垫付报销，确认到账后结案

## 出问题找谁

- [ ] 保险公司拒赔争议：12378
- [ ] 对方全责不赔：凭认定书起诉对方及其保险公司
- [ ] 认定书不服：3 日内申请复核
