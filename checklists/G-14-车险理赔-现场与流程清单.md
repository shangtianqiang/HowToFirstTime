# G-14 第一次车险理赔 · 清单

> 打印后勾选。依据见 [G-14 正文](../book/07-钱与消费/G-14-第一次车险理赔.md)。

## 平时备好

- [ ] 保险单拍照存手机：报案电话、保单号、保险起止日期
- [ ] 行驶证、驾驶证放车内固定位置
- [ ] 装好交管 12123，提前登录一次「事故快处」
- [ ] 车内放《交通事故自行协商协议书》，保险公司和交警队可领
- [ ] 三角警示牌放在能快速取到的位置

## 事故现场

- [ ] 有人伤：开双闪、放警示标志，先打 120 救人，再打 122 报警，不挪现场
- [ ] 车能动人未伤：按四要素拍照——全景（含道路标线）、碰撞部位、双方车牌、刹车痕迹
- [ ] 拍完照再把车挪到不妨碍交通的地方，先拍后挪
- [ ] 责任无争议：走 12123 事故快处或当地快处快赔
- [ ] 责任有争议、有人伤或对方涉酒驾：原地等交警，不私了
- [ ] 记下对方车牌、电话、保险公司和交警姓名联系方式
- [ ] 高速上：人撤到护栏外，车后 150 米放三角牌，报警报百米桩位置

## 报案与定损

- [ ] 48 小时内打保险公司报案电话，单方事故也要报
- [ ] 报保单号、时间地点、经过和损失，有无人伤说清楚
- [ ] 记下报案号，查进度、催赔付全靠它
- [ ] 配合查勘定损，自己拍的现场照片一并提供
- [ ] 核对定损单项目和金额与修理厂报价一致，签字确认后再修车

## 修车与赔付

- [ ] 在定损范围内选修理厂，选 4S 店先问是否补差价
- [ ] 报案前翻保单，确认玻璃、划痕等附加险有没有投保
- [ ] 修完拿发票和维修清单，旧件拍照留存，处理前问是否回收
- [ ] 垫付的医药费留好票据，凭认定书和票据走保险结算
- [ ] 确认直赔或垫付报销，理赔款到账再结案

## 出问题找谁

- [ ] 保险公司拒赔：要书面拒赔通知和条款依据，协商不成打 12378 或起诉
- [ ] 对方全责不赔：凭认定书直接向其保险公司交涉，不成起诉对方和保险公司
- [ ] 认定书不服：收到之日起 3 日内向上一级公安交管部门申请复核
- [ ] 对方逃逸：立即报警，记车牌车型颜色，行车记录仪画面留好
- [ ] 异地出险：拨保单上的全国报案电话，大事故可要求回承保地维修
- [ ] 口头不认全责：责任划分是交警的职权，现场别随口认
- [ ] 小几百元的损失：先算无赔款优待账，报案可能比自掏腰包更贵
