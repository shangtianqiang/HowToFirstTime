# H-01 第一次独居 · 清单

> 打印后勾选。依据见 [H-01 正文](../book/08-居住与生活/H-01-第一次独居.md)。

## 入住

- [ ] 拍照记录房屋现状
- [ ] 记录电表水表读数
- [ ] 换锁芯或改密码
- [ ] 检查猫眼、门链、窗锁
- [ ] 检查燃气、电路
- [ ] 确认消防通道

## 开通

- [ ] 电户号和缴费方式
- [ ] 水户号和缴费方式
- [ ] 燃气开户或过户
- [ ] 宽带预约
- [ ] 垃圾投放时间
- [ ] 存物业和房东电话

## 安全

- [ ] 灭火器或灭火毯
- [ ] 急救包
- [ ] 手电筒
- [ ] 备用钥匙放信任的人处
- [ ] 紧急联系人
- [ ] 手机存 110、119、120

## 习惯

- [ ] 出门反锁
- [ ] 睡前检查门窗燃气
- [ ] 不透露独居
- [ ] 外卖快递放门口
- [ ] 不轻易开门
- [ ] 定期联系家人

## 出问题找谁

- [ ] 燃气泄漏：关阀、开窗、室外打电话
- [ ] 火灾：撤离、拨 119
- [ ] 入室盗窃：拨 110，不正面冲突
- [ ] 漏水：关总阀，联系楼上和物业
