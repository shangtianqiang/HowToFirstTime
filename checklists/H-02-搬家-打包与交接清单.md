# H-02 第一次搬家 · 清单

> 打印后勾选。依据见 [H-02 正文](../book/08-居住与生活/H-02-第一次搬家.md)。

## 提前两周

- [ ] 提前 1–2 周断舍离，不用的捐、卖、扔
- [ ] 量电梯和门宽，确认大件家具能进
- [ ] 问物业：搬家时间、电梯保护、放行条
- [ ] 比价 3 家搬家公司，看营业执照和口碑，不找楼道小广告
- [ ] 备纸箱、气泡膜、胶带、记号笔

## 打包

- [ ] 按房间装箱，箱外写编号和内容
- [ ] 易碎品单独装，箱外标「易碎」
- [ ] 液体拧紧套袋
- [ ] 证件、首饰、电脑随身带，不放货车
- [ ] 拆装家具拍照，记好螺丝位置

## 签合同

- [ ] 合同写清车型、人数、楼层、距离、费用
- [ ] 拆装、打包、空调移机是否另收费写进合同
- [ ] 写清损坏、丢失赔偿条款
- [ ] 不签空白合同，不付全款
- [ ] 跨城搬家问清计费方式，是否含装卸

## 搬家当天

- [ ] 与司机核对物品清单，拍照记录装车前状态
- [ ] 贵重物品自己拿，跟车或约好到达时间
- [ ] 记下车牌和司机电话
- [ ] 卸货按编号逐件核对，重点查家具、电器、易碎品
- [ ] 损坏当场拍照写进验收单，再签字
- [ ] 按合同结算，索要发票或收据

## 入住与收尾

- [ ] 旧居水电燃气结清费用，办销户或过户，燃气过户要预约
- [ ] 新居先装床、灶、网络，清洁后再摆物品
- [ ] 快递外卖改默认地址，通知常用平台和驿站
- [ ] 银行、社保、公积金、车牌、驾驶证、居住证变更地址
- [ ] 孩子学校、医保定点同步更新

## 出问题找谁

- [ ] 搬家公司迟到：电话确认，保留沟通记录
- [ ] 现场加价：按合同拒绝，必要时报警或投诉
- [ ] 物品损坏：凭验收单和合同索赔，向市场监管投诉
- [ ] 电梯故障：改走楼梯或改期，费用协商
- [ ] 途中事故：报警，联系搬家公司，保留证据
- [ ] 新居不能入住：先住酒店留凭证，向房东或中介追责
