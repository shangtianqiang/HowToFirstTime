# H-03 第一次装修 · 清单

> 打印后勾选。依据见 [H-03 正文](../book/08-居住与生活/H-03-第一次装修.md)。

## 开工前

- [ ] 定预算，留 10%–20% 备用
- [ ] 比 3 家方案
- [ ] 查装修公司资质
- [ ] 看在建工地
- [ ] 合同写增项规则
- [ ] 报物业、交保证金
- [ ] 办出入证

## 拆改

- [ ] 确认承重墙位置
- [ ] 不拆承重结构
- [ ] 关闭水电总阀
- [ ] 垃圾袋装清运

## 水电

- [ ] 弹线开槽
- [ ] 分路布线
- [ ] 水管打压
- [ ] 拍照记录走向
- [ ] 保留图纸

## 防水

- [ ] 卫生间、厨房、阳台防水
- [ ] 墙面高度按规范
- [ ] 闭水 24–48 小时
- [ ] 到楼下检查
- [ ] 签字验收

## 竣工

- [ ] 逐项验收
- [ ] 整改清单
- [ ] 通水通电通气
- [ ] 水电图
- [ ] 保修卡
- [ ] 发票
- [ ] 留 5%–10% 尾款

## 入住前

- [ ] 通风 3–6 个月
- [ ] CMA 机构检测甲醛
- [ ] 达标再住
- [ ] 保留检测报告

## 出问题找谁

- [ ] 公司跑路：报警、市场监管
- [ ] 漏水：关水、拍照、协商
- [ ] 甲醛超标：通风、治理、复检
- [ ] 合同纠纷：投诉或起诉
