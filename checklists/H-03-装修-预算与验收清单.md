# H-03 第一次装修 · 清单

> 打印后勾选。依据见 [H-03 正文](../book/08-居住与生活/H-03-第一次装修.md)。

## 定预算选公司

- [ ] 预算分硬装、主材、家具家电，留 10%–20% 备用
- [ ] 比 3 家方案，确认报价含拆改、水电、防水、油漆、安装
- [ ] 看营业执照和装修资质，看在建工地不只样板间
- [ ] 问清是否转包、工人是否自有，合同主体与收款账户一致
- [ ] 硬装行情约 800–2000 元/平方米，按城市调整

## 签合同报物业

- [ ] 优先闭口合同，或写明增项上限
- [ ] 增项须书面确认，单价和工程量提前约定，不口头同意
- [ ] 写清工期、付款节点和违约责任，按节点付款
- [ ] 留 5%–10% 尾款，验收后付
- [ ] 报物业登记：房产证明、身份证、装修方案图纸、公司资质
- [ ] 交装修保证金，办施工人员出入证

## 拆改与水电

- [ ] 承重墙、剪力墙、梁柱不动，不扩大门窗洞口
- [ ] 拆前确认水电走向，关闭总阀
- [ ] 垃圾袋装，按物业指定位置堆放清运
- [ ] 电线分路，厨房、空调、卫生间独立回路
- [ ] 水管打压测试，拍照录像记录走向，图纸留底

## 防水与泥木

- [ ] 卫生间、厨房、阳台做防水，墙面高度按规范
- [ ] 闭水试验 24–48 小时，到楼下看渗漏，合格再签字
- [ ] 瓷砖查空鼓，木作看收边，墙面找平
- [ ] 油漆前保护成品，保持通风
- [ ] 安装橱柜、卫浴、灯具、地板，核对型号数量，查划痕

## 竣工入住

- [ ] 逐项验收，列整改清单，整改完再结清尾款
- [ ] 通水通电通气测试
- [ ] 索要水电走向图、保修卡、发票
- [ ] 记住保修期：基础工程 2 年，防水 5 年
- [ ] 通风 3–6 个月，别信「零甲醛」
- [ ] 找 CMA 资质机构检测甲醛，达标再住

## 出问题找谁

- [ ] 公司跑路：报警，向市场监管投诉，联合业主维权
- [ ] 漏水到楼下：立即关水，拍照，协商维修赔偿
- [ ] 甲醛超标：继续通风，专业治理后复检
- [ ] 施工事故：拨 120、110，保留现场，通知公司
- [ ] 合同纠纷：留合同、付款凭证、聊天记录，投诉或起诉
