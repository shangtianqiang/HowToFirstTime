# H-04 第一次开通水电燃气宽带 · 清单

> 打印后勾选。依据见 [H-04 正文](../book/08-居住与生活/H-04-第一次开通水电燃气宽带.md)。

## 备材料查现状

- [ ] 备身份证、房产证或购房合同；租房备租赁合同和房东授权
- [ ] 户口簿部分业务要带，银行卡备着用于代扣
- [ ] 问房东或前业主：户号、是否欠费、表具位置
- [ ] 拍照记录电表、水表、燃气表读数
- [ ] 确认燃气灶和热水器合规，无熄火保护的灶具可能不通气
- [ ] 确认宽带是否已覆盖小区

## 分头办理

- [ ] 电：网上国网 App 或供电营业厅，实名认证提交房产或租赁证明，拿户号
- [ ] 水：水务营业厅或线上开户，签供用水合同
- [ ] 燃气：必须由燃气公司开通，预约上门安检和通气，不私自改管
- [ ] 二手房：水电燃气全部过户，结清前业主欠费，否则可能停供
- [ ] 宽带：三大运营商比套餐，问清速率和是否绑定手机号

## 宽带细节

- [ ] 看清合约期，通常 1–2 年
- [ ] 提前解约的违约金问清再签
- [ ] 问清安装费和光猫押金，一般在 0–200 元
- [ ] 宽带安装完成，测速正常再让师傅走

## 设置缴费

- [ ] 绑定支付宝、微信或官方 App
- [ ] 设自动缴费或缴费提醒，欠费会停供还生滞纳金
- [ ] 水电燃气都按阶梯价计费，留意用量
- [ ] 客服和抢修电话存手机，贴冰箱上

## 出问题找谁

- [ ] 燃气泄漏：关阀、开窗、撤离，到室外打燃气公司抢修电话
- [ ] 停水停电：先查欠费和抢修公告，问物业
- [ ] 水管爆裂：关总阀，联系水务和物业
- [ ] 宽带故障：重启光猫，报修并保留工单号
- [ ] 表具异常：拍照，联系公司校验
- [ ] 上门推销换管收费：核实工牌，拨官方客服
