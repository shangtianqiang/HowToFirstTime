# H-04 第一次开通水电燃气宽带 · 清单

> 打印后勾选。依据见 [H-04 正文](../book/08-居住与生活/H-04-第一次开通水电燃气宽带.md)。

## 材料

- [ ] 身份证
- [ ] 房产证或购房合同
- [ ] 租赁合同和房东授权
- [ ] 户口簿（如需）
- [ ] 银行卡

## 查现状

- [ ] 问户号和欠费
- [ ] 拍照电表水表燃气表
- [ ] 确认燃气灶和热水器合规
- [ ] 确认宽带覆盖

## 办理

- [ ] 电开户或过户
- [ ] 水开户或过户
- [ ] 燃气开户和安检
- [ ] 宽带预约安装
- [ ] 绑定线上缴费
- [ ] 设置缴费提醒

## 安全

- [ ] 燃气软管检查
- [ ] 燃气报警器
- [ ] 总阀和总闸位置
- [ ] 存客服和抢修电话

## 出问题找谁

- [ ] 燃气泄漏：关阀、开窗、室外打电话
- [ ] 停水停电：查欠费和抢修
- [ ] 水管爆裂：关总阀，联系水务
- [ ] 宽带故障：重启光猫、报修
