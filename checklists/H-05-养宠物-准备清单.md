# H-05 第一次养宠物 · 清单

> 打印后勾选。依据见 [H-05 正文](../book/08-居住与生活/H-05-第一次养宠物.md)。

## 养前评估

- [ ] 房东和物业允许，看清合同是否写明
- [ ] 家人不过敏、不怕动物
- [ ] 每天能遛狗 1–2 小时，出差旅行有人照顾
- [ ] 算清年度预算：食物约 100–500 元/月，疫苗驱虫每年几百元
- [ ] 不冲动买「网红品种」，先查当地禁养犬种目录

## 挑宠来源

- [ ] 领养优先，找正规救助机构
- [ ] 买宠物查繁殖场资质，不买来路不明的幼犬
- [ ] 幼犬看疫苗记录，看得到母犬更好
- [ ] 警惕「星期狗」，病宠治病花更多

## 备齐用品

- [ ] 食盆水盆、狗粮或猫粮
- [ ] 牵引绳和胸背带，大型犬按当地规定备嘴套
- [ ] 猫砂盆和猫砂
- [ ] 航空箱或外出包
- [ ] 疫苗本和养犬登记证
- [ ] 养猫封窗，防猫坠楼

## 疫苗登记

- [ ] 幼犬幼猫按兽医方案接种疫苗，猫打猫三联和狂犬疫苗
- [ ] 犬只每年接种狂犬疫苗
- [ ] 体内外驱虫按体重和季节做
- [ ] 到派出所、城管或指定平台办养犬登记
- [ ] 提交身份证、居住证明、疫苗证明，领犬牌

## 日常与就医

- [ ] 定时喂食，不喂人吃的剩菜，巧克力、洋葱、葡萄有毒
- [ ] 每天遛狗牵绳、戴犬牌，当场清理粪便
- [ ] 猫砂盆每天清理
- [ ] 选有动物诊疗许可证的医院，保留病历和发票
- [ ] 绝育、洗牙、体检按兽医建议
- [ ] 考虑宠物医疗险，看病常见病几百到几千元
- [ ] 出行用航空箱，不把宠物单独留车内；寄养选正规机构

## 出问题找谁

- [ ] 被咬伤：立即冲洗伤口 15 分钟，就医打狂犬疫苗
- [ ] 误食：带上包装就医，不要自行催吐
- [ ] 走失：小区群和平台发布，贴寻宠启事，查监控
- [ ] 伤人：送医、垫付、保留记录，联系保险公司，协商或走法律
- [ ] 养不了：找人领养或联系救助机构，不遗弃
