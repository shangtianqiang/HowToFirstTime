# H-06 第一次处理邻里纠纷 · 清单

> 打印后勾选。依据见 [H-06 正文](../book/08-居住与生活/H-06-第一次处理邻里纠纷.md)。

## 先取证定诉求

- [ ] 记录时间、行为、持续多久、影响多大，证据会随时间消失，别拖延
- [ ] 录音录像保持连续性；在公共区域或自己家中取证，不侵入住宅、不拍隐私
- [ ] 找其他受影响的邻居作证
- [ ] 保存与物业的沟通记录
- [ ] 诉求写具体：停止侵害、赔礼道歉、赔偿损失、修复漏水、限时施工

## 先礼后兵沟通

- [ ] 当面或书面说明影响，态度平和
- [ ] 提具体诉求，如「晚上 11 点后的声音影响到我休息，能不能调整」
- [ ] 不对骂不动手，最好有物业或邻居在场
- [ ] 不堵门、不断水断电，违法可能反被起诉
- [ ] 不上网曝光，可能侵犯名誉权

## 物业与居委会

- [ ] 向物业交书面投诉，要求上门协调
- [ ] 拿工单编号，保留处理记录
- [ ] 向居委会申请调解，提交证据
- [ ] 拿调解记录或签调解协议；能调解就调解，直接诉讼成本更高

## 报警

- [ ] 噪声扰民、人身威胁、故意毁坏财物，拨 110
- [ ] 人身威胁立即报警，保留录音
- [ ] 高空抛物：立即报警，保留物品，查监控
- [ ] 拿受案回执

## 诉讼

- [ ] 调解不成，收集证据向法院起诉，要求停止侵害和赔偿
- [ ] 写起诉状，向法院立案
- [ ] 可申请行为保全，要求停止侵害
- [ ] 诉讼费按标的额收，邻里纠纷通常几十到几百元，可申请法律援助

## 出问题找谁

- [ ] 楼上漏水：关总阀、拍照录像，联系楼上和物业，必要时申请鉴定
- [ ] 高空抛物伤人：拨 120、110，保护现场
- [ ] 占楼道堵消防通道：找物业清理，向消防部门举报
- [ ] 对方是租户：同时联系房东和物业
- [ ] 群体纠纷：推选代表，统一证据，避免冲突
