# H-07 第一次办居住证 · 清单

> 打印后勾选。依据见 [H-07 正文](../book/08-居住与生活/H-07-第一次办居住证.md)。

## 条件

- [ ] 确认居住满半年
- [ ] 确认有稳定就业、住所或就读
- [ ] 完成居住登记

## 材料

- [ ] 身份证
- [ ] 租赁合同或房产证
- [ ] 劳动合同或社保记录
- [ ] 学生证或学校证明
- [ ] 照片
- [ ] 居住登记回执

## 办理

- [ ] 到派出所或社区
- [ ] 填表
- [ ] 采集照片
- [ ] 拿受理回执
- [ ] 按时间领证
- [ ] 核对信息

## 后续

- [ ] 每年签注
- [ ] 住址变更及时更新
- [ ] 换城市重新办理
- [ ] 了解子女入学和医保用途

## 出问题找谁

- [ ] 房东不配合：社区说明、投诉
- [ ] 材料退回：按清单补
- [ ] 签注逾期：尽快补签
- [ ] 证件丢失：挂失补办
