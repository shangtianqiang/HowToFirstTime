# H-07 第一次办居住证 · 清单

> 打印后勾选。依据见 [H-07 正文](../book/08-居住与生活/H-07-第一次办居住证.md)。

## 确认条件

- [ ] 确认在当前城市居住满半年
- [ ] 有合法稳定就业、住所或连续就读之一
- [ ] 先办居住登记，多数城市登记满半年才能申领
- [ ] 问清当地按「居住登记满半年」还是「实际居住满半年」算

## 备材料

- [ ] 身份证
- [ ] 居住证明：租赁合同、房产证或单位宿舍证明
- [ ] 就业证明：劳动合同、社保记录或营业执照
- [ ] 就读证明：学生证或学校证明
- [ ] 照片按当地要求准备
- [ ] 居住登记回执（如有）

## 登记与申领

- [ ] 到派出所、社区服务站或线上平台办居住登记，拿登记凭证
- [ ] 租房让房东配合提供房产信息
- [ ] 到居住地派出所或社区事务受理中心填表申领
- [ ] 提交材料，采集照片，拿受理回执和领证时间
- [ ] 办理周期约 5–30 天，按城市
- [ ] 按通知领取或选邮寄，核对姓名、身份证号、住址、有效期

## 签注与变更

- [ ] 有效期通常一年，每年签注一次
- [ ] 到期前办签注，逾期功能中止，补签后恢复
- [ ] 住址变更及时更新，影响子女入学和办事
- [ ] 换城市要重新办理，跨市不通用
- [ ] 用起来：子女入学、医保、驾照、车牌、职业资格考试、积分落户

## 出问题找谁

- [ ] 房东不配合：提供租赁合同向社区说明，必要时投诉
- [ ] 材料被退回：问清原因，按清单补
- [ ] 签注逾期：尽快补签并说明情况
- [ ] 证件丢失：带身份证挂失补办，首次申领免费
- [ ] 子女入学急用：提前一年准备，问教育局
- [ ] 不轻信收费代办，材料造假取消资格还影响信用
