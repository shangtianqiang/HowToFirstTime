# H-08 第一次找家政/保姆 · 清单

> 打印后勾选。依据见 [H-08 正文](../book/08-居住与生活/H-08-第一次找家政保姆.md)。

## 需求

- [ ] 明确工作内容
- [ ] 住家还是不住家
- [ ] 每天工时
- [ ] 每周休息
- [ ] 工资预算
- [ ] 支付方式

## 选公司

- [ ] 营业执照
- [ ] 经营年限
- [ ] 服务员是否公司员工
- [ ] 是否培训
- [ ] 查信用平台
- [ ] 不找黑家政

## 面试

- [ ] 工作经验
- [ ] 健康证
- [ ] 身份证
- [ ] 培训证书
- [ ] 带孩子或老人经验
- [ ] 能否住家

## 合同

- [ ] 三方合同
- [ ] 服务内容
- [ ] 工时和休息
- [ ] 工资和支付日
- [ ] 请假和违约
- [ ] 损坏赔偿
- [ ] 保险责任

## 入职

- [ ] 介绍家庭习惯
- [ ] 交接钥匙和门禁
- [ ] 家电使用
- [ ] 告知摄像头位置
- [ ] 紧急联系人

## 出问题找谁

- [ ] 突然离职：公司调换
- [ ] 物品丢失：报警、公司
- [ ] 老人儿童受伤：就医、保险、监控
- [ ] 隐私泄露：报警、起诉
