# H-08 第一次找家政/保姆 · 清单

> 打印后勾选。依据见 [H-08 正文](../book/08-居住与生活/H-08-第一次找家政保姆.md)。

## 明确需求

- [ ] 列清工作内容：保洁、做饭、带孩子还是照顾老人
- [ ] 定住家还是不住家，每天几小时
- [ ] 每周休息几天，法定节假日工资怎么算
- [ ] 定工资预算和支付方式，不发现金，转账留记录

## 选公司

- [ ] 查营业执照和经营年限
- [ ] 问服务员是否公司员工、是否培训
- [ ] 到家政服务信用信息平台查信用，部分城市可查犯罪记录
- [ ] 不找路边小广告和熟人口中的「黑家政」
- [ ] 不私下雇佣：没合同没保险，出事难维权

## 面试核验

- [ ] 问工作经验、擅长的菜、带孩子经验、能否住家
- [ ] 核验健康证，涉及老人儿童的建议加查传染病
- [ ] 核验身份证
- [ ] 看培训证书（育儿嫂、护工）
- [ ] 身份核实后再交接钥匙，别引狼入室

## 签合同

- [ ] 签三方合同：雇主、家政公司、服务员，各持一份
- [ ] 写清服务内容、时间、工资、休息、请假和违约
- [ ] 写清损坏物品、人身伤害的责任划分
- [ ] 确认家政责任险和意外险，问清谁出钱买
- [ ] 约定更换或解约的提前通知和结算方式

## 入职与日常

- [ ] 介绍家庭情况、生活习惯和禁忌
- [ ] 交接钥匙、门禁，讲清家电使用
- [ ] 告知摄像头位置，卧室卫生间等隐私区域不装
- [ ] 节假日按合同安排，加班费或调休
- [ ] 每周沟通一次，及时反馈
- [ ] 尽量不让保姆单独带幼儿，有家人监护

## 出问题找谁

- [ ] 突然离职：联系公司调换，按合同结算
- [ ] 物品丢失：保留证据，报警，联系公司
- [ ] 老人儿童受伤：先就医，报保险，查监控
- [ ] 服务员受伤：就医，报保险，按合同处理
- [ ] 损坏物品：凭照片和购买凭证索赔，从工资扣要合法
- [ ] 隐私泄露或纠纷：保留证据，找公司、打 12315 或起诉
