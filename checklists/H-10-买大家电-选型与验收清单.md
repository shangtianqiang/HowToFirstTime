# H-10 第一次买大家电 · 清单

> 打印后勾选。依据见 [H-10 正文](../book/08-居住与生活/H-10-第一次买大家电.md)。

## 下单前

- [ ] 量三个尺寸：入户门/电梯、摆放位（含散热空间）、楼道转角
- [ ] 冰箱看升数，洗衣机看公斤数，空调按面积选匹数
- [ ] 看能效标签（吃国补须一级），扫码验真
- [ ] 问国补怎么算：先减店铺优惠再算最终价的 15%，每人每类限 1 件，家电单件至多 1500 元
- [ ] 问补贴到账方式：先减后付还是先付后返，后者要留凭证
- [ ] 要安装辅料价目表（挂架/管线/支架）
- [ ] 确认送装时间、上楼费、旧机拆运和折价
- [ ] 线上线下比「到手价」

## 收货当天

- [ ] 当面开箱：外观、配件、三包凭证、发票，别先签字后开箱
- [ ] 通电试机：冰箱启动、洗衣机空转进排水、空调制冷
- [ ] 有损伤当场拒收或注明后再签
- [ ] 没来得及试机，第二天发现问题立即拍照联系客服，多数平台 24 小时内可主张

## 安装时

- [ ] 位置提前想好，挂壁空调看支架螺栓，热水器看防电墙和泄压
- [ ] 师傅推荐「升级配件」：非必需的可拒
- [ ] 辅料收费逐项核对价目表再确认
- [ ] 试机正常再签安装单，收好单据（保修常凭安装日期）
- [ ] 包装箱留两周，退换货要原包装

## 售后与三包

- [ ] 分清两个 7 天：三包 7 日针对性能故障，网购另有 7 天无理由退货
- [ ] 7 日内性能故障：可选退货/换货/修理，「只能修」是话术
- [ ] 8–15 日内：选换货或修理
- [ ] 同一故障修两次可主张换货
- [ ] 报修提供发票和安装单，维修记录留底
- [ ] 电子发票存档，纸质发票放说明书袋

## 出问题找谁

- [ ] 送装进不了门：现场测量拍照，让客服改方案（拆门、吊装、换型号），费用按责任方承担
- [ ] 安装后通电跳闸：先排查线路容量，找物业电工；机器本身故障走售后
- [ ] 补贴承诺不兑现：留订单页和客服承诺截图，向平台投诉，未果打 12315
- [ ] 到货与订单型号不符：拒签或当场拍照留证，主张换货及补偿
- [ ] 强制搭售或「不装不管保修」：向品牌客服和 12315 反映
- [ ] 空调搬家拆装：找品牌售后或专业拆装，别找杂牌游击队
- [ ] 延保要买：确认承保方和覆盖部件，口头承诺写进合同
