# H-10 第一次买大家电 · 清单

> 打印后勾选。依据见 [H-10 正文](../book/08-居住与生活/H-10-第一次买大家电.md)。

## 下单前

- [ ] 量三个尺寸：入户门/电梯、摆放位（含散热空间）、楼道转角
- [ ] 看能效标签（吃国补须一级），扫码验真
- [ ] 问国补资格和到账方式（立减还是返现）
- [ ] 要安装辅料价目表（挂架/管线/支架）
- [ ] 确认送装时间、上楼费、旧机拆运
- [ ] 线上线下比「到手价」

## 收货当天

- [ ] 当面开箱：外观、配件、三包凭证、发票
- [ ] 通电试机（冰箱启动/洗衣机空转/空调制冷）
- [ ] 有损伤当场拒收或注明再签

## 安装时

- [ ] 位置提前想好，别师傅问哪都行
- [ ] 辅料收费逐项核对再确认
- [ ] 试机正常再签安装单，收好单据
- [ ] 包装箱留两周

## 售后底线

- [ ] 7 日内性能故障：可选退货/换货/修理
- [ ] 8–15 日内：选换货或修理
- [ ] 发票+安装单存好，维修记录留底
- [ ] 纠纷：平台客服 → 12315
