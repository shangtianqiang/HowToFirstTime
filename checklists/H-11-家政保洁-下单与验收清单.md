# H-11 第一次约家政保洁与空调清洗 · 清单

> 打印后勾选。依据见 [H-11 正文](../book/08-居住与生活/H-11-第一次约家政保洁与空调清洗.md)。

## 下单前

- [ ] 想清楚服务类型：日常 / 深度 / 开荒 / 单项（油烟机、空调、冰箱清洗）
- [ ] 对齐计价口径：日常约 40–60 元/小时，深度约 6–12 元/㎡，开荒约 5–15 元/㎡，别只比总价
- [ ] 开荒保洁约在硬装完、家具进场前，进场后再做边角扫不到还更贵
- [ ] 微信支付宝搜「家政信用查」核验人员信用
- [ ] 问清人员是否持「居家上门服务证」（电子版即可）
- [ ] 写清服务范围、耗材设备谁出、超时怎么算
- [ ] 约定取消改期和损坏赔偿规则；包年卡先算单价，优先按次付或短周期

## 服务当天

- [ ] 贵重物品、现金、证件收好，交代宠物和易碎品
- [ ] 提供水电和使用许可
- [ ] 核对上门人员与订单信息再开工
- [ ] 带看重点区域，说明禁忌（地板怕水怕划、不进的房间）
- [ ] 加项当场确认价格写进订单，不口头含糊
- [ ] 外窗作业要求系安全带
- [ ] 首次服务建议在家

## 验收

- [ ] 重点查边角缝隙、玻璃正反面、厨卫油污水垢、柜顶床底
- [ ] 不合格当场指出，正常范围内返工不另收费
- [ ] 空调分普通清洗（滤网+外壳）和深度拆洗（蒸发器、风轮），价格差数倍，下单看清
- [ ] 空调验收：滤网蒸发器干净、开机无异味、滴水正常
- [ ] 合格再点完成/签单，单据留底
- [ ] 遗漏区域 24 小时内拍照联系客服，正常范围补做不收费

## 安全与维权

- [ ] 不交长期钥匙和永久密码，用临时密码用完即删
- [ ] 损坏先拍照停工，联系平台/公司定损，索要所用清洁剂名称留证
- [ ] 被反锁或怀疑失窃：立即报警，调监控，凭订单和沟通记录
- [ ] 保洁爽约：联系平台改约或要求赔付
- [ ] 想长期约同一位：仍走平台下单指定人员，别私下绕开
- [ ] 纠纷：平台客服 → 12315
