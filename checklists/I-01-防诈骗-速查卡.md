# I-01 第一次防诈骗 · 清单

> 打印后勾选。依据见 [I-01 正文](../book/09-数字与网络/I-01-第一次防诈骗.md)。

## 日常防线

- [ ] 三不一多：未知链接不点、陌生来电不信、个人信息不透露、转账前多核实
- [ ] 不出租、出借、出售电话卡、银行卡、支付账户和社交账号
- [ ] 快递单、外卖单涂掉个人信息再扔
- [ ] 身份证号、银行卡号、验证码不随便给
- [ ] 不扫来历不明的二维码，不装陌生 App
- [ ] 装国家反诈中心 App，留意 12381 涉诈预警短信

## 认识高发套路

- [ ] 记住 10 类高发：刷单返利、虚假投资、虚假购物、冒充客服、贷款征信、冒充领导熟人、冒充公检法、婚恋交友、游戏交易、机票退改签
- [ ] 要求保密、开屏幕共享、先交手续费保证金解冻金、催你马上决定——都是诈骗信号
- [ ] 公检法没有「安全账户」，让你转账到「安全账户」的都是诈骗
- [ ] 投资理财没有稳赚不赔，导师带单先给小利、后让你垫大额
- [ ] 领导熟人换号借钱：先打电话核实本人

## 接到可疑电话

- [ ] 先挂断，不按对方要求操作
- [ ] 用官方 App 或客服电话回拨核实，确认诈骗就拉黑举报
- [ ] 不提供验证码、密码、银行卡号
- [ ] 96110 来电要接——说明你或家人可能正在被骗
- [ ] 拿不准拨 96110 咨询

## 已经被骗

- [ ] 立即拨 110 请求紧急止付，说清被骗时间、金额、对方账号、转账方式
- [ ] 保存聊天记录、转账凭证、对方账号、涉诈 App 或网址
- [ ] 联系银行或支付平台客服挂失冻结
- [ ] 到派出所报案做笔录，拿受案回执
- [ ] 修改相关密码，检查其他账户是否被盗
- [ ] 金额小也要报警

## 防二次诈骗

- [ ] 不信网上「网警」「律师」「黑客」「追款专员」
- [ ] 不交保证金、解冻金，不把「追回的钱」转到指定账户
- [ ] 公安民警不会在网上留 QQ、微信办案
- [ ] 只联系办案民警和官方客服，进展以办案机关通知为准

## 帮家人防骗

- [ ] 帮老人装国家反诈中心 App
- [ ] 给老人孩子的手机设置支付限额
- [ ] 约定大额转账先打电话确认
- [ ] 老人被骗：先报警再安抚，保留证据不责怪
