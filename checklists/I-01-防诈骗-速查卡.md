# I-01 第一次防诈骗 · 清单

> 打印后勾选。依据见 [I-01 正文](../book/09-数字与网络/I-01-第一次防诈骗.md)。

## 日常

- [ ] 未知链接不点
- [ ] 陌生来电不信
- [ ] 个人信息不透露
- [ ] 转账前多核实
- [ ] 不出租、出借、出售电话卡和银行卡

## 接到可疑电话

- [ ] 先挂断，不按对方要求操作
- [ ] 用官方 App 或客服电话核实
- [ ] 不提供验证码、密码、银行卡号
- [ ] 拿不准拨 96110 咨询

## 已经被骗

- [ ] 立即拨 110 请求紧急止付
- [ ] 保存聊天记录、转账凭证、对方账号
- [ ] 联系银行或支付平台冻结账户
- [ ] 到派出所报案并拿回执

## 防二次诈骗

- [ ] 不信网上“网警”“律师”“追款专员”
- [ ] 不交保证金、解冻金
- [ ] 只联系办案民警和官方客服

## 帮家人防骗

- [ ] 帮老人装国家反诈中心 App
- [ ] 设置支付限额
- [ ] 约定大额转账先打电话确认
