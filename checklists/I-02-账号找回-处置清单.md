# I-02 第一次账号被盗/找回 · 清单

> 打印后勾选。依据见 [I-02 正文](../book/09-数字与网络/I-02-第一次账号被盗找回.md)。

## 发现被盗

- [ ] 确认异常迹象
- [ ] 用另一台设备尝试改密
- [ ] 官方客服冻结
- [ ] 通知家人朋友
- [ ] 检查银行卡和支付账户

## 申诉

- [ ] 只在官方渠道申诉
- [ ] 身份证
- [ ] 历史密码和注册信息
- [ ] 好友辅助
- [ ] 记下申诉编号

## 找回后

- [ ] 改强密码
- [ ] 开二次验证
- [ ] 检查绑定手机和邮箱
- [ ] 踢掉陌生设备
- [ ] 检查授权应用
- [ ] 检查交易记录

## 有损失

- [ ] 银行卡挂失
- [ ] 支付账户冻结
- [ ] 拨 110 或 96110
- [ ] 保留证据

## 不做什么

- [ ] 不找找回中介
- [ ] 不点陌生找回链接
- [ ] 不把验证码给别人
- [ ] 不删除聊天记录
