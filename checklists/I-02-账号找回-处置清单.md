# I-02 第一次账号被盗/找回 · 清单

> 打印后勾选。依据见 [I-02 正文](../book/09-数字与网络/I-02-第一次账号被盗找回.md)。

## 发现被盗

- [ ] 对迹象：密码突然失效、收到陌生登录提醒、账号发布陌生内容
- [ ] 好友收到你「借钱」的消息、绑定手机或邮箱被改——按被盗处理
- [ ] 用另一台设备登录尝试改密码
- [ ] 改不了就找官方客服申请紧急冻结
- [ ] 通知家人朋友别信借钱消息，让好友电话视频核实
- [ ] 检查银行卡和支付账户有无异常

## 准备申诉

- [ ] 备好身份证、绑定手机号
- [ ] 整理历史密码、注册时间、常用地点
- [ ] 保存交易记录截图
- [ ] 只在官方 App 和官网申诉，记下申诉编号和处理时限
- [ ] 按平台要求找 2–3 位好友辅助验证，不让好友转账点链接

## 找回后加固

- [ ] 改独立强密码，不与其他账号复用
- [ ] 开启二次验证和登录保护
- [ ] 绑定手机被改：走人工申诉，提供身份证和入网证明，联系运营商
- [ ] 踢掉陌生登录设备
- [ ] 检查授权应用和交易记录

## 有损失

- [ ] 支付账户被盗刷：立即挂失、报警、申请赔付
- [ ] 拨 110 或 96110 申请止付
- [ ] 保留交易记录和聊天记录
- [ ] 游戏账号被盗：带充值记录和账号信息报案
- [ ] 被敲诈：不转账，报警，保留聊天记录

## 不做什么

- [ ] 不找「找回中介」，多为骗局还二次泄露信息
- [ ] 不信「内部解封」
- [ ] 不点陌生找回链接
- [ ] 不把验证码给别人
- [ ] 不删除聊天记录
- [ ] 未成年人账号由监护人协助申诉，企业账号联系管理员走企业通道
