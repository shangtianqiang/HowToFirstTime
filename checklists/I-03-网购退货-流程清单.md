# I-03 第一次网购与退货 · 清单

> 打印后勾选。依据见 [I-03 正文](../book/09-数字与网络/I-03-第一次网购与退货.md)。

## 下单前

- [ ] 正规平台
- [ ] 看商品参数
- [ ] 看店铺评分和差评
- [ ] 看发货时间
- [ ] 看退换规则
- [ ] 买运费险
- [ ] 对比价格

## 支付

- [ ] 平台官方支付
- [ ] 不扫私人收款码
- [ ] 不脱离平台
- [ ] 保留订单记录

## 收货

- [ ] 核对快递
- [ ] 贵重物品拍开箱视频
- [ ] 检查外观和数量
- [ ] 保留包装和吊牌
- [ ] 破损拒收

## 退货

- [ ] 七天内申请
- [ ] 选退货原因
- [ ] 上传照片
- [ ] 按平台地址寄回
- [ ] 保留快递单号
- [ ] 跟进退款

## 出问题找谁

- [ ] 不发货：退款、平台投诉
- [ ] 假货：保留证据、投诉、索赔
- [ ] 快递丢失：联系卖家补发
- [ ] 退款不到账：平台客服、12315
