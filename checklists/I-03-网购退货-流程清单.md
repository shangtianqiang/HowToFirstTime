# I-03 第一次网购与退货 · 清单

> 打印后勾选。依据见 [I-03 正文](../book/09-数字与网络/I-03-第一次网购与退货.md)。

## 下单前

- [ ] 只在正规电商 App 下单，不点陌生链接
- [ ] 看清商品参数、材质、产地和发货时间，是否预售
- [ ] 看店铺评分和差评，对比价格防「先涨后降」
- [ ] 看退换规则，顺手买运费险
- [ ] 平台官方支付，不扫私人收款码，不加微信转账
- [ ] 保留订单和支付记录
- [ ] 退款只走平台流程，不点陌生「退款」链接

## 收货验货

- [ ] 核对快递单号和商品
- [ ] 外包装破损，当着快递员拆箱拍照
- [ ] 贵重物品拍开箱视频
- [ ] 检查外观、数量、型号，不符当场拒收或拍照留证
- [ ] 保留包装和吊牌——剪吊牌、下水洗就不能退了

## 七天无理由退货

- [ ] 自收到商品之日起七日内，商品完好可退
- [ ] 拆封查验不影响商品完好，可以退；使用痕迹明显可能被拒
- [ ] 定制、生鲜、拆封音像制品、报刊不适用无理由退货
- [ ] 平台订单页申请：选原因、上传照片
- [ ] 看清退货地址、运费承担、退款时间：无理由退货运费买家出，质量问题卖家出
- [ ] 按平台提供的地址寄回，保留快递单号
- [ ] 商家签收后 1–7 个工作日退款到账
- [ ] 预售商品：定金通常不退，尾款可退，看平台规则

## 出问题找谁

- [ ] 长时间不发货：申请退款，向平台投诉
- [ ] 收到假货：保留商品和包装拍照，申请退款并投诉，可主张赔偿
- [ ] 快递丢失：联系卖家补发或退款，卖家向快递索赔
- [ ] 商家跑路：平台投诉，申请先行赔付
- [ ] 退款不到账：平台客服，保留记录，12315
- [ ] 买到违禁品：报警，保留证据
