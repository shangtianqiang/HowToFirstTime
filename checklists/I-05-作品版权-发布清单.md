# I-05 第一次发布作品与版权 · 清单

> 打印后勾选。依据见 [I-05 正文](../book/09-数字与网络/I-05-第一次发布作品与版权.md)。

## 发布前

- [ ] 确认作品权属
- [ ] 图片有授权
- [ ] 音乐有授权
- [ ] 字体有商用授权
- [ ] 肖像权授权
- [ ] 看平台协议
- [ ] 保留原稿

## 发布

- [ ] 保留署名
- [ ] 记录发布时间
- [ ] 保存链接
- [ ] 选择许可协议
- [ ] AI 内容加标识

## 监测

- [ ] 定期搜索标题
- [ ] 搜索图片
- [ ] 截图取证
- [ ] 记录侵权链接

## 维权

- [ ] 发通知要求删除
- [ ] 平台投诉
- [ ] 提交权属证明
- [ ] 公证取证
- [ ] 起诉

## 授权

- [ ] 书面许可合同
- [ ] 范围、期限、地域
- [ ] 费用和支付
- [ ] 独家条款谨慎

## 出问题找谁

- [ ] 被索赔：核实权利、保留授权
- [ ] 平台下架：提交权属申诉
- [ ] 被盗图：取证、通知、起诉
- [ ] 商业秘密泄露：报警
