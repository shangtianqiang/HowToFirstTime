## 认证前

- [ ] 确认是官方渠道

- [ ] 看隐私政策
- [ ] 确认办事必需

## 认证

- [ ] 本人操作
- [ ] 人脸识别环境安全
- [ ] 只填必要信息
- [ ] 不把验证码给别人
- [ ] 保存认证结果

## 权限

- [ ] 关闭通讯录
- [ ] 关闭不必要定位
- [ ] 关闭不必要相册
- [ ] 关闭后台麦克风相机
- [ ] 定期检查授权

## 账号

- [ ] 强密码
- [ ] 二次验证
- [ ] 注销不用的账号
- [ ] 解绑银行卡
- [ ] 检查名下账号

## 泄露处置

- [ ] 改密码
- [ ] 冻结账号
- [ ] 通知银行
- [ ] 12321、网信、公安投诉
- [ ] 保留证据

## 出问题找谁

- [ ] 身份被冒用：报警、平台申诉、查征信
- [ ] 人脸泄露：报警、删除、防换脸诈骗

- [ ] 未成年人充值：平台退款
