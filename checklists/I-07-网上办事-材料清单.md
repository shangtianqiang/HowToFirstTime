# I-07 第一次网上办事 · 清单

> 打印后勾选。依据见 [I-07 正文](../book/09-数字与网络/I-07-第一次网上办事.md)。

## 认准入口

- [ ] 国家政务服务平台、当地一网通办 App 或部门官网（人社、医保、公积金、公安、税务）
- [ ] 核对官方域名和备案信息，只从官方应用商店下载 App
- [ ] 不用搜索引擎广告位链接，不点短信链接
- [ ] 不向「代办」交钱，多数政务事项免费，少数工本费按公示收

## 备材料

- [ ] 身份证正反面、户口簿
- [ ] 相关证明：结婚证、出生证明、劳动合同
- [ ] 电子照片按规格，银行卡（如需）
- [ ] 代办：授权委托书和双方身份证
- [ ] 材料拍正、清晰、四角完整，不反光不遮挡
- [ ] 存成 PDF 或 JPG，大小符合要求，多页合并

## 办理

- [ ] 手机可拍照、人脸识别，网络稳定再开始
- [ ] 注册绑定手机号，完成实名认证和人脸核验
- [ ] 搜索事项，看受理条件、材料清单、办理时限、是否收费
- [ ] 按提示填表上传，确认提交成功
- [ ] 记下办件编号和查询密码，截图保存

## 跟进

- [ ] 定期查进度；办件编号丢了用账号查「我的办件」，或拨 12345 提供身份证号查询
- [ ] 收到补正通知在规定时间内补齐，错过期限视为放弃
- [ ] 办结后在「我的证照」下载电子证照，与纸质同等效力
- [ ] 纸质证照选邮寄（约 10–30 元）或窗口领取
- [ ] 简单事项当天办结，复杂事项要等几个工作日到几十天

## 出问题找谁

- [ ] 认证失败：检查光线和网络，换设备，或到线下窗口
- [ ] 系统故障：错峰办理，拨 12345
- [ ] 材料被退回：看原因补材料或改信息，重新提交
- [ ] 办件超时：拨 12345 投诉
- [ ] 老年人操作困难：到政务大厅「帮办代办」窗口
- [ ] 信息被冒用：报警，联系平台冻结
