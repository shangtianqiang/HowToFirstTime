# I-09 第一次发短视频/开直播 · 清单

> 打印后勾选。依据见 [I-09 正文](../book/09-数字与网络/I-09-第一次发短视频与开直播.md)。

## 发布前

- [ ] 通读平台社区规则和直播规范
- [ ] 确认年龄达标：直播发布者账号年满 16 周岁，未成年人已取得监护人同意
- [ ] 完成手机号注册和身份证实名认证
- [ ] 医疗、财经、法律、教育内容已备好执业资质并报备，无资质不碰这类选题
- [ ] 背景音乐来自平台曲库或已获授权
- [ ] 影视、综艺片段有授权，或使用平台授权素材
- [ ] 画面里没有未经同意的路人正脸、门牌车牌、聊天记录
- [ ] 出镜亲友已同意露脸，未成年人出镜有监护人把关
- [ ] 定位等权限按需开启

## 开直播前

- [ ] 背景整理干净，清走快递单、票据、证件
- [ ] 准备好口播提示，如「出镜家人均已同意」
- [ ] 网络和电量正常，支架补光灯就位
- [ ] 定好时长，不连续久播
- [ ] 记住三不：不诱导大额打赏、不虚假宣传、不展示他人隐私

## 带货加做

- [ ] 已开通带货权限，按平台提交实名和经营资质
- [ ] 核对类目证照：食品要食品经营许可证，图书要出版物经营许可证
- [ ] 资质信息按平台要求在显著位置公示
- [ ] 带购物链接的种草、测评内容已标明「广告」
- [ ] 话术自查：不说「全网最低」「保证有效」这类话
- [ ] 只挂平台内链接，不引导站外转账

## 出问题找谁

- [ ] 被网暴：开一键防护屏蔽陌生人，用快捷取证和快捷投诉入口，必要时报警
- [ ] 作品被搬运：存证原片和发布时间，走平台侵权投诉，或向国家版权局举报（12390）
- [ ] 账号被盗或被封：走平台申诉入口，被盗按 I-02 处置
- [ ] 未成年人打赏：联系平台客服，提交监护人证明和打赏记录申请退款
- [ ] 直播泄露隐私：立即下播、删回放，联系平台删除切片
- [ ] MCN 合同纠纷：翻合同找违约和争议解决条款，咨询律师再回复
- [ ] 「招主播」收费骗局：保存聊天记录和转账凭证，报警，参考 I-01
