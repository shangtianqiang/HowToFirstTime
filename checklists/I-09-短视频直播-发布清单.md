# I-09 第一次发短视频/开直播 · 清单

> 打印后勾选。依据见 [I-09 正文](../book/09-数字与网络/I-09-第一次发短视频与开直播.md)。

## 发布前

- [ ] 通读平台社区规则、直播规范和带货规则
- [ ] 确认年龄达标：直播发布者账号年满 16 周岁，未成年人注册需监护人同意
- [ ] 完成手机号注册、身份证实名认证和人脸核验
- [ ] 医疗、财经、法律、教育内容已备好执业资质并报备，无资质不碰这类选题
- [ ] 背景音乐用平台曲库或已获授权，影视片段用平台授权素材或取得版权方同意
- [ ] 画面里没有未经同意的路人正脸、门牌车牌、聊天记录；定位等权限按需开启
- [ ] 出镜亲友已同意露脸，未成年人出镜有监护人把关
- [ ] 定止损线：投入多少时间、多少钱就停，写在纸上

## 开播前

- [ ] 背景整理干净，清走快递单、票据、证件
- [ ] 准备好口播提示，如「出镜家人均已同意」
- [ ] 网络电量正常，支架补光灯就位；定好时长，第一次别连续播几小时
- [ ] 手机通知调成免打扰，防弹窗露出私人短信和验证码
- [ ] 记住三不：不诱导大额打赏、不虚假宣传、不展示他人隐私
- [ ] 观众问用药、投资、打官司，建议对方咨询医生或律师，不在直播间下结论
- [ ] 有人刷屏辱骂，用禁言、屏蔽处理，不与对方对骂
- [ ] 不买粉买数据：虚构点赞量、浏览量、交易数据属违规，冷启动慢是正常的

## 带货加做

- [ ] 已开通带货权限，按平台提交实名和经营资质；粉丝数、保证金门槛以平台规则页为准
- [ ] 核对类目证照：食品要食品经营许可证，图书要出版物经营许可证，资质在显著位置公示
- [ ] 带购物链接的种草、测评内容已标明「广告」
- [ ] 话术自查：不说「全网最低」「保证有效」这类话
- [ ] 只挂平台内链接，不引导站外转账；留好客服入口处理售后

## 下播复盘

- [ ] 正常结束直播，按需保存或删除回放
- [ ] 查后台违规提醒和信用分记录，有违规点开看原因，调整话术和内容
- [ ] 作品审核不通过按提示原因修改后重发，不反复原样重发
- [ ] 想全职先当副业跑几个月，有持续收入再考虑

## 出问题找谁

- [ ] 被网暴：开一键防护屏蔽陌生人，用快捷取证和快捷投诉入口，涉及威胁恐吓报警
- [ ] 作品被搬运：存证原片和发布时间，走平台侵权投诉，或向国家版权局举报（12390）
- [ ] 账号被盗或被封：走平台申诉入口，被盗按 I-02 处置；处理不满意向 12377 反映
- [ ] 未成年人打赏：联系平台客服，提交监护人证明和打赏记录申请退款
- [ ] 直播泄露隐私：立即下播、删回放，联系平台删除切片
- [ ] MCN 合同纠纷：重点看账号归属、收益分成、是否独家、违约金、解约，咨询律师再回复
- [ ] 「招主播」收费骗局：保存聊天记录和转账凭证，报警，参考 I-01
