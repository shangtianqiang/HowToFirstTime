# I-10 第一次手机丢失应急处理 · 清单

> 打印后勾选。依据见 [I-10 正文](../book/09-数字与网络/I-10-第一次手机丢失应急处理.md)。

## 应急三步（借手机完成，10 分钟）

- [ ] 1. 挂失 SIM：移动 10086 / 联通 10010 / 电信 10000
- [ ] 2. 冻结支付宝：95188 或 110.alipay.com
- [ ] 3. 冻结微信支付：95017 按 9

## 紧接着做

- [ ] 银行卡丢失的：逐个打银行客服挂失
- [ ] 冻结手机银行 / 网银
- [ ] iPhone：icloud.com/find 开丢失模式；安卓：厂商查找服务锁定
- [ ] 被盗或已盗刷：110 报警，拿回执

## 稳定后恢复

- [ ] 营业厅补 SIM 卡（号码不变）
- [ ] 解除支付冻结，改锁屏和支付密码
- [ ] 重要账号换绑新卡：邮箱 → 支付银行 → 社交
- [ ] 确认找不回的：远程抹除（最后手段）

## 丢失前预防（平时做）

- [ ] 开启厂商「查找」并登录账号
- [ ] 设置 SIM 卡 PIN 码
- [ ] 锁屏密码与支付密码不同
- [ ] 锁屏不显示通知内容
- [ ] 客服电话抄一份放在钱包或家人手机里
