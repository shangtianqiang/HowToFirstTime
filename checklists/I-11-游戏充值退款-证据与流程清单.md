# I-11 第一次处理孩子游戏充值退款 · 清单

> 打印后勾选。依据见 [I-11 正文](../book/09-数字与网络/I-11-第一次处理孩子游戏充值退款.md)。

## 发现后先做（别删游戏）

- [ ] 截图全部充值记录：支付账单逐笔截图，标注日期和金额
- [ ] 记录游戏名、区服、角色 ID、登录账号
- [ ] 固定孩子操作的证据：上课时段规律、聊天记录、操作视频、承认操作的录音
- [ ] 别让孩子注销账号——那会销毁操作证据
- [ ] 备好户口簿或出生证明、监护人和孩子的身份证件
- [ ] 记下家长是否保管过密码、是否知情，平台审核会参考

## 判断情形

- [ ] 不满 8 周岁：充值行为无效，可主张全额退
- [ ] 8–18 周岁：与年龄不匹配的大额充值，未经监护人同意可主张退
- [ ] 官服充值找厂商，App Store 充值先走苹果，安卓渠道服找渠道和厂商
- [ ] 多账号分散充值的，每个账号单独申诉，账单逐笔整理一次报全

## 按渠道申请

- [ ] 苹果充值：reportaproblem.apple.com → 请求退款 → 选未成年人未经授权购买
- [ ] 苹果被拒：拨客服 400-666-8800 补充证据再申请，多数成功靠第二轮
- [ ] 腾讯游戏：youyou.qq.com 家长服务平台，监护人实名发起
- [ ] 其他官服：走厂商家长服务平台或客服，配合电话回访核实
- [ ] 安卓渠道服：先渠道客服，不受理或拖延的同时向厂商提交
- [ ] 官方申请免费，别找「退款代办」中介，防伪造材料卷进骗退

## 被拒后升级

- [ ] 补充「孩子操作」证据（时段规律、操作视频、家长不在场证明）重新提交
- [ ] 12315（www.12315.cn）投诉，被投诉对象写实际收费方
- [ ] 金额数万元以上：委托律师起诉，诉讼时效三年
- [ ] 游戏停服跑路：向 12315 和文化市场综合执法投诉，保留起诉权利

## 收尾与预防

- [ ] 核对退费明细与申请清单，可能按责任比例部分退还，差额要求说明口径
- [ ] 退款原路退回；平台只退一部分的，自行权衡接受或继续申诉
- [ ] 改支付密码（避免生日和连续数字）、关免密支付
- [ ] 游戏账号开未成年人模式，设消费限额和时段限制
- [ ] 账单设置扣款提醒，和孩子约定规则
- [ ] 提交虚假材料冒充未成年人操作属骗退，有法律风险
