# I-11 第一次处理孩子游戏充值退款 · 清单

> 打印后勾选。依据见 [I-11 正文](../book/09-数字与网络/I-11-第一次处理孩子游戏充值退款.md)。

## 发现后先做（别删游戏）

- [ ] 截图全部充值记录（支付账单逐笔）
- [ ] 记录游戏名、区服、角色 ID、登录账号
- [ ] 固定孩子操作的证据：时段规律、聊天记录、操作视频
- [ ] 备好户口簿/出生证明、双方身份证

## 按渠道申请

- [ ] 苹果充值：reportaproblem.apple.com → 请求退款 → 选未成年人理由
- [ ] 腾讯游戏：youyou.qq.com 家长服务平台，监护人发起
- [ ] 其他官服：厂商家长服务/客服通道
- [ ] 安卓渠道服：先渠道客服，再厂商客服

## 被拒后升级

- [ ] 补充「孩子操作」证据重新提交
- [ ] 打渠道/厂商客服电话申诉
- [ ] 12315 平台（www.12315.cn）投诉收费方
- [ ] 金额大的：咨询律师起诉

## 收尾与预防

- [ ] 核对退款金额与明细
- [ ] 改支付密码、关免密支付
- [ ] 游戏账号开未成年人模式
- [ ] 账单设置扣款提醒
