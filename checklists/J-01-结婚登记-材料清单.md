# J-01 第一次结婚登记 · 清单

> 打印后勾选。依据见 [J-01 正文](../book/10-人生节点/J-01-第一次结婚登记.md)。

## 条件

- [ ] 双方自愿，亲自到场
- [ ] 男满 22 周岁，女满 20 周岁
- [ ] 双方均无配偶
- [ ] 不是直系血亲或三代以内旁系血亲
- [ ] 一方患重大疾病的，登记前如实告知对方，隐瞒的另一方可请求撤销婚姻
- [ ] 只办婚礼不登记，不受法律保护

## 预约与材料

- [ ] 在登记机关官网、App 或小程序预约，选工作日避开特殊日期高峰
- [ ] 双方身份证
- [ ] 双方户口簿（按当地要求）
- [ ] 3 张 2 寸近期半身免冠合影，红底或蓝底按当地要求
- [ ] 无配偶声明（现场签署）
- [ ] 离婚证或法院判决书（再婚）

## 现场办理

- [ ] 内地居民结婚登记可全国通办，任一婚姻登记机关都行
- [ ] 双方必须亲自到场，不能请人代办
- [ ] 到登记处取号，提交材料，填写声明
- [ ] 在登记表上签字、按指纹
- [ ] 工作人员打印结婚证、贴照片、盖钢印，当场发证
- [ ] 核对姓名、身份证号、照片，检查钢印和登记日期
- [ ] 结婚登记免费；照相馆拍照约 30–100 元
- [ ] 领证后迁户口自愿，不是必须

## 婚检

- [ ] 自愿参加，不强制
- [ ] 带身份证到指定妇幼保健机构
- [ ] 多数地区免费
- [ ] 领取婚检报告

## 出问题找谁

- [ ] 父母干涉：婚姻自由，任何人不得干涉
- [ ] 被胁迫结婚：向法院请求撤销婚姻
- [ ] 材料不全：按清单补齐，改约时间
- [ ] 登记被拒：要求书面说明，向上级民政部门投诉
- [ ] 涉外婚姻：到指定登记机关，材料需认证翻译
- [ ] 结婚证丢失：到原登记机关或现户籍地登记机关申请补领
