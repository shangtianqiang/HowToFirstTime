# J-01 第一次结婚登记 · 清单

> 打印后勾选。依据见 [J-01 正文](../book/10-人生节点/J-01-第一次结婚登记.md)。

## 条件

- [ ] 双方自愿
- [ ] 男满 22 周岁
- [ ] 女满 20 周岁
- [ ] 双方无配偶
- [ ] 不是直系血亲或三代以内旁系血亲

## 材料

- [ ] 双方身份证
- [ ] 户口簿（按当地要求）
- [ ] 2 寸合影照片 3 张
- [ ] 无配偶声明
- [ ] 离婚证或判决书（再婚）

## 办理

- [ ] 预约
- [ ] 到场取号
- [ ] 提交材料
- [ ] 填写声明
- [ ] 签字按指纹
- [ ] 领取结婚证
- [ ] 核对信息

## 婚检

- [ ] 自愿参加
- [ ] 带身份证
- [ ] 到指定妇幼保健机构
- [ ] 领取报告

## 出问题找谁

- [ ] 父母干涉：婚姻自由
- [ ] 被胁迫：法院撤销
- [ ] 材料不全：补齐再约
- [ ] 登记被拒：民政部门投诉
