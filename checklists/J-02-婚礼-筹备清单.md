# J-02 第一次办婚礼 · 清单

> 打印后勾选。依据见 [J-02 正文](../book/10-人生节点/J-02-第一次办婚礼.md)。

## 预算与名单

- [ ] 先定总预算，再分配到酒席、婚庆、婚纱、摄影、婚车、喜糖、烟酒
- [ ] 留 10% 备用金
- [ ] 双方家庭出资和分工写清，避免当天争执
- [ ] 定婚期，避开旺季和节假日省钱
- [ ] 先定宾客人数再订场地，别反过来

## 订酒店

- [ ] 看场地容量、层高、音响、停车
- [ ] 问清最低消费、服务费、开瓶费、超时费
- [ ] 试菜，确认菜量和口味
- [ ] 合同写清取消和改期规则
- [ ] 问清定金能否退：通常不可退，改期可能收手续费
- [ ] 提前和酒店确认加桌规则

## 订婚庆

- [ ] 查营业执照，看案例和客片
- [ ] 服务清单逐项列明：布置、主持、摄影、摄像、化妆
- [ ] 人员名单和到场时间写进合同
- [ ] 设备清单写进合同
- [ ] 口头承诺写进合同，付款节点、违约条款逐条写清
- [ ] 不付全款，警惕低价婚庆现场加价减配

## 婚纱摄影与礼服

- [ ] 看清套餐内容，选片后确认交付时间
- [ ] 底片归属写进合同，全部底片要加钱，提前谈
- [ ] 精修数量写进合同
- [ ] 交付时间写进合同，约定逾期违约
- [ ] 婚纱租赁看清洁、破损赔偿、改尺寸、取还时间

## 彩排与当天

- [ ] 发请柬统计人数，排座次，定伴郎伴娘
- [ ] 提前一天到场地彩排：走位、音乐、灯光、话筒
- [ ] 确认主持人串词和双方父母发言
- [ ] 留一人管钱、一人管流程、一人管物品
- [ ] 保管好戒指、红包、证件，备好备用音响和话筒

## 结算与出问题

- [ ] 核对酒店实际桌数和消费，婚庆尾款按合同付
- [ ] 收取照片和视频，确认数量质量，保存合同、发票、影像
- [ ] 天气突变：启用室内备用方案；宾客超员：联系酒店加桌
- [ ] 食物中毒：就医、留菜样、拨 12315
- [ ] 婚庆纠纷：保留合同和聊天记录，投诉或起诉；婚庆跑路报警并找市场监管
