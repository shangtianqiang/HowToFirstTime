# J-03 第一次独自过年/离家 · 清单

> 打印后勾选。依据见 [J-03 正文](../book/10-人生节点/J-03-第一次独自过年离家.md)。

## 行程与住宿

- [ ] 提前订票，春运期间留足时间
- [ ] 住宿选正规酒店或已租住房，检查门锁、燃气、暖气
- [ ] 把地址和电话发给家人
- [ ] 查附近医院、超市、派出所
- [ ] 返程提前查交通，避开高峰；离家前检查水电燃气

## 年货与物资

- [ ] 年夜饭提前订餐厅或买半成品，别等除夕当天
- [ ] 备 3–5 天食物、饮用水和速食
- [ ] 饺子、汤圆、春联、零食按需备
- [ ] 常用药备齐
- [ ] 充电宝充满，取暖设备检查一遍，电暖器燃气热水器防一氧化碳
- [ ] 春节外卖部分商家营业，配送费可能上涨，提前下单

## 除夕当天

- [ ] 打扫房间，贴春联
- [ ] 检查冰箱，确认餐厅预订或半成品配送
- [ ] 做或热年夜饭
- [ ] 和家里约好视频时间，云干杯
- [ ] 安排娱乐：看春晚、电影，查社区活动、庙会

## 假期作息

- [ ] 每天和家里报平安
- [ ] 按计划出门走走，别一直躺着
- [ ] 朋友聚会适量饮酒，独自不醉酒
- [ ] 保持作息，别熬夜打乱节奏
- [ ] 不回家如实向家人说明原因，可以寄点年货

## 安全

- [ ] 不向陌生人透露自己独居
- [ ] 外卖、快递放门口再取
- [ ] 出门前：燃气关阀
- [ ] 春节诈骗高发：不转账、不点链接，警惕「春节兼职」刷单
- [ ] 手机存好 110、120、96110

## 出问题找谁

- [ ] 生病：拨 120 或去急诊，告诉家人
- [ ] 停电停水：查欠费和抢修，备手电和饮用水
- [ ] 燃气泄漏：关阀、开窗、到室外打电话
- [ ] 被尾随：进便利店、酒店大堂，拨 110
- [ ] 被诈骗：拨 110 或 96110
- [ ] 情绪低落持续两周以上看心理科；崩溃时联系家人、拨心理援助热线
