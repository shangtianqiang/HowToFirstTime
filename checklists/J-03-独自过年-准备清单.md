# J-03 第一次独自过年/离家 · 清单

> 打印后勾选。依据见 [J-03 正文](../book/10-人生节点/J-03-第一次独自过年离家.md)。

## 行程

- [ ] 提前订票
- [ ] 确认住宿
- [ ] 检查门锁和燃气
- [ ] 地址发给家人
- [ ] 查附近医院和超市

## 年货

- [ ] 年夜饭食材或半成品
- [ ] 饮用水和速食
- [ ] 常用药
- [ ] 春联和零食
- [ ] 充电宝
- [ ] 取暖设备检查

## 除夕

- [ ] 打扫房间
- [ ] 贴春联
- [ ] 做年夜饭
- [ ] 和家里视频
- [ ] 安排娱乐

## 假期

- [ ] 每天报平安
- [ ] 出门走走
- [ ] 朋友聚会
- [ ] 适量饮酒
- [ ] 保持作息

## 安全

- [ ] 不透露独居
- [ ] 外卖快递放门口
- [ ] 燃气用完关阀
- [ ] 电暖器远离可燃物
- [ ] 存 110、120、119

## 出问题找谁

- [ ] 生病：120 或急诊
- [ ] 燃气泄漏：关阀、开窗、室外打电话
- [ ] 被尾随：进公共场所、110
- [ ] 情绪崩溃：家人、心理热线
