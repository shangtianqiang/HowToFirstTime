# J-04 第一次跨城定居 · 清单

> 打印后勾选。依据见 [J-04 正文](../book/10-人生节点/J-04-第一次跨城定居.md)。

## 前期与政策

- [ ] 先确认工作，再定住处
- [ ] 租房看通勤、学区、生活配套，签正规租赁合同并办居住登记
- [ ] 了解落户条件：学历、社保、房产、积分；通道有人才引进、积分落户、投靠落户
- [ ] 查购房限购和车牌摇号、拍牌政策
- [ ] 查子女入学条件和报名时间，别错过
- [ ] 查医保报销比例和定点医院

## 证件材料

- [ ] 身份证、户口簿
- [ ] 劳动合同
- [ ] 社保缴费记录
- [ ] 公积金账号
- [ ] 学历证书
- [ ] 房产证或租赁合同
- [ ] 档案存放证明

## 手续办理

- [ ] 到派出所或社区办居住登记，住满半年申领居住证
- [ ] 落户：拿准迁证，回原籍办迁移证，再到新户籍地落户
- [ ] 社保转移：国家社会保险公共服务平台或经办机构，养老保险和医保关系都转
- [ ] 公积金转移：全国住房公积金小程序或公积金中心办异地转移接续
- [ ] 档案：新单位或人才中心开调档函，走机要或专人转递，不自己拿、不拆封
- [ ] 医保异地就医先备案，选定点医院
- [ ] 别轻信「包落户」中介，材料造假有风险
- [ ] 社保尽量无缝衔接，断缴影响医保待遇、购房资格、落户积分

## 生活接入

- [ ] 办新手机号或保留原号
- [ ] 银行、社保、医保定点变更
- [ ] 驾驶证到新居住地车管所转入，带身份证、驾驶证、照片
- [ ] 车牌看当地限行和迁入政策，外地车牌可能受限
- [ ] 子女学籍转接：联系转入地教育局和学校
- [ ] 到社区登记

## 出问题找谁

- [ ] 落户被拒：问清原因，补材料或走其他通道
- [ ] 社保转移失败：核对身份信息，联系两地经办机构
- [ ] 档案丢失：向原单位、人才中心查询补建
- [ ] 医保不能结算：先自费，保留发票回参保地报销
- [ ] 子女无法入学：联系教育局统筹安排
