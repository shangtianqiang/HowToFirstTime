# J-05 第一次失业 · 清单

> 打印后勾选。依据见 [J-05 正文](../book/10-人生节点/J-05-第一次失业.md)。

## 确认资格

- [ ] 失业保险缴满 1 年
- [ ] 非本人意愿失业：裁员、合同到期不续签、单位解除
- [ ] 已办失业登记并有求职要求
- [ ] 主动辞职一般不符合条件
- [ ] 离职证明别写成「个人原因」，否则失去资格
- [ ] 解除劳动合同之日起 60 日内办理，尽快办

## 材料与权益

- [ ] 身份证、社保卡
- [ ] 解除或终止劳动合同证明
- [ ] 银行卡
- [ ] 户口簿、照片（部分地区要）
- [ ] 算清权益：缴费年限对应的领取月数、当地失业金标准（低于最低工资、高于低保）
- [ ] 丧葬补助、抚恤金、一次性生活补助（农民合同制工人）如涉及

## 办理

- [ ] 办失业登记：当地人社部门、街道社保所或线上平台
- [ ] 申领失业金，绑定银行卡
- [ ] 按月签到或线上认证，不签到会停发
- [ ] 确认职工医保由失业保险基金代缴，个人不缴
- [ ] 领取期限：缴 1–5 年最长 12 个月，5–10 年 18 个月，10 年以上 24 个月
- [ ] 养老保险可以灵活就业身份续缴
- [ ] 失业金免征个人所得税

## 求职与再就业

- [ ] 办求职登记
- [ ] 参加免费技能培训
- [ ] 更新简历，保留求职记录
- [ ] 重新就业参保后停领，未领完的期限可累计到下次失业
- [ ] 不隐瞒就业，隐瞒会被追回并处罚

## 出问题找谁

- [ ] 单位不给离职证明：向劳动监察投诉，申请仲裁
- [ ] 失业金被拒：要书面理由，申请复核
- [ ] 医保未代缴：联系失业保险经办机构
- [ ] 经济困难：申请临时救助、低保，咨询社区
- [ ] 心理压力大找家人朋友、心理咨询；轻信「代领失业金」是骗局
