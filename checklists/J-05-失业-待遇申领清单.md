# J-05 第一次失业 · 清单

> 打印后勾选。依据见 [J-05 正文](../book/10-人生节点/J-05-第一次失业.md)。

## 资格

- [ ] 失业保险缴满 1 年
- [ ] 非本人意愿失业
- [ ] 已办失业登记
- [ ] 有求职要求
- [ ] 确认不属于主动辞职

## 材料

- [ ] 身份证
- [ ] 社保卡
- [ ] 离职证明
- [ ] 银行卡
- [ ] 户口簿（如需）
- [ ] 照片（如需）

## 办理

- [ ] 失业登记
- [ ] 申领失业金
- [ ] 绑定银行卡
- [ ] 确认发放时间
- [ ] 按月签到
- [ ] 确认医保代缴

## 求职

- [ ] 求职登记
- [ ] 参加免费培训
- [ ] 更新简历
- [ ] 保留求职记录
- [ ] 重新就业后停领

## 出问题找谁

- [ ] 单位不给离职证明：劳动监察、仲裁
- [ ] 失业金被拒：书面理由、复核
- [ ] 医保未代缴：失业保险经办机构
- [ ] 经济困难：临时救助、低保
