# J-06 第一次退休 · 清单

> 打印后勾选。依据见 [J-06 正文](../book/10-人生节点/J-06-第一次退休.md)。

## 查清

- [ ] 出生日期
- [ ] 参加工作时间
- [ ] 养老保险缴费年限
- [ ] 视同缴费年限
- [ ] 医保缴费年限
- [ ] 是否特殊工种或病退

## 材料

- [ ] 身份证
- [ ] 社保卡
- [ ] 人事档案
- [ ] 户口簿
- [ ] 银行卡
- [ ] 照片
- [ ] 退休申请表
- [ ] 特殊工种证明

## 办理

- [ ] 提前 3 个月准备
- [ ] 提交申请
- [ ] 审核档案
- [ ] 核对养老金核定表
- [ ] 医保补缴（如需）
- [ ] 激活社保卡金融功能
- [ ] 首月养老金到账

## 退休后

- [ ] 每年生存认证
- [ ] 异地就医备案
- [ ] 关注养老金调整
- [ ] 补充商业保险（如需）
- [ ] 规划退休生活

## 出问题找谁

- [ ] 档案缺失：原单位、档案馆
- [ ] 缴费记录错误：申请更正
- [ ] 养老金未到账：社保经办机构
- [ ] 认证失败：社区或窗口
