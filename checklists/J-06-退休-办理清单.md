# J-06 第一次退休 · 清单

> 打印后勾选。依据见 [J-06 正文](../book/10-人生节点/J-06-第一次退休.md)。

## 查清

- [ ] 出生日期、参加工作时间、参保地
- [ ] 养老保险累计缴费年限，目前满 15 年，2030 年起逐步提高
- [ ] 是否有视同缴费年限，需要档案证明
- [ ] 医保缴费年限是否满足退休要求
- [ ] 是否特殊工种、病退、弹性提前退休
- [ ] 缴费不足 15 年：继续缴至满 15 年，或按当地政策转入城乡居民养老保险
- [ ] 缴费记录有断缴、错误，提前申请更正补材料

## 材料

- [ ] 身份证
- [ ] 社保卡
- [ ] 人事档案
- [ ] 户口簿
- [ ] 银行卡
- [ ] 照片
- [ ] 退休申请表
- [ ] 特殊工种证明（如适用）

## 办理

- [ ] 提前 3 个月准备，生日当月或次月办理
- [ ] 确认档案存放地和内容，缺失的到原单位、档案馆补开证明
- [ ] 提交退休申请：社保经办机构、单位人事部门或线上平台
- [ ] 核对养老金核定表：缴费指数、个人账户余额，少算当场提
- [ ] 医保年限不足：按当地政策一次性补缴或继续缴
- [ ] 激活社保卡金融功能，否则养老金打不进来
- [ ] 不轻信「代办退休」，不提前退保
- [ ] 关注首月养老金到账

## 退休后

- [ ] 每年做生存认证：人社 App 人脸认证，或社区、社保窗口
- [ ] 异地居住办异地就医备案，认证可线上
- [ ] 关注国家每年养老金调整通知
- [ ] 退休后养老保险不用再缴，医保按当地退休人员政策执行
- [ ] 线上办事走国家社会保险公共服务平台，咨询拨 12333

## 出问题找谁

- [ ] 档案缺失：到原单位、档案馆查找，补开证明
- [ ] 缴费记录错误：提供工资单、劳动合同申请更正
- [ ] 养老金未到账：查社保卡金融账户，联系社保经办机构
- [ ] 认证失败：到社区或窗口人工认证
