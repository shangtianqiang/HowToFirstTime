# J-07 第一次立遗嘱/意定监护 · 清单

> 打印后勾选。依据见 [J-07 正文](../book/10-人生节点/J-07-第一次立遗嘱意定监护.md)。

## 盘点财产

- [ ] 房产、存款、股票、基金、保险逐项列明
- [ ] 车辆、股权、知识产权
- [ ] 债权债务
- [ ] 数字资产：账号、虚拟货币（按平台规则）
- [ ] 列清单，写清权属和证件位置
- [ ] 夫妻共同财产只能处分自己份额，不处分他人财产

## 内容与形式

- [ ] 确定继承人：配偶、子女、父母，想给谁、给多少
- [ ] 保留必留份：缺乏劳动能力又没有生活来源的继承人
- [ ] 选形式：自书、代书、打印、录音录像、公证
- [ ] 自书遗嘱必须亲笔书写，不能打印后签名
- [ ] 打印遗嘱每页签名，注明年月日
- [ ] 代书、打印、录音录像遗嘱要 2 名以上见证人
- [ ] 见证人不能是继承人、受遗赠人、利害关系人（子女不行）
- [ ] 语言明确不歧义，可指定信任的人作遗嘱执行人（遗产管理人）

## 意定监护

- [ ] 书面指定信任的人作失能后的监护人
- [ ] 写清权限范围
- [ ] 最好公证，增强证明力减少争议
- [ ] 告知家人
- [ ] 不做意定监护，失能后无人有权代理

## 保管与变更

- [ ] 原件放保险柜或交公证处保管
- [ ] 告知一位信任的家人存放位置，别藏到没人知道
- [ ] 多份遗嘱以最后一份合法有效的为准，公证遗嘱不再优先
- [ ] 情况变化重新订立，新遗嘱注明日期、妥善保管
- [ ] 口头遗嘱只在危急情况有效，危急解除后改为书面

## 出问题找谁

- [ ] 遗嘱争议：做笔迹鉴定，按民法典处理
- [ ] 被胁迫立的遗嘱：可以请求撤销
- [ ] 遗嘱丢失：用复印件或见证人证言，效力较弱
- [ ] 意定监护争议向法院申请指定监护；涉外财产按财产所在地法律咨询律师
