# J-08 第一次面对身后事安排 · 清单

> 打印后勾选。依据见 [J-08 正文](../book/10-人生节点/J-08-第一次面对身后事安排.md)。

## 生前把意愿写下来

- [ ] 和家人沟通捐献、殡葬方式，别只口头说
- [ ] 写书面意愿，签名注日期
- [ ] 指定一位信任的人执行，告知医生和家属
- [ ] 有临终医疗意愿的，写生前预嘱并告知家属和医生
- [ ] 备齐身份证、遗嘱、财产清单、保单、捐献登记卡和紧急联系人
- [ ] 列数字资产清单：账号、照片、支付账户，密码交信任的人保管

## 摸清当地政策

- [ ] 查清当地是火葬区还是土葬改革区
- [ ] 问殡仪馆官方收费和惠民殡葬政策，别找殡葬中介
- [ ] 查生态安葬补贴：海葬、树葬、花坛葬，问当地民政部门
- [ ] 存下器官捐献流程和红十字会联系方式

## 捐献登记

- [ ] 到当地红十字会或官方平台填志愿书，登记器官或遗体捐献
- [ ] 看清捐献条件和家属配合要求；即使本人生前登记，执行时通常也要家属配合
- [ ] 记住：器官捐献用于移植，遗体捐献用于医学教学研究
- [ ] 拿到登记卡，交家人保管

## 死亡发生后：证明与殡葬

- [ ] 医院死亡由医院开死亡医学证明；家中死亡联系社区卫生服务机构或报警
- [ ] 生前登记过捐献的，死亡后通知红十字会
- [ ] 联系正规殡仪馆接运，选定火化、告别仪式和骨灰安葬方式
- [ ] 拿到死亡证明多复印几份，补办麻烦
- [ ] 火化完成后，拿到火化证明
- [ ] 后事办理预留 3–7 天

## 注销、待遇与遗产

- [ ] 凭死亡证明到户籍地派出所注销户口
- [ ] 注销社保和医保，不注销多领待遇要退回
- [ ] 参加企业职工基本养老保险的，遗属向社保经办机构申请丧葬补助金和抚恤金
- [ ] 清点财产和债务，防止遗漏
- [ ] 有遗嘱按遗嘱，无遗嘱按法定继承，必要时办公证
- [ ] 按平台规则申请注销或继承数字账号

## 出问题找谁

- [ ] 非正常死亡：保护现场，报警，不移动遗体
- [ ] 捐献被拒：问清医学原因，尊重家属决定
- [ ] 殡葬乱收费：向民政、市场监管投诉
- [ ] 遗产纠纷：协商、调解、诉讼
- [ ] 异地死亡：联系当地殡仪馆和户籍地民政部门
- [ ] 心理危机：联系家人、心理咨询、援助热线
