# J-09 第一次办离婚登记 · 清单

> 打印后勾选。按「申请日 → 冷静期 → 领证日 → 领证后」四段走。依据见 [J-09 正文](../book/10-人生节点/J-09-第一次办离婚登记.md)，核实记录见 [J-09.核实](../sources/J-09.核实.md)。

## 申请日前

- [ ] 确认两人都自愿，能各自到场两次
- [ ] 拟好离婚协议书：自愿离婚意思表示、子女抚养与探望、财产分割、债务处理逐项写清
- [ ] 有贷款的写明还款人、过户配合期限
- [ ] 预约婚姻登记机关（官网、小程序或政务服务网，以当地为准）
- [ ] 双方身份证在有效期内
- [ ] 结婚证两本都在；丢了的先咨询登记机关
- [ ] 协议书按当地要求备份数（部分地区一式三份）

## 第一次到场（申请日）

- [ ] 交双方身份证、结婚证、离婚协议书
- [ ] 填写离婚登记声明书和申请表
- [ ] 如实回答是否自愿、协议是否真实
- [ ] 拿到受理回执单
- [ ] 记下冷静期起止日和申领截止日（届满后 30 天内）
- [ ] 和对方约好第二次共同到场日期，别压最后一天

## 冷静期 30 天内

- [ ] 任一方想撤回：单独向受理机关提出即可，程序终止（想清楚再用）
- [ ] 整理财产证件：房产证、行驶证、存款账户、公积金
- [ ] 列后续事项清单：孩子户口、学籍、保险受益人、遗嘱更新
- [ ] 大额分歧谈不拢的，咨询律师或法律援助，考虑改走诉讼

## 第二次到场（领证日，届满后 30 天内）

- [ ] 两人同去，回到受理申请的原机关
- [ ] 带双方身份证、结婚证、受理回执单、离婚协议书
- [ ] 拿到离婚证，核对姓名、身份证号、登记日期
- [ ] 结婚证交登记机关处理（多数收回或注明注销，以当地为准）
- [ ] 离婚协议书各留一份原件存好

## 领证后

- [ ] 房产、车辆过户或贷款变更
- [ ] 孩子户口、学籍信息变更（公安、学校要求以当地为准）
- [ ] 保险受益人、遗嘱等安排更新
- [ ] 户口簿婚姻状况变更（自愿办理，以当地公安要求为准）

## 出问题找谁

- [ ] 一方反悔或不来领证：程序视为撤回；坚持离婚的向法院起诉
- [ ] 家暴：报警 110，向妇联、居委会求助，向法院申请人身安全保护令
- [ ] 材料被退：问清原因，补齐再约
- [ ] 情绪困扰：登记机关婚姻家庭辅导服务，或拨 12345 查当地心理援助渠道
