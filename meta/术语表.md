# 术语表

只收本书反复出现的词。解释只写一句，具体以官方页面为准。

| 词 | 一句话解释 |
| --- | --- |
| 值机 | 在机场确认你要坐这一班飞机、拿到登机牌、把行李交运的手续。 |
| 登机牌 | 值机后拿到的凭证，上面有航班号、登机口和座位号。 |
| 安检 | 进入候机区或候车区前，检查随身物品和人身安全的环节。 |
| 登机口 | 登机牌上写的候机位置，飞机在这里检票上客。 |
| 行李额 | 机票或车票包含的免费托运行李重量或件数，超出要另付费。 |
| 候补 | 车票售完后排队等退票，有人退票时按顺序分配。 |
| 改签 | 把原车票或机票换成另一时间、车次或航班，通常有条件和手续费。 |
| 检票口 | 车站里刷证或扫码进站台的入口，票面或大屏会写编号。 |
| 席别 | 火车座位或铺位的等级，如二等座、一等座、硬卧、软卧。 |
| 边检 | 出入境时检查护照、签证和出入境资格的环节。 |
| 海关申报 | 携带超过限额的现金、物品或禁限物品时，向海关如实申报。 |
| 领事保护 | 中国驻外使领馆对海外中国公民提供的协助，有明确范围。 |
| 五险一金 | 养老、医疗、失业、工伤、生育保险和住房公积金。 |
| 试用期 | 劳动合同里约定的考察期，长度和工资有法定限制。 |
| 三方协议 | 毕业生、学校、用人单位签的就业协议，不等同于劳动合同。 |
| 社保基数 | 计算社保缴费金额的工资基数，通常每年调整一次。 |
| 公积金 | 单位和职工共同缴存的住房储金，可用于买房、租房等。 |
| 生育津贴 | 生育保险支付的产假期间工资性补助，标准按当地规定。 |
| 建档 | 孕妇在医疗机构建立孕产期保健档案，后续产检跟着档案走。 |
| 出生医学证明 | 孩子出生后由医院签发的法定医学证明，上户口要用。 |
| CEFR | 欧洲语言共同参考框架，把外语水平分为 A1 到 C2 六级。 |
| 科目一 | 驾照考试的理论考试，考交通法规和安全常识。 |
| 科目二 | 驾照考试的场地驾驶考试。 |
| 科目三 | 驾照考试的道路驾驶考试。 |
| 科目四 | 驾照考试的安全文明驾驶常识考试。 |
| 实习期 | 初次领证后的一段时间，开车有额外限制。 |
| 起付线 | 医保开始报销前，个人先自付的金额门槛。 |
| 医保目录 | 医保能报销的药品、诊疗项目和医用耗材范围。 |
| 12315 | 市场监管部门的消费者投诉举报电话和平台。 |
| 12326 | 民航服务质量监督电话。 |
| 12308 | 外交部全球领事保护与服务应急热线。 |
