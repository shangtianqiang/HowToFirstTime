## 填写要求

### front-matter

| 字段 | 要求 |
| --- | --- |
| `id` | 栏目字母 + 两位序号，永不复用 |
| `title` | 与文件名、一级标题一致 |
| `domain` | 十个栏目名称之一，和所在目录一致 |
| `stage` | `学生` `初入职场` `新婚` `新手父母` `中年` `退休`，可多选 |
| `prerequisites` | 缺了就办不成的东西，没有就写 `[]` |
| `duration` | `半小时内` `半天` `1-3天` `长期` |
| `cost` | `免费` `百元内` `千元级` `万元级` |
| `risk` | `低` `中` `高`；高风险条目必须写「做错的后果」和「找谁」 |
| `volatility` | `S` 稳定、`M` 易变、`H` 高频变动 |
| `region` | `全国` `分省` `分市` `分机构` |
| `last_verified` | 最近一次核实日期，格式 `YYYY-MM-DD` |
| `status` | `初稿` `已核实` `待更新` `有争议` |
| `source_count` | 文末来源列表的条数 |
| `related` | 相关条目 ID 数组，例如 `[B-01, A-02]` |

### 各板块

- **一句话**：不超过 50 字，只写最关键的动作和底线。
- **适用 / 不适用**：读者能据此判断这篇是不是写给他看的。
- **0. 30 秒速查**：4–6 条，每条一行，不解释。
- **1. 准备事项**：按时间倒排，材料清单用 `- [ ]` 复选框。
- **2. 现场流程**：每步写清「在哪、做什么、看什么、说什么、完成标志」。
- **3. 常见问题**：至少 10 条，问题来自搜索、问答、访谈，不自己编。
- **4. 避坑提醒**：至少 8 条，每条写「坑是什么 + 怎么躲」。
- **5. 特殊情况与应急**：至少 5 种，每种写第一步找谁。
- **6. 费用与时间预算**：给区间，标必选/可选。
- **7. 延伸资源**：官方入口、相关条目、清单，不放广告。
- **8. 依据与核实**：写等级构成、来源数、核实日期、地区差异、易变项。

## 未核实内容怎么写

查不到可靠来源时，不要猜。统一写成：

```markdown
- 提前多久到：待核实（要查：机场官网/航司运输总条件）
```

并在 `sources/ID.核实.md` 的「待核实」表里登记。核实后再替换成正文。
